계산 기준과 검증 범위

레이더 A~D는 모두 2026-10의 각 시장 마지막 거래일 기준입니다. 진행 중인 2026-11 가격은 레이더에 사용하지 않습니다. 요약 바의 ‘개선’은 현재 상태, B는 이번 달 새로 개선으로 전환한 항목입니다. 항목은 여러 섹션에 함께 나올 수 있습니다.

x = 해당 월 수익률 − 벤치마크 해당 월 수익률(%p). 절대 수익률이 아니라 벤치마크 대비 상대 성과입니다. 예를 들어 2026-10 코스닥은 절대 −15.4%였고 SPX 대비로는 +0.8%p입니다. M = 최근 3개월 x의 산술평균(%p). V = M − 전월 M. A = V − 전월 V. 벤치마크는 섹터 SPY, 모든 지수 SPX(데이터 키 SP500)입니다.

상태는 첫 일치만 부여합니다: 개선(x ≥ 1.5, V ≥ 1.5, 전월 M ≤ 0) → 둔화(전월 M ≥ 0.5이며 (V ≤ −1.5 또는 x ≤ −0.5)) → 우위(M ≥ 0.5, x ≥ −0.5) → 열위(M ≤ −0.5) → 중립.

순위는 M(3개월 상대수익률)을 큰 값부터 직접 정렬해 매깁니다. 동점은 공동 순위로 두고 그다음 순위를 건너뜁니다. 각 월 자료가 있는 관찰 대상만 순위에 포함하며 벤치마크는 제외합니다.

C는 |종가 / SMA200 − 1| ≤ 0.02 또는 월중 상향 돌파입니다. SMA200은 당일을 포함한 최근 200거래일 종가의 단순평균입니다. 전 거래일 종가가 해당 일 SMA200 이하, 당일 종가가 SMA200 초과면 돌파로 보고 월중 첫 돌파일을 표시합니다. 월말에 다시 이탈했어도 돌파 사실은 남깁니다. D는 상대 우위(M > 0)를 유지하면서 1개월 상대수익률(x)이 마이너스이거나 상대 변화(V)가 하락한 항목입니다(원본은 M ≥ 5·x < 0·V < 0을 모두 요구했으나 26년 표본에서 거의 발생하지 않아 완화했습니다). E는 반대로 M < 0(아직 벤치마크보다 부진)이지만 V > 0(전월보다 상대 흐름 개선)인 항목으로, 낙폭이 줄어드는 후보를 관찰합니다.

x·M·V·A·상태·백분위·개선 전환은 백테스트 산출물을 그대로 사용합니다. 페이지가 자체 공식을 다시 적용하면 백테스트 수치와 어긋나므로, 확정 월 레코드는 검증 결과 JSON에서 읽습니다. A의 ‘검증 통과/미통과’는 순위 조건의 백테스트 비교에 한정하며 C·D의 예측력은 별도로 검증하지 않았습니다.
