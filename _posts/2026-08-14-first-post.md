이 글은 Markdown으로 작성하고 **Jekyll**이 HTML로 변환한 첫 번째 테스트 글입니다.

## 게시 흐름

1. Markdown 파일을 작성합니다.
2. GitHub 저장소에 push합니다.
3. GitHub Pages가 Jekyll로 사이트를 빌드합니다.
4. 완성된 정적 페이지를 공개합니다.

## 코드 예시

```python
def hello():
    print("Hello, GitHub Pages!")

hello()
```

## 테스트 표

| 항목 | 상태 |
|---|---|
| Markdown | 준비 완료 |
| Jekyll | 자동 빌드 |
| GitHub Pages | 공개 예정 |

앞으로 이 공간에 AI, 데이터 분석, 투자 리서치와 서버 운영 기록을 정리할 예정입니다.
