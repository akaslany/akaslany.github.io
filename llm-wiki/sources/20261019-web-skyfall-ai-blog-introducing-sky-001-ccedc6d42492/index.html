1. 개요 (Overview)

[사실] 본 보고서는 스카이폴 에이아이 블로그(Skyfall AI Blog)에 2026년 10월 19일 게시된 스카이폴 리서치(Skyfall Research)의 기술 아티클 "Introducing SKY-001: The First World Model for Engineering"을 바탕으로 작성되었습니다. 해당 자료는 헤드리스 크롬(--dump-dom) 방식으로 렌더링된 아티클 컨테이너의 동결 텍스트 데이터를 수집하여 분석에 활용하였습니다. 본 문서에서 다루는 SKY-001은 기존 대형 언어 모델(LLM)이 물리적 엔지니어링 영역에서 가지는 근본적인 한계점을 극복하기 위해 개발되었습니다. 기존 언어 모델은 추론, 코드 작성 및 일반적인 문제 해결에는 뛰어난 성과를 보이지만, 수천 개의 상호 연결된 부품 전반에서 기하학적 정밀도, 물리적 가용성, 제조 가능성 및 공간적 제약 조건을 일관되게 유지하거나 장기 계획(Long-horizon planning)을 수행하는 데 명확한 한계를 나타냅니다. (01 Introduction)

[사실] SKY-001은 시각적 세계에서 직접 설계 및 생성 시퀀스를 계획하는 '공간 월드 모델(Spatial World Model)'입니다. 단순히 환경을 관찰하거나 탐색용 이미지를 생성하는 기존 월드 모델과 달리, SKY-001은 복잡한 물리적 시스템을 관리 가능한 요소로 분할하고 수백~수천 단계의 건설 과정을 거치는 동안 공간적 일관성을 유지합니다. 주요 적용 분야는 CAD(컴퓨터 가공/설계)와 BIM(건축 정보 모델링)입니다. CAD 영역에서는 단일 제품 이미지를 기반으로 어셈블리와 부품의 계층 구조를 도출하고 각 부품을 형성하는 스케치 및 작업 시퀀스를 생성합니다. BIM 영역에서는 건물 외곽선 정보를 바탕으로 유닛 배치 및 세부 방 구조 평면도를 생성합니다. (01 Introduction)

[사실] SKY-001의 전체 파이프라인은 디자인을 계층적으로 분할하는 '계층적 작곡가(Hierarchical Composer)'와 분할된 각 부품의 시각적 생성 순서를 예측하는 '건설 월드 모델(Construction World Model)'의 2단계 구조로 구성되어 있습니다. 성능 평가 결과, SKY-001은 최신 프론티어 모델(GPT-6 Astra 등)과 동등하거나 그 이상의 생성 품질(IoU)을 유지하면서도, CAD 영역에서는 처리 속도 약 51배 향상 및 비용 약 150배 절감을 달성하였고, BIM 영역에서는 처리 속도 약 119배 향상 및 비용 약 186배 절감을 기록하는 독보적인 효율성을 입증하였습니다. (02 Pipeline Overview, 06 Performance)

2. 주요 논점 (Main Issues & Technical Details)
2.1. 기존 언어 모델의 한계와 SKY-001의 공간적 접근법
  • 논점: [소스 주장] 언어(Text)는 복잡한 물리적 엔지니어링 설계 시 정밀한 기하학적 관계 및 공학적 제약 조건을 표현하기에 비효율적인 매체입니다. (01 Introduction)
  • 근거: [소스 주장] 단일 평면(Flat) 구조의 언어 기반 모델은 설계의 모든 부품과 생성 단계를 하나의 긴 사슬(Chain)로 연결하여 순차 생성합니다. 이 방식은 이전의 모든 결정이 다음 생성에 연속적으로 영향을 미치므로, 수천 단계의 생성 과정 속에서 오차가 누적되는 치명적인 문제가 발생합니다. (02 Pipeline Overview)
  • 사례/구조: [사실] SKY-001은 계층적(Hierarchical) 방식을 도입하여 작업 사슬을 분쇄합니다. 상위 부모 노드(Parent Node)의 구조가 확정되면, 하위 요소들의 롤아웃(Rollout)은 실제 엔지니어링 팀이 업무를 분담하는 것처럼 병렬(Parallel)로 실행됩니다. 이에 따라 전체 순차 작업 단계의 길이는 시스템의 전체 크기가 아닌 '트리의 깊이(Depth)'에만 비례하게 되어 긴 시퀀스의 생성 작업이 가능해집니다. 또한, 상위 단계에서 하위 단계로 명확한 서브골(Subgoal)을 전달함으로써 수백 단계가 지난 후에도 개별 볼트 조인트 수준의 결정이 전체 엔진 구조와 일관성을 유지하도록 보장합니다. (02 Pipeline Overview)
2.2. SKY-001의 2단계 파이프라인 구조

[사실] SKY-001은 계층적 작곡가와 건설 월드 모델이라는 2단계 파이프라인을 통해 정밀한 디자인 플랜을 도출합니다. (02 Pipeline Overview)

구분 계층적 작곡가 (Hierarchical Composer) 건설 월드 모델 (Construction World Model)
주요 역할 [사실] 전체 디자인 생성 -> 계층적 분할 -> 리프(Leaf) 부품 정교화 (03 Hierarchical Composer) [사실] 각 리프 부품의 시각적 생성 순서(Visual Sequence) 예측 (04 Construction World Model)
CAD 적용 [사실] - 단일 이미지 입력에서 개괄적 3D 형상 생성<br>- 어셈블리 및 하위 부품으로 단계별 트리 분할 (예: VMS-85 엔진의 5단계 트리)<br>- 정교화(Refiner) 과정을 통해 가려진 내부 기하 구조 및 미세 세부요소 완성 [사실] - 단계별 3D 서브골(중간 3D 형상) 계획<br>- 연속된 3D 상태 사이를 잇는 2D 스케치 생성<br>- 기저 외곽선 돌출(Extrusion), 추가 돌출, 절삭(Cut) 작업 등의 스케치 연산을 교차 수행하여 리프 부품 완성
BIM 적용 [사실] - 건물 외곽선 및 요약서(Brief) 입력<br>- 요약서에 명시된 프로그램 및 면적을 기반으로 방 1개당 1개의 상자(one box per room) 형태의 레이아웃 스케치를 먼저 생성하여 모델에 공간적 위치 전달<br>- 외벽, 슬래브 및 공유 동선(복도, 계단, 엘리베이터) 배치 후 전체 층을 개별 유닛 및 방 단위로 분할 [사실] - 외곽선 -> 유닛 간 분리 벽체 -> 세부 방/문/창문/가구 순의 도면 생성<br>- 단계별 2D 도면 상태를 순차적으로 롤아웃하여 전체 평면도 완결

[사실] 2D 롤아웃 압축 기술 (Latent Compression & Refinement): CAD의 스케치 생성 및 BIM의 도면 작성 과정에서는 2D 디퓨전(Diffusion) 기술이 적용됩니다. 본 모델은 효율성을 위해 마트료시카(Matryoshka) 스타일 오토인코더를 활용합니다. 오토인코더는 초기 학습 시 코드의 뒷부분을 단계적으로 제거하며 전체적인 레이아웃을 전반부 코드에 압축 수록하도록 학습됩니다. 건설 월드 모델은 압축된 잠재 공간(Latent Space)에서 압축 코드를 사용해 전체 생성 시퀀스를 조밀하고 빠르게 롤아웃(Latent Rollout)한 후, 정교화 모델(Refiner)이 이를 받아 고해상도 캔버스로 재그림으로써 선명한 선, 정밀한 모서리 및 세부 디테일을 복원합니다. (04 Construction World Model - 2D Rollout)

2.3. 학습 데이터셋 구축 및 데이터 품질 비교

[사실] 데이터 정제 프로세스: 공개 데이터셋의 CAD 자산은 불일치하는 어셈블리 트리, 중복 표면, 무작위 개체 혼합 등의 문제가 존재합니다. 스카이폴 연구진은 모든 자산의 계층 구조를 공학적 표준 관례에 맞춰 재구축하였으며, 건설 히스토리가 누락된 부품에 대해서는 엔지니어링 툴과 LLM 기반 워크플로우를 활용해 역공학(Reverse-engineering) 방식으로 건설 트래젝터리를 복원·검증하였습니다. BIM 데이터 역시 평면도 축 정렬, 방 유형 매핑, 요약서 역생성 과정을 거쳐 정제되었습니다. (05 Training Data)

2.4. 성능 평가 (Performance Benchmarks)

[사실] CAD 건설 벤치마크 (1,000개 부품 대상): 재규어 E-타입 로드스터(Jaguar E-Type Roadster), 화낙 아크메이트 100iB(FANUC ArcMate 100iB) 로봇 암, 미니트랙터 4×4(Minitractor 4×4), 벨 222 헬리콥터(Bell 222 helicopter), 제트 엔진(Jet Engine) 등 복잡한 객체에서 추출한 1,000개 부품을 대상으로 생성 속도, 비용, 품질(IoU)을 평가하였습니다. (06 Performance - CAD)

  • 생성 속도 (건당): SKY-001 (3.9초) vs GPT-6 Astra (199초) vs Gemini 4 (253초) vs Qwen 3.8 Max (764초) vs Kimi K3 (439초) vs Grok 4.7 (1,250초) (SKY-001은 GPT-6 Astra 대비 약 51배 빠른 속도 달성)
  • 건당 비용: SKY-001 ($0.005) vs GPT-6 Astra ($0.75) vs Gemini 4 ($0.25) vs Qwen 3.8 Max ($0.30) vs Kimi K3 ($0.13) vs Grok 4.7 ($0.59) (SKY-001은 GPT-6 Astra 대비 약 150배 저렴한 비용 달성)
  • 품질 (IoU): SKY-001 (79.7%) vs GPT-6 Astra (79.1%) vs Gemini 4 (76.9%) vs Qwen 3.8 Max (34.4%) vs Kimi K3 (9.5%) vs Grok 4.7 (출력 실패/no output)

[사실] CAD 계층적 작곡가 블라인드 평가: 단일 이미지 기반 자동차, 오토바이, 엔진 생성을 두고 평가를 진행하였습니다. 비교 대상 프론티어 모델들은 단일 프롬프트 요청 시 전체 어셈블리에 대한 블렌더 스크립트(Blender script)를 작성하는 방식으로 평가되었으며, GPT-6.1 Sol 및 Claude Opus 5.5 등 2대의 LLM 심사위원이 블라인드 평가를 수행하였습니다 (1~10점 만점). (06 Performance - CAD)

  • 부품 분해 (Part decomposition): SKY-001 (7.8) vs GPT-6 Astra (6.4)
  • 내부 구조 (Interior): SKY-001 (7.3) vs GPT-6 Astra (6.3)
  • 복잡성 (Complexity): SKY-001 (8.0) vs GPT-6 Astra (7.3)
  • 입력 이미지 일치도 (Match to input image): SKY-001 (8.1) vs GPT-6 Astra (6.7)
  • 외부 리얼리즘 (Exterior realism): SKY-001 (7.7) vs GPT-6 Astra (7.4) (참고: 비교 대상인 GPT-6 Astra는 자산의 82%에 대해서만 모델 출력을 완료함)

2.5. 향후 발전 방향 (What Comes Next)
