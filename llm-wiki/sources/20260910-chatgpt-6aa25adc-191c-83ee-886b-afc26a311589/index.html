DeepSeek-V4.1 기술 심층 분석 보고서: 단일 모델을 넘어선 메모리 계층 지능 시스템으로의 진화

1. 서론: DeepSeek-V4.1의 패러다임 전환 및 핵심 설계 철학

DeepSeek-V4.1은 단순한 모델 파라미터 확장이 아닌, '장기 에이전트(Long-term Agent)' 시대를 타겟으로 Transformer의 컴퓨팅 및 메모리 아키텍처를 근본적으로 재설계한 지능형 시스템이다. 기존 Transformer 아키텍처가 가진 '모든 토큰의 독립적 처리 및 상태 저장'이라는 고정관념을 파괴하고, 다차원적 희소성(Multi-dimensional Sparsity)과 계층적 메모리(Hierarchical Memory) 구조를 도입함으로써 지능형 에이전트 운영의 경제성을 확보했다.

본 보고서는 DeepSeek-V4.1의 혁신을 시스템 아키텍트의 관점에서 분석하며, 하드웨어 제약(HBM 대역폭 및 용량) 내에서 추론 밀도를 극대화하기 위한 전략적 선택들을 다룬다.

핵심 기술 분류
  • Breakthrough (근근적 혁신):
    • Causal Encoder-Decoder (CED): 입력과 출력의 비대칭적 처리 구조
    • Cross-Layer Attention 2.0 (CSA2): 레이어 축 압축(Layer dimension compression)
    • SWA Bounded Replay: 출력 불변성 기반의 근사 상태 복원(Approximate state reconstruction)
    • Engram: 연산(Compute)과 암기(Memorization)의 물리적 분리
  • Engineering Advance (기술적 진보):
    • Single-Pass mHC: 활성화 메모리 트래픽의 이론적 하한선 도달
    • DSpark: 백본과 분리된 독립형 추측 디코딩(Speculative Decoding)
    • DSec: 수백만 에이전트 운영을 위한 엘라스틱 컴퓨트 스케줄러
    • Reasoning Effort Control: 컨디셔닝 시그널을 통한 추론 비용 제어

2. 아키텍처 혁신 I: 컴퓨팅 효율성 극대화를 위한 구조적 Breakthrough

CED(Causal Encoder-Decoder): 비대칭적 연산의 도입

기존 Decoder-only 모델은 프롬프트가 길어질수록 모든 토큰이 모든 레이어를 통과해야 하여 $O(NL)$의 복잡도를 가졌다. DeepSeek-V4.1은 40개 레이어를 20개의 Causal Encoder와 20개의 Decoder로 분리하고, Decoder의 Global KV를 Encoder의 마지막 Hidden State($H_{20}$)에서 직접 프로젝션하도록 설계했다.

이 구조를 통해 전체 복잡도는 $O(NL/2 + n_{win}L/2) \approx O(NL/2)$ 수준으로 감소한다. 이는 '입력을 읽는 컴퓨터와 출력을 생성하는 컴퓨터는 구조가 달라도 된다'는 전략적 판단의 결과이며, 특히 입력 부하가 큰 에이전트 워크로드에서 TCO(Total Cost of Ownership)를 획기적으로 낮추는 핵심 요인이 된다.

CSA2(Cross-Layer Attention 2.0): 레이어 축의 희소화

DeepSeek는 토큰과 시퀀스 축 압축을 넘어, 인접 레이어 간의 유사성을 활용해 레이어 축을 압축한다. CSA2는 세 가지 모드로 동작하며 메모리와 연산을 최적화한다.

  • Full Mode: 신규 Main KV 생성 및 인덱서 기반 Top-K 탐색 수행.
  • Reindex Mode: 이전 레이어의 Main KV를 공유하되, 쿼리(Q)만 새로 생성하여 스코어링 재수행.
  • Reuse Mode: Main KV와 탐색된 Top-K 인덱스까지 완전히 공유. 이러한 계층적 공유는 HBM 대역폭 점유를 줄여 서빙 밀도(Serving Density)를 높이는 데 결정적 역할을 한다.
Hierarchical Sparse Indexer: O(N) 병목의 해소

1M 컨텍스트 환경에서 전체 토큰을 스캔하는 비용은 새로운 $O(N)$ 병목이 된다. V4.1은 첫 번째 Full 레이어에서 16,384개의 고정 후보군(Candidate pool)을 생성하고, 후속 Reindex 레이어들은 이 안에서만 탐색하도록 제한했다. 그 결과, 컨텍스트를 256배(4K → 1M) 확장했음에도 싱글 토큰 디코드 FLOPs 증가는 단 25% 수준으로 억제되었다.

3. 아키텍처 혁신 II: 메모리 계층 및 저장 용량의 한계 돌파

KV Cache 압축 수치 분석

DeepSeek-V4.1은 하드웨어 HBM 용량 한계를 정면으로 돌파하기 위해 Entry, Sequence, Layer 축을 동시 압축했다.

모델 버전 1M 컨텍스트 기준 KV Cache 크기 (토큰당) V4.1 대비 비율
DeepSeek-V1 약 389,000 bytes/token 약 437배
DeepSeek-V4-Flash 약 3,560 bytes/token 약 4배
DeepSeek-V4.1 890 bytes/token 1 (기준)
SWA Bounded Replay: 근사 컴퓨팅의 도입

SSD 기반 Persistent 캐시 용량을 줄이기 위해 수학적 동일성 대신 '출력 품질의 불변성'을 선택했다. 전체 Sliding Window Attention(SWA) 상태를 저장하지 않고 마지막 128 토큰만 Replay하여 상태를 근사적으로 복원한다. 이는 정밀한 수학적 복원 비용을 포기하는 대신 시스템 복잡도와 저장 비용을 획기적으로 낮춘 실용적 Breakthrough이다.

Persistent KV 및 메모리 계층화

Persistent 캐시를 V4 대비 1/8로 줄인 비결은 Global KV의 1/4 압축과 SWA 캐시의 완전한 제거에 있다.

  • Global KV: 장기 재사용을 위해 SSD에 72시간 이상 유지 (Episodic Memory).
  • SWA KV: 단기 세션용으로 Host DRAM에서 짧은 TTL(Time To Live)로 관리 (Working Memory). 이는 LLM이 단순한 신경망을 넘어 CPU와 유사한 '계층형 메모리 시스템'으로 진화했음을 시사한다.
FP4 Main KV

메인 KV 캐시에 FP4 QAT를 적용하여 메모리 풋프린트를 최소화했다. 이는 하드웨어의 FP4 가속 여부와 무관하게 HBM 점유량을 줄여, 동일 하드웨어에서 더 많은 동시 사용자(Session)를 수용하기 위한 전략적 선택이다.

4. 지능 및 메모리 확장: Engram과 차세대 학습 전략

Engram (Conditional Memory Access)

196B 파라미터 규모의 Engram은 연산과 암기를 분리한다. n-gram 해싱 기반의 Sparse Embedding Table 룩업 방식을 채택하여, 매 토큰마다 행렬 곱 연산을 수행하는 대신 필요한 지식만 조건부로 액세스한다. RDMA 프리페치를 통해 Host 메모리에서 병렬적으로 데이터를 가져옴으로써 연산 비용 증가 없이 지식 용량만 확장하는 데 성공했다.

Sparse-from-scratch Training

V4.1은 Dense-attention 워밍업 없이 64K 컨텍스트에서 scratch부터 Sparse Attention 학습을 시작하여 총 45T 토큰을 소화했다. 이는 모델이 초기부터 정보의 희소 라우팅을 전제로 표현(Representation)을 학습했음을 의미하며, 추론 시의 효율성이 학습 단계의 아키텍처 설계와 직결됨을 보여준다.

Multimodal Routing

이미지 토큰과 텍스트 토큰의 분포 차이를 고려하여 모달리티별 라우팅 보정(Correction bias) 기법을 적용했다. 이는 특정 전문가(Expert)에게 이미지 토큰이 편중되어 텍스트 처리 능력이 왜곡되는 현상을 방지하고 균형 잡힌 멀티모달 지능을 구현하기 위함이다.

5. 시스템 엔지니어링 및 에이전트 인프라 (Engineering Advances)

Single-Pass mHC: 대역폭 효율의 극대화

Mega-mHC 융합 커널을 통해 Residual update부터 FP8 변환까지의 과정을 단일 커널에서 처리한다. 활성화 메모리 트래픽을 기존 대비 절반으로 줄여 이론적 하한선에 도달했으며, 이는 HBM 대역폭이 병목인 대규모 서빙 환경에서 실질적인 처리량(Throughput) 향상을 견인한다.

DSpark 및 Reasoning Effort Control
  • DSpark: 백본 학습과 분리된 별도의 3개 레이어 Transformer 블록으로 구성된 추측 디코딩 시스템이다. 시스템 부하에 따라 검증 길이를 동적으로 조정한다.
  • Reasoning Effort Control: RL 단계에서 conditioning signal($b \in [1,100]$)을 부여하여, 모델이 주어진 예산 내에서 탐색과 검증의 수준을 스스로 결정하도록 학습시킨다. 이는 서비스의 특성에 따라 추론 비용과 품질을 유연하게 조절할 수 있는 Knob을 제공한다.
DSec (DeepSeek Elastic Compute)

수백만 규모의 에이전트 샌드박스를 위해 커스텀 스케줄러를 도입했다. 강한 일관성 대신 최종 일관성(Eventual consistency) 전략을 채택하여 관리 효율을 극대화했다. 특히 단일 노드당 컨테이너 밀도를 기존 1,000개에서 2,500개로 확장하며 서빙 밀도를 2.5배 향상시킨 점은 상업적 에이전트 인프라 구축에 있어 중대한 진전이다.

6. 성능 평가 및 한계점: 수치 중심 분석

벤치마크 결과 기술
  • 코딩 및 지능: HumanEval(79.4), BigCodeBench(60.6) 등에서 유의미한 성능 향상을 기록했다.
  • 에이전트 역량: DeepSWE v1.1(74.2%), Terminal-Bench 2.1(90.6%)로 급격한 상승을 보였다.
  • 롱 컨텍스트 (LongBench-V2): V4.1-Flash는 45.2점을 기록하며 V4-Flash(44.7) 대비 소폭 향상에 그쳤다. 이는 V4.1의 혁신이 '추론 품질의 수직 상승'보다는 '장문 문맥 유지의 경제적 실현'에 집중되어 있음을 방증한다.
Frontier Capability Parity 부인

벤치마크 점수 일치가 실제 지능의 완전한 대등을 의미하지는 않는다.

  • Terminal-Bench 4.0: V4.1-Flash(31.2) vs Opus-5(51.8) / GPT-5.6 Sol(39.9)
  • HLE: V4.1-Flash(36.8) vs Opus-5(56.3) / GPT-5.6 Sol(44.5) 위 수치에서 보듯, 고난도 과학적 추론 및 장기 호라이즌(Long-horizon) 문제에서는 여전히 폐쇄형 프론티어 모델과의 격차가 존재한다.

7. 결론 및 사후 갱신 기준

DeepSeek-V4.1은 LLM이 정적인 신경망에서 '동적 메모리 계층 컴퓨팅 시스템'으로 전환되는 분기점을 상징한다. 모든 축(토큰, 시퀀스, 레이어, 정밀도, 캐시)에서 희소성과 재사용을 적용함으로써, 1M 토큰 규모의 에이전트 워크로드를 상업적으로 실현 가능한 비용 구조 내로 편입시켰다. 본 모델은 파라미터 수보다 KV bytes/token, prefill FLOPs 등 시스템 효율성 지표가 모델의 경쟁력을 결정하는 새로운 시대를 예고하고 있다.

향후 본 보고서의 결론을 갱신해야 할 기준:

  1. 장문 품질(Long-form Quality): 극도로 효율화된 희소 구조가 실제 장기 추론 과정에서 정보 손실이나 문맥 붕괴를 야기하는지 여부.
  2. 극단 입력 Robustness: CSA2 및 Bounded Replay의 근사 연산이 매우 복잡하거나 이례적인 엣지 케이스에서 실패할 가능성.
  3. 재현 가능한 비용 자료: 실제 상업적 운영 데이터 확보를 통해, 토큰당 TCO 절감 수치가 이론적 기대치와 일치하는지 확인.

출처 한계와 철회 기준

본 결론은 공유 답변의 분석에 한정된다. 정식 기술 보고서·모델 카드·재현 가능한 serving benchmark에서 KV bytes/token, prefill FLOPs/token, cross-layer reuse, persistent-cache 절감, long-context 품질이 다르게 확인되면 평가를 갱신한다. 특히 장문 품질, CSA2 sparse selection, Bounded Replay의 극단 입력 robustness, 실제 동시 사용자 비용이 반증되면 “서비스 아키텍처 breakthrough”라는 결론을 축소하거나 철회한다.
