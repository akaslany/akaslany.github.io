MiMo-V2.6 기술 보고서 심층 분석: 자기개선(Self-Improvement)을 위한 강화학습 계산 확장 전략

1. 서론: MiMo-V2.6의 목표와 핵심 아키텍처 토대

보고서 저자들의 주요 주장 요약 MiMo-V2.6 시리즈(Pro 1.02T, Flash 310B)는 모델이 스스로 성능을 향상시키는 **재귀적 자기개선(Recursive Self-Improvement, RSI)**의 비전을 실현하기 위해 설계되었습니다. 저자들은 모델 지능의 경계를 확장하기 위한 핵심 동력으로 **강화학습(RL) 계산 규모의 확장(Scaling RL Compute)**을 제시합니다. 대규모 에이전트 과업에서 발생하는 복잡한 궤적과 다층적 피드백 신호를 처리하기 위해 인프라, 환경, 그리고 평가자(Grader)를 시스템적으로 고도화하는 것이 본 보고서의 핵심 아키텍처적 지향점입니다.

Hybrid-SWA 아키텍처 상세 MiMo-V2.6은 전역 문맥(Global Context)의 보존과 계산 효율성 사이의 절충점을 찾기 위해 하이브리드 희소 MoE(Hybrid Sparse Mixture-of-Experts) 트랜스포머 구조를 채택했습니다. 이 구조는 국소적 관계를 포착하는 Local Sliding Window Attention(SWA) 블록과 전역 정보를 통합하는 Global Attention(GA) 블록을 교차 배치합니다. 이러한 설계는 윈도우 경계를 넘어서는 정보 교환을 가능하게 하면서도, 고해상도 처리 시 발생하는 연산 비용을 획기적으로 낮추는 이점을 제공합니다.

2. RL 단계 이전의 준비: 사전 중간학습(Mid-training) 및 최적화

에이전트 중심 중간학습 사전 학습(Pre-training)과 강화학습 사이의 가교 역할을 하는 에이전트 중심 중간학습(Agent-centric Mid-training) 단계를 도입했습니다. 코딩, 사무, 시각적 설계 등의 실제 에이전트 궤적과 고품질 멀티모달 데이터 혼합물을 학습함으로써, 모델이 이후 RL 단계에서 더 효과적인 문제 해결 경로를 발견할 수 있는 '탐색 공간(Exploration Space)'을 사전에 확보했습니다.

Muown 옵티마이저의 도입 대규모 배치 학습 시 AdamW의 데이터 효율성 저하를 극복하기 위해 Muown 옵티마이저를 도입했습니다. Muown은 행렬 구조 가중치 업데이트를 직교화하는 Muon 알고리즘에 행렬 행 정규화(Row-norm control) 기능을 추가하여 스펙트럼 노름(Spectral-norm) 표류를 억제합니다.

  • 최적화 상세: Muon 컴포넌트는 **10회의 Newton-Schulz 반복(iterations)**과 Nesterov 모멘텀을 사용하여 업데이트 정밀도를 높입니다.
  • 혼합 전략: 은닉층 가중치에는 데이터 효율성이 높은 Muown을 적용하고, 임베딩 및 MoE 라우터에는 AdamW를 유지합니다. 이는 Muown의 행렬 기반 업데이트가 희소 라우팅 논리(Sparse routing logic)에는 지나치게 공격적일 수 있어 학습 안정성을 보장하기 위함입니다.

컨텍스트 확장 중간학습은 단계적으로 진행되었습니다. 초기 256K 컨텍스트에서 대부분의 계산을 수행한 후, 최종 단계에서 1M(100만) 토큰까지 확장하여 장기 추론 및 에이전트 기억 능력을 극대화했습니다.

3. 강화학습 계산의 3차원 확장 전략

제1차원: 계산 규모 및 처리량 확장
  • 대규모 배치 처리: 스텝당 1,568개의 프롬프트 배치를 사용하며, 그룹 크기($G=16$)를 포함해 스텝당 약 2.7B~3.7B 개의 토큰을 소비합니다.
  • 자원 포화 전략: 1M 컨텍스트 환경에서 GPU 자원 활용을 극대화하기 위해 비동기 학습(Asynchronous training) 및 **부분 롤아웃(Partial rollout)**을 사용합니다. 특히 롤아웃 시 **산술 연산 강도(Arithmetic intensity)**를 높게 유지하여 HBM 점유율과 GPU 연산 성능을 최대로 끌어올립니다.
제2차원: 환경 및 하네스(Harness)의 다양화
  • 4대 도메인: 코드(Code), 일반 사무(General), 비전(Visual), 사이버 보안(Cyber).
  • 미니 하네스(Mini-harness): 복잡한 프로덕션 하네스 대신 독립적으로 구성 가능한 최소 단위의 에이전트 루프를 사용하여 다양한 상호작용 메커니즘을 학습에 통합했습니다.
제3차원: 평가자(Grader) 계산의 확장

단순 이진 피드백을 넘어, 복잡한 장기 과업에서 정밀한 보상 신호를 제공하기 위해 **에이전트 기반 평가자(Agentic Grader)**에 더 많은 계산 자원을 투입합니다. 이는 해결책의 정답 여부뿐만 아니라 해결 과정의 효율성까지 평가에 포함합니다.

4. 혁신적 보상 체계: Groupwise Agentic Grading

GRS (Groupwise Reward Synthesis)

오프라인 롤아웃 비교를 통해 생성된 과업별 루브릭을 기반으로 합니다.

  • 점수화: 구현 품질($S_{sol}$)과 문제 해결 행동($S_{beh}$)을 개별 점수화하여 최종 보상을 산출합니다(Eq. 2: $R_i = R_test_i \cdot S_{sol,i} \cdot S_{beh,i}$).
GAR (Groupwise Advantage Redistribution)

온라인에서 동일 그룹 내 궤적을 실시간 비교하여 이득(Advantage)을 재분배하는 메커니즘입니다.

  • 재분배 로직 (Eq. 3): 고품질 해결책에 양(+)의 이득을 더 많이 배분하기 위해 **재분배 계수($\lambda$)**를 사용합니다. 이는 낮은 품질의 패스(Pass)를 다운웨이트(Downweight)하되, 전체 긍정적 이득의 총합을 보존하여 엔트로피 붕괴를 방지합니다.
효과 분석 (Figure 8 근거)
  • GAR 적용 시: 턴(Turn) 수와 토큰 길이가 안정적으로 유지되며, 학습 후반부까지 통과율(Pass rate)이 지속 상승합니다.
  • GAR 미적용 시: 통과율을 높이기 위해 모델이 예외 처리 중복, 과도한 검증 로직 등 불필요하게 긴 토큰을 생성하며 효율성이 급감합니다.

5. 대규모 RL 인프라: 혼합 과제(Mixed-task) 에이전트 RL

Payload Porter를 통한 데이터 관리 수만 개의 시퀀스를 처리하기 위해 제어 평면(Metadata)과 데이터 평면(Payload)을 분리했습니다.

  • 구조: Ray actors와 TransferQueue를 기반으로 작동하며, 토큰 ID, MoE 라우팅 기록 등의 대규모 페이로드를 Ray object store에 분산 저장하여 드라이버 노드의 병목을 제거합니다.

Harness Pool 및 메모리 관리

  • 멀티테넌트 환경: 고정된 수의 호스트 액터 내에서 여러 에이전트 루프를 실행하는 구조를 통해 효율성을 높였습니다.
  • 계층적 캐싱: **HBM(GPU 메모리)**과 Pinned Host Memory를 교차 사용하는 계층적 KV 캐시 관리를 통해 1M 컨텍스트 환경에서도 지연 없는 추론을 지원합니다.

추론 가속 및 일관성

  • DFlash (Speculative Decoder): RL에 최적화된 FP8 DFlash를 통해 10.3% 높은 노드당 처리량과 **31.3% 향상된 평균 수용 길이(Accepted length)**를 달성했습니다.
  • R3 및 Top-p 재현: MoE 전문가 인덱스(R3)와 샘플링 후보군 비트맵을 기록하여 학습과 추론 엔진 간의 수치적 정렬을 보장합니다.

6. 학습 안정성 및 안전 보장 메커니즘

MoE 라우터 동결 (Router Freezing) 학습 초기 라우터 드리프트로 인한 **부하 붕괴(Load-collapse)**를 방지하기 위한 조치입니다(Figure 11).

  • 효과: 라우터 미동결 시 변동계수(CV)가 2.0으로 급증하고 피크 부하가 16배까지 치솟으나, 동결 시 CV 0.7, 피크 부하 5.5배 수준으로 전문가 부하가 균등하게 유지됩니다.

보상 해킹(Reward Hacking) 방어

  • 사전 방어 (Environment Scrubbing): 솔루션 유출 방지를 위해 빌드 로그, 검증기 출력, 잔여 패치(Residual patches), Git 기록을 완전히 제거합니다. 네트워크 격리 후 Hack Agent를 투입하여 취약 경로를 선제 차단합니다.
  • 학습 중 방어: 오프라인 궤적 감사를 통해 해킹이 확정된 샘플의 보상을 즉시 0으로 초기화합니다. 이를 통해 해킹 감지율을 2% 미만으로 관리했습니다.

7. 벤치마크 결과 및 실패 사례 분석

성능 요약

  • DeepSWE v1.1: Pro(71.9), Flash(67.9)로 업계 최고 수준 달성.
  • AutomationBench: Pro(53.1), Flash(52.3)로 뛰어난 워크플로 수행 능력 입증.

실패 사례 분석 (Figure 12 근거)

  • Pro 모델의 주요 실패: Grader 노드의 네트워크 도달 불능(Unreachability) 문제.
  • Flash 모델의 주요 실패: 긴 시퀀스 패킹 시 발생하는 CPU OOM (Driver failure). 이는 호스트 메모리 용량을 초과하는 데이터 볼륨으로 인해 발생했습니다.
  • 공통 실패: Predictive Rollout Dispatch 과정에서의 길이 추정 오류로 인한 KV pool 고갈 및 MoE 불균형에 의한 GPU OOM.

MOPD2 RL 이후, 검증이 어려운 영역으로 능력을 확장하기 위해 Prefix-Conditioned OPD를 적용했습니다. 이는 고품질 궤적의 접두사(Prefix)로부터 학생 모델이 직접 답변을 생성하게 하여 학습 효율을 높입니다.

8. 결론

MiMo-V2.6은 대규모 강화학습 계산 확장을 통해 에이전트 지능의 새로운 기준을 제시했습니다. Hybrid-SWA 아키텍처와 Muown 옵티마이저, 그리고 혁신적인 그룹 단위 평가 체계는 모델이 단순 정답을 넘어 효율적이고 정교한 문제 해결 행동을 체득하게 함으로써 재귀적 자기개선의 실질적 가능성을 증명했습니다.
