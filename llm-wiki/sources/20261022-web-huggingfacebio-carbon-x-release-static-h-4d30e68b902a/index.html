1. 개요 (Overview)

Carbon-X는 게놈 DNA 서퀀스에 대한 정밀한 이해 및 생성 역량을 자연어 처리 능력과 단일 모델 내에서 결합하기 위해 개발된 140억 파라미터(14B) 규모의 오픈형 생물학 언어 모델이다. 기본 아키텍처로 Qwen3-14B 디코더를 채택하였으며, 연구자 커뮤니티가 자체 하드웨어 인프라에서 제약 없이 검증하고 확장할 수 있도록 Apache 2.0 라이선스로 전면 공개되었다. 이러한 완전한 오픈소스 배포 방식은 외부 Cloud API 전송 시 발생할 수 있는 보안 우려를 완벽히 해소하여, 미발표 유전체 데이터나 민감한 환자 게놈 정보를 연구자의 온프레미스(On-premise) 환경 내에서 안전하게 분석할 수 있는 기반을 제공한다.

본 모델의 개발 목적은 기존 자연어 처리 대형 언어 모델(LLM)과 게놈 기초 모델(Genomic Foundation Model) 간에 존재하던 고유한 기능적 파편화를 극복하는 데 있다. 기존의 문헌 기반 LLM은 생물학적 개념이나 논문 내용을 텍스트로 설명하는 데는 탁월하지만, 원시 DNA 서퀀스 자체를 직접 입력받아 해석하거나 단일 베이스 변이가 유도하는 분자생물학적 영향을 정밀하게 예측하는 데는 구조적 한계를 보였다. 반면 Carbon-3B와 같은 기존 DNA 전용 게놈 모델은 서퀀스 점수화, 다음 베이스 예측, 변이 효과 평가 등 정량적 연산에는 강점을 보였으나, 추론 결과에 대한 이유를 자연어로 설명하거나 연구자의 복합적인 질의에 응답하는 대화형 인터페이스를 제공하지 못했다. Carbon-X는 단일 트랜스포머 백본 내에서 원시 게놈 데이터 학습과 자연어 지시 이행 능력을 유기적으로 통합함으로써 이 두 영역 간의 단절을 성공적으로 연결하였다.

본 연구 및 개발 프로젝트는 Hugging Face, Zhongguancun Academy, 그리고 Telethon Institute of Genetics and Medicine / University of Naples "Federico II"의 공동 연구팀에 의해 수행되었다. Carbon-X는 텍스트 토큰과 DNA 서퀀스 토큰을 단일 임베딩 공간에서 공존시키는 다중 모달리티(Multi-modality) 하이브리드 아키텍처를 구현함으로써, 단일 모델만으로 게놈 서퀀스 질의응답, 변이 효과 예측, 신규 DNA 서퀀스 생성 과제를 동시에 수행할 수 있는 프론티어급 생물학 인공지능을 완성하였다.

2. 주요 논점 (Key Arguments)

2.1. 언어 모델과 DNA 서퀀스의 통합 아키텍처

기존의 모달리티 통합 시도(예: BioReason)가 별도의 DNA 인코더와 언어 모델 디코더를 연결하는 교차 주의(Cross-attention) 또는 병합 방식을 취했던 것과 달리, Carbon-X는 단일 14B 디코더 백본(Qwen3-14B) 내에서 DNA 서퀀스와 자연어 텍스트를 동일한 토큰 집합으로 직접 처리하는 단순화된 하이브리드 구조를 도입하였다.

  • 하이브리드 토크나이저(Hybrid Tokenizer): 기존 Qwen3의 BPE(Byte-Pair Encoding) 어휘집에 4,096개의 6-mer(6개 베이스 단위) DNA 토큰과 서퀀스 경계를 명시하는 특수 토큰(<dna>, </dna>), 그리고 부분 서퀀스 표현을 위한 전용 토큰을 추가 확장하였다. 이를 통해 DNA를 일반 텍스트 토크나이저로 무작위 분절할 때 발생하는 불규칙성을 배제하고, 모든 DNA 서퀀스에 일관된 정보 표현력을 부여하였다.
  • 공유 임베딩 매트릭스(Shared Embedding Matrix): 자연어 텍스트 토큰과 새롭게 추가된 DNA 6-mer 토큰은 투과적인 공유 임베딩 매트릭스를 거쳐 Qwen3-14B 트랜스포머 레이어로 전달된다. 입출력 과정에서 자연어와 DNA 토큰이 자유롭게 교차할 수 있어, 모델은 자연어로 입력된 질의에 대해 DNA 서퀀스를 직접 생성하거나, DNA 서퀀스 입력에 대해 심층적인 자연어 설명을 출력할 수 있다.
  • 토큰 효율성 및 압축 효과: 6-mer 토크나이징 기법을 채택함으로써 기존 Qwen3 BPE 토크나이저가 동일한 DNA 서퀀스를 표현할 때 대비 토큰 소비량을 약 3분의 1 수준으로 대폭 절감하였다. 이는 제한된 컨텍스트 윈도우 내에서 훨씬 더 긴 유전체 영역을 효율적으로 처리할 수 있게 하는 핵심적 기술 기반이 된다.

2.2. 3단계 모델 학습 방법론 (Midtraining, SFT, RL)

Carbon-X의 고성능 구축 과정은 Qwen3-14B 베이스 모델을 출발점으로 하여 중간 사전학습(Midtraining), 감독 미세조정(SFT), 강화학습(RL)으로 이어지는 정밀한 3단계 파이프라인을 거쳐 완성되었다.

[Qwen3-14B Base] 
       │
       ▼
[1단계: Midtraining (300B Tokens)] ──► DNA 모달리티 이식 & 텍스트 망각 차단
       │
       ▼
[2단계: SFT (Supervised Fine-Tuning)] ──► 결정론적 검증기 기반 환각 제거 데이터 학습
       │
       ▼
[3단계: RL (Reinforcement Learning)] ──► 검증 가능한 보상 신호 기반 벤치마크 점수 도약
1. 중간 사전학습 (Midtraining) 및 기술적 실패 경험(Ablations) 분석
  • 데이터 구성: 총 3,000억(300B) 토큰의 데이터 믹스가 활용되었다. 이는 OpenGenome2 및 GENERator 기반 원시 DNA 서퀀스(Carbon-3B 데이터 믹스), 웹/PDF에서 수집한 생물학 및 일반 영어 텍스트, 지시 이행 능력 보존을 위한 대화 데이터, 논문/포럼 추출 DNA-텍스트 쌍, 그리고 Gemini를 활용해 RefSeq 주석 서퀀스를 분석한 합성 데이터로 정교하게 배합되었다.
  • 학습률(LR) 충돌과 시도된 절차적 실패들(Negative Results): 연구진은 초기 Qwen3-4B 코퍼스 실험 과정에서 DNA 모달리티의 빠른 습득을 위해 높은 학습률을 적용할 경우, 기존에 보유하고 있던 영어 언어 능력 및 일반 추론 능력에 치명적인 망각(Forgetting) 현상이 발생한다는 심각한 계층 간 그래디언트 충돌을 발견하였다. 연구진은 이 문제를 해결하기 위해 다음과 같은 5가지 보완적 기술 시도를 전개했으나 모두 실패를 경험했다:
    1. DNA 임베딩 동결 학습: 임의로 초기화된 DNA 임베딩 매트릭스만 먼저 학습시키고 트랜스포머 바디(Body)를 동결(Freeze)시켰으나 언어 성능과 DNA 이해의 통합에 실패함.
    2. 분리 학습률 적용: 임베딩 레이어와 트랜스포머 바디에 서로 다른 학습률 스케줄을 적용했으나 상호 간섭을 차단하지 못함.
    3. 충돌 레이어 보호: DNA와 영어 그래디언트가 충돌하는 특정 레이어를 동결하거나 업데이트를 제한했으나 전체적인 표현력 저하 유발.
    4. 전문가 모델 병합: DNA 전용 4B 모델과 영어 전용 4B 모델을 가중치 병합(Merging)했으나 모달리티 간 협험 능력이 발휘되지 않음.
    5. 영어 재생(Replay) 데이터 증량: 학습 데이터 내 영어 비중을 극단적으로 늘렸으나 DNA 학습 속도가 정체되는 한계 직면.
  • 최종 해결책: 연구진은 실험적 검증을 통해 유일한 해결책이 **"더 큰 모델 규모(14B) + 낮은 학습률 + 더 긴 학습 시간"**이라는 결론에 도달했다. 14B 규모에서는 낮은 학습률에서도 지속적인 학습을 통해 영어 능력을 완벽히 보존하면서 DNA 능력을 안정적으로 고도화할 수 있었다. 아울러 Warmup-Stable-Decay 형태의 코사인 감쇠(Cosine Decay) 스케줄은 학습 구간 대부분에서 높은 학습률을 유지시켜 망각을 악화시키므로, 최종 학습에서는 이를 신중히 제어하였다.
  • RL과의 유기적 연계성: Base Qwen3-14B 모델에 중간 사전학습 없이 직접 RL을 적용했을 때는 FrontierVEP 벤치마크 성능이 무작위 예측 수준인 50%를 벗어나지 못했으나, Midtraining을 거친 체크포인트에 RL을 적용하자 50%의 한계를 돌파하고 가파른 성능 향상을 기록하였다.
2. 감독 미세조정 (SFT)
  • 환각(Hallucination) 차단: 기존 상용 프론티어 모델 기반 증류(Distillation) 데이터나 자가 증류(Self-distillation) 데이터를 활용할 경우, 모델이 존재하지 않는 DB 참조를 지어내거나 근거 없는 유전자 기능을 주장하는 환각 현상이 SFT 데이터셋에 유입되는 문제가 발생했다.
  • 결정론적 검증기(Deterministic Verifiers): 연구진은 도메인 전문가들과 협력하여 입력된 DNA 서퀀스 원본과 모델의 서술 내용을 직접 대조 검증하는 규칙 기반의 결정론적 검증 시스템을 구축하였다. 입력 서퀀스에 의해 엄격하게 정당화되는(Grounded) 응답만을 SFT 데이터로 채택함으로써, 자가 증류 데이터 대비 확연히 뛰어난 신뢰성과 높은 FrontierVEP 점수를 확보하였다.
3. 강화학습 (RL)
  • 검증 가능한 보상(Verifiable Rewards): SFT를 거친 모델을 바탕으로 변이 효과 예측, DNA 질의응답, 서퀀스 복원, 서퀀스 위치 추정 등 결과의 정답 여부를 수학적·생물학적으로 명확히 판별할 수 있는 과제들에 대해 작업별 검증기(Task-specific Verifiers)가 즉각적인 보상 신호를 제공하는 RL 학습을 수행하였다.
  • 성능 도약: RL 도입 결과 5개 DNA 벤치마크 전반에서 뚜렷한 성능 향상이 나타났으며, 특히 변이 효과 예측 분야인 BioReason Non-SNV에서 SFT 대비 약 20%p, BioReason Coding에서 약 10%p라는 폭발적인 점수 상승을 달성하였다.
2.3. 성능 평가 및 타 모델 대비 비용 효율성

Carbon-X는 대표적인 5대 DNA 평가 벤치마크(BioReason Coding, BioReason Non-SNV, GenomeQA, NextBase, FrontierVEP) 전체 평가에서 평균 **66.7%**의 점수를 기록하였다. 이는 사전학습 베이스 모델인 Qwen3-14B(39.7%) 대비 무려 27점 상승한 성과이며, 현존 최상위 상용 모델인 GPT-6.1 Sol(평균 67.5%)에 육박하는 프론티어급 지능 수준이다.

추론 효율성 측면에서 Carbon-X의 진가가 드러난다. H200 GPU 연산 비용(시간당 $5)을 기준으로 동일한 벤치마크 문제당 추론 비용을 산정한 결과, Carbon-X는 GPT-6.1 Sol 대비 추론 비용을 무려 1,800분의 1 수준으로 절감한다. 또한 평가에 사용된 모든 벤치마크 데이터셋은 데이터 오염으로 인한 성능 과대를 방지하기 위해 **DNA 중복(DNA overlap), 텍스트 중복(Text overlap), 상렬성 검사(Homology checks)**의 3단계 데이터 정제(Decontamination) 프로세스를 엄격히 거쳤음이 확인되었다.

[케이스 스터디] NF1 c.6007-2A>G 유전자 변이 분석 정밀 비교

Carbon-X의 변이 효과 예측 정밀도와 자연어 설명 능력의 우수성은 인간 유전체 내 신경섬유종증 관련 핵심 변이인 NF1 c.6007-2A>G 분석 사례(Figure 4)에서 명확히 실증된다.

  • 입력 조건: 8,192 베이스 길이의 인간 DNA 영역 내 단일 A→G 변이 서퀀스 제시.
  • Carbon-X의 수행: 해당 변이를 병원성(Pathogenic)으로 정확히 판별함과 동시에, "해당 단일 베이스 변화가 스플라이스 부위(Splice site)의 필수적인 AG 서퀀스를 교란하기 때문"이라는 분자생물학적 원인까지 자연어로 정밀하게 설명함.
  • 타 프론티어 모델 비교: 평가 대상 최상위 상용 모델 중 **GPT-6.1 Sol(Max effort)**만이 정답과 올바른 논리를 제시했다. Claude Opus 5.5는 병원성 라벨은 맞혔으나 잘못된 생물학적 근거를 제시(Right label for wrong reason)하였고, Gemini 4 Argon을 비롯한 나머지 상용 모델들은 'Pathogenic'이 아닌 'Benign(무해함)'으로 오판하거나 안전 필터에 의한 거부(Refusal), 또는 토큰 초과 오류를 일으키며 분석에 실패하였다.

  • GenomeQA: 유전자 조절 부위 등 생물학적 특징 식별 및 유기체 그룹 분류

2.4. 하위 에이전트(Sub-agent) 활용 및 로컬 배포
  • 전문 서브에이전트 연동 실험: Carbon-X는 단독 분석 모델 역할 외에도 범용 대형 언어 모델의 유전체 전문 서브에이전트(Sub-agent)로 구동될 수 있다. Python 코드 실행 환경이 부여된 상태에서 5개 벤치마크당 각 100개씩 총 500개의 질의에 대해 Carbon-X 상담을 필수화(Required consultation)하는 조건으로 에이전트 평가를 진행한 결과, Kimi K3 모델의 평균 지능 지수가 기존 49.4%에서 60.5%로 11.1%p 폭증하는 효과를 보였다.
  • 대규모 변이 분석의 압도적 경제성: 임상적 의미가 미확정된 ClinVar VUS(Variants of Uncertain Significance) 변이 240만 개를 전수 분석할 경우, 기존 프론티어 상용 API 모델을 사용하면 모델 및 추론 노력 설정에 따라 최소 $32,000에서 최대 $4,000,000에 달하는 막대한 비용이 발생한다. 반면 Carbon-X의 추론 연산을 활용할 경우 단 약 $300 수준의 컴퓨팅 비용만으로 분석을 완수할 수 있다.
  • 로컬 배포와 완전한 데이터 보안: Carbon-X는 경량화 엔진인 llama.cpp와 완전 호환되어 M 시리즈 칩셋이 탑재된 맥북(MacBook) 등 연구자의 로컬 하드웨어 단말에서 온프레미스로 구동할 수 있다. 미공개 연구 서퀀스나 환자의 유전체 정보 등 극도로 민감한 데이터를 외부 클라우드 서버로 송신하지 않고 자체 인프라 내에서 완벽한 보안을 유지하며 분석할 수 있는 결정적 이점을 제공한다.

5. 한계와 불확실성 (Limitations & Uncertainties)

소스 명시 한계점
  • 정밀한 서퀀스 좌표 연산 한계: 서퀀스 내 정확한 베이스 개수를 세거나, 게놈 좌표계를 완벽히 인식하고, 긴 서퀀스에서 특정 위치를 수정하는 편집 작업 시 오류(위치 혼동 및 잘못된 베이스 교체)가 발생할 수 있다.
  • 맥락 부족 시 환각(Hallucination) 발생: 입력 프롬프트 내에 서퀀스에 관한 충분한 주석이나 맥락 정보가 제공되지 않을 경우, 모델이 서퀀스의 명칭이나 생물학적 기능을 자의적으로 지어내는 환각 현상이 발생할 수 있다.
  • 짧은 DNA 과제 및 기초 생물학 문제의 열세: 짧은 단일 가닥 DNA 연습 문제나 교과서 수준의 일반 생물학 개념 질문에 대해서는 여전히 상용 프론티어 LLM이 우수한 대응력을 보인다.
  • 긴 DNA 서퀀스 생성 품질 저하: 모델이 새로 생성해야 하는 DNA 서퀀스의 길이가 길어질수록 출력물의 생물학적 일관성과 품질이 점차 저하된다.
  • 임상적 미검증: Carbon-X는 실제 의료 및 임상 현장에 직접 적용하기 위한 임상적 검증(Clinical validation) 과정을 거치지 않은 순수 연구 목적의 모델이다.
폐쇄형 API 모델의 거부율(Refusal) 현상 및 성능 폭락

상용 프론티어 API 모델(Gemini 4 Argon, Claude Opus 5.5 등)은 플랫폼 고유의 과도한 안전장치(Content filter stop) 작동으로 인해 정당한 연구 목적의 생물학 요청까지 바이오위험으로 오인하여 거부(Refusal)하는 심각한 문제를 드러낸다. 이는 벤치마크 측정 점수 폭락으로 직결된다.

  • Gemini 4 Argon의 사례: FrontierVEP 벤치마크에서 추론 노력을 높일수록(Low → High) 거부율이 급증하여 정밀도 점수가 기존 58.0%에서 38.0%로 20%p 폭락하였다.
  • Claude Opus 5.5의 사례: NextBase 서퀀스 생성 벤치마크에서 추론 노력을 최대화(Max reasoning)할 경우 안전 필터에 의한 거부율이 폭발적으로 상승하며, 점수가 17.7%에서 1.1%로 가혹하게 폭락하는 현상이 관찰되었다.

이중 용도(Dual-use) 및 안전성 조치
  • 바이오안보 데이터 필터링: 생물학적 위험 요소의 남용을 방지하기 위하여, 사전학습 데이터 구축 단계에서 진핵생물을 감염시키는 바이러스 게놈(Eukaryote-infecting viral genomes) 데이터를 DNA 데이터셋에서 엄격히 pre-exclusion(사전 제외) 처리하였다.
  • 위험성 평가 결과: 악용 가능성이 존재하는 유전자 편집 과제에 대해 Carbon-X를 다각도로 평가한 결과, 편집 신뢰성이 제한적인 수준이었으며 기존에 연구 현장에서 널리 쓰이는 결정론적 소프트웨어 도구 대비 추가적인 우위나 위협적 능력을 형성하지 않는 것으로 확인되었다.
미다뤄진 불확실성
  • Carbon-X 모델을 사용자가 추가 미세조정(Fine-tuning)하거나 타 외부 자율형 시스템과 결합하여 구동할 때 발생할 수 있는 잠재적 악용 위험에 대해서는 현재의 평가 체계로 완벽히 예측하기 어려우며, 향후 지속적인 연구와 모니터링이 요구된다.
