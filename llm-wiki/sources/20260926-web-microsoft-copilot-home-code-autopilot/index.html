1. 개요 및 차세대 Microsoft Copilot의 비전

본 보고서는 2026년 9월 25일, 마이크로소프트의 AI at Work 수석 마케팅 책임자(CMO)인 Jared Spataro가 공식 발표한 내용을 바탕으로 작성되었습니다. Jared Spataro 수석 부사장의 발표에 따르면, 마이크로소프트는 진화하는 현대의 업무 환경에 발맞추어 개인과 조직의 역량을 인간의 야망 수준으로 확장할 수 있도록 Microsoft Copilot을 플랫폼 차원에서 전면 재정의하고 있습니다. 이번 차세대 Copilot 발표의 핵심은 임직원들이 매일 사용하는 생산성 도구와 직접 구축·맞춤화·확장 가능한 차세대 AI 에이전트 역량을 단일 워크스페이스 내로 통합하는 데 있습니다.

차세대 Copilot 앱은 엔터프라이즈 업무 환경을 혁신할 세 가지 핵심 축을 중심으로 구성됩니다:

  • Home: 대화형 질의 응답(Chat)과 자율적 업무 위임(Cowork)이 하나로 결합되고, Office 앱의 실시간 생성 역량이 내장된 새로운 엔터프라이즈 업무 시작점
  • Code: 전문 개발자뿐만 아니라 현업 비즈니스 사용자도 자연어를 통해 로컬 및 클라우드 호스팅 솔루션을 안전하게 구축할 수 있는 환경
  • Autopilot: 단발성 프롬프트 대기 방식에서 벗어나 백그라운드에서 지속적·선제적으로 비즈니스 프로세스를 수행하는 자율형 디지털 팀원

[출시 단계 및 타임라인 요약] 발표 내용에 기반한 주요 기능별 제공 단계는 다음과 같습니다. 본 기능들은 현재 일반 제공(GA) 상태가 아니며, 단계별 접근 프로그램을 통해 순차적으로 확장됩니다.

  • Home: 향후 몇 주에 걸쳐 Frontier 프로그램을 통해 시범 출습(Rollout)이 시작될 예정입니다. (현재 GA 상태가 아님)
  • Code: 이번 달 말 Frontier 프로그램에 출시되며, 향후 몇 주 내 광범위한 접근이 가능해집니다. 올해 말 Microsoft 365 Premium 및 Pro 구독자를 대상으로 프리뷰(Preview)가 진행될 계획입니다.
  • Autopilot: 이번 달 말 프라이빗 프리뷰(Private Preview) 형태로 대상이 확대될 예정입니다.
2. 신규 Copilot 앱 핵심 기능 상세 분석
2.1. Home 및 Office in Copilot

Jared Spataro 수석 부사장의 발표에 따르면, Home은 회의, 채팅, 문서, 이메일, 애플리케이션, 에이전트 간을 수시로 전환해야 하는 현대 지식 노동자의 맥락 파악 시간을 단축해 주는 새로운 작업 센터입니다. 사용자는 최근 활동을 복기하고 Copilot이 추천하는 인텔리전트 과제를 확인하며 이전 작업을 즉시 이어받아 처리할 수 있습니다.

  • Home 및 라우팅 구조:

    • Chat (반응형/일상적 AI): 대화형 질의 응답 모드로, 빠른 정보 검색, 단발성 분석, 초안 작성 및 진행 상황 업데이트 확인에 최적화되어 있습니다.
    • Cowork (자율적 엔드투엔드 위임 과제): 사용자가 목표를 정의하면 RFP 답변서 작성, 제품 출시 키트 제작, 고객 브리핑 자료 작성, 재무 결산 패키지 준비 등 다단계의 복잡한 프로세스를 엔드투엔드(End-to-End)로 완결하여 고품질 결과물을 반환합니다.
    • 지능형 자동 라우팅 (향후 제공 예정): 사용자가 작업 모드를 직접 지정할 필요 없이 자연어로 요구사항을 입력하면, Copilot이 과업의 복잡도와 의도를 분석하여 Chat, Cowork, Code 중 최적의 모드로 작업을 자동 배정(Routing)합니다.

  • Office in Copilot 연동:

    • Word, Excel, PowerPoint의 서식 엔진과 편집 기능이 Home 인터페이스 내에 직접 내장되었습니다.
    • 외부 앱으로 맥락을 이동하거나 서식이 깨지는 현상, 파일 버전이 분산되는 문제 없이 Home에서 즉시 실시간 편집이 가능한 워크북, 문서, 발표 자료를 생성 및 수정할 수 있습니다.
    • 대화창 측면에서 결과물을 정교하게 미세 조정할 수 있으며, 동료를 @mention하여 초동 작업에 참여시키면 동료의 편집 내용이 Copilot 대화창과 Office 앱 간에 실시간 동기화됩니다.

  • Microsoft 365 주요 앱별 강화 기능:

    • PowerPoint: 기업의 브랜드 가이드라인을 자동으로 준수하며, 슬라이드 레이아웃 및 이미지 미세 조정, 맞춤형 조직 템플릿의 신속한 적용을 지원합니다.
    • Excel: Copilot 또는 다른 협업자가 수정한 변경 사항과 그 근거 추적 기능을 제공하며, 데이터 구조에 최적화된 시각화 차트를 제안합니다.
    • M365 Skills (전문 기술): Excel의 재무 전문 기술, Word의 법률 전문 기술 등 산업별/직무별 규준 지식을 앱 내로 직접 가져와 재사용 가능한 워크플로우로 표준화할 수 있습니다.
2.2. Code 및 Copilot Managed Runtime

Jared Spataro는 전통적인 지식 업무의 단위를 '문서, 스프레드시트, 프레젠테이션'의 3대 파일 체계로 정의하고, 차세대 업무 환경에는 Code라는 네 번째 단위가 추가되었다고 강조했습니다. Code는 비개발자도 자신의 업무 목적에 최적화된 소형 솔루션을 직접 제작하도록 지원합니다.

  • Code 기능의 핵심:

    • 아이디어, 데이터 추적기, 대화형 대시보드, 자동화 워크플로우를 자연어로 설명하면 Copilot이 적절한 아키텍처를 선택하여 앱을 구축합니다.
    • 데스크톱 위젯부터 데이터 탐색용 대시보드, 팀 단위 클라우드 호스팅 내부 앱까지 다양한 스케일로 생성이 가능합니다.
    • GitHub Copilot과 동일한 기반 기술로 작동하며, 테넌트 내의 격리된 샌드박스(Sandboxed) 환경에서 실행됩니다.
    • Microsoft IQ를 통해 기업 업무 맥락을 반영하고 플러그인을 자동 동기화합니다. 전문 개발자는 기존 GitHub Copilot 환경을 유지하면서 Copilot 플랫폼과의 연동성을 확장할 수 있습니다.

  • Microsoft Copilot Managed Runtime (엔터프라이즈 IT 아키텍처 관점):

    • M365 환경 내에서 코드가 안전하게 실행되도록 지원하는 차세대 호스팅 인프라입니다. (현재 프리뷰 제공 중이며, Code 내부에서도 접근 가능)
    • IT 거버넌스 및 비즈니스 민첩성 확보: 중앙 IT 통제가 미치지 않는 곳에서 발생하는 shadow IT 리스크(통제되지 않은 로컬 앱 개발)를 방지하는 동시에, 테넌트 격리 샌드박스를 통해 현업의 비즈니스 개발 민첩성을 완벽히 보장합니다.
    • Cowork, Code, Copilot Studio로 생성된 앱을 공통적으로 지원하며, 서드파티 및 전문 개발자(Pro-code) 앱에도 동일한 호스팅 인프라를 개방합니다.
2.3. Autopilot (구 Scout)

기존 프로젝트명 'Scout'에서 정식 명칭으로 확정된 Autopilot은 지속적이고 선제적으로 동작하는 조직의 '디지털 팀원(Digital Teammate)'으로 정의됩니다.

  • 주요 특징 및 비동기적 작동 메커니즘:

    • 이름, 역할, 목표를 부여받으면 프롬프트 입력을 기다리지 않고 백그라운드에서 자율적으로 업무를 지속합니다.
    • 클라우드 호스팅 기반으로 구동되므로, 사용자의 로컬 PC가 종료되거나 클라이언트 앱이 비활성화된 상태에서도 비동기적으로(Asynchrony) 백그라운드 구동이 유지됩니다.
    • 채널 감시, 쓰레드 팔로우업, 공급업체 검토 프로세스(일정 및 워크백 플랜 수립, 회의 준비, 파트너사 업데이트 요청 등)를 수일에 걸쳐 독자적으로 완료합니다.

  • 엔터프라이즈 보안 및 거버넌스:

    • 고객 테넌트 내에 전용 식별자(Identity), 메모리(Memory), 컴퓨팅(Compute), 워크스페이스(Workspace)를 보유합니다.
    • Microsoft IQ를 기반으로 조직의 실제 업무 규칙을 이해하며, Teams, Outlook, 채팅, 문서 내에서 일반 동료처럼 @mention으로 호출할 수 있습니다.
    • IT 관리자의 접근 권한, 감사(Audit), 보안 정책 및 거버넌스 지침을 엄격히 준수합니다.

[엔터프라이즈 아키텍처 관점의 핵심 요약]
차세대 Copilot 앱은 단순 대화형 인터페이스를 넘어 Copilot Managed Runtime을 기반으로 Shadow IT 보안 위험을 원천 차단하면서, 비개발자의 애플리케이션 구축(Code)과 비동기 자율 에이전트 구동(Autopilot)을 통제된 테넌트 환경 내에서 승인된 방식으로 흡수하는 아키텍처적 진화를 이루었습니다.

3. 기업 비즈니스 맥락 확장: Microsoft IQ 및 플러그인 생태계

Jared Spataro의 발표에 따르면, 엔터프라이즈 AI의 성패는 기업 고유의 데이터와 비즈니스 운영 맥락을 얼마나 깊이 있게 이해하고 활용하느냐에 달려 있습니다.

  • Microsoft IQ 중심의 데이터 컨텍스트 통합:

    • 마이크로소프트 스택 전반에 걸쳐 비즈니스 운영 방식과 기업 지식을 실시간 단일 뷰로 연결하는 엔터프라이즈 AI 전용 통합 인텔리전스 플랫폼입니다.
    • 엔터프라이즈 RAG/그라운딩의 단절 문제를 해결하기 위해 Microsoft Graph(비조직화 문서 및 대화 데이터), Fabric IQ(Power BI 시맨틱 모델), Dynamics 365(CRM/ERP 트랜잭션 데이터)를 하나의 실시간 맥락 레이어로 연결합니다.

  • 데이터 맥락 연동 상세:

    • Fabric IQ: Power BI 내 2,000만 개 이상의 시맨틱 모델 맥락을 Copilot과 연결합니다. 현재 Chat 및 Cowork 모드에서는 일반 제공(GA) 상태이며, Code 연동은 Frontier 프로그램을 통해 곧 제공될 예정입니다.
    • Dynamics 365 & Power Platform 결합: 영업 및 서비스 데이터(거래 이력, 지원 티켓 등)를 Copilot과 직접 연결합니다. 영업 담당자는 애플리케이션 전환 없이 제안서 작성 중 관련 트랜잭션 데이터를 문서에 즉시 불러올 수 있습니다. 향후 한 달간 공개 프리뷰(Public Preview)로 순차 출시됩니다.

  • 통합 플러그인 레지스트리 (Plugin Registry):

    • 마이크로소프트 공식, 파트너사, 기업 커스텀 플러그인을 단일 카탈로그로 통합 관리하는 신규 레지스트리가 도입됩니다.
    • IT 관리자는 플러그인을 중앙에서 검토 및 승인할 수 있고, 개발자는 1회 게시(Publish once)로 M365 전반의 모든 Copilot 접면에 확장 적용할 수 있습니다.
    • 현재 순차적으로 출시 중이며, 향후 몇 주 내 일반 제공(GA)될 예정입니다.

[데이터 맥락 관점의 핵심 요약]
Microsoft IQ는 조직 내에 산재된 분석 데이터(Fabric)와 실행 데이터(Dynamics 365)를 단일 지능형 레이어로 융합함으로써, AI 에이전트가 환각(Hallucination) 없이 정확한 비즈니스 맥락 위에서 작업할 수 있도록 보장합니다.

4. AI 비용 관리 및 빌링 모델 (AI FinOps)

발표에서는 일상적인 AI 작업(Reactive/Everyday AI)과 장시간 자율 실행되는 에이전트 작업(Autonomous Agentic Work)의 컴퓨팅 특성 차이를 명확히 구분하고, 이에 맞춘 요금 체계 및 IT 통제 역량을 공개했습니다.

과금 방식 및 아키텍처 비교
구분 사용자 구독 라이선스 (USL) 사용량 기반 과금 (UBB)
대상 작업 일상적 AI (Everyday AI)<br>- Chat, Word, Excel, PowerPoint, Outlook, Teams 내 질의응답, 단발성 초안 작성, 요약 장시간 실행 에이전트 작업 (Agentic Work)<br>- Cowork, Code, Autopilot 등 자율형 과제 및 첨단 프론티어 모델(Astra, Fable 등) 활용
비용 구조 고정 비용 (Fixed Cost)<br>- 예측 가능한 운영 비용(OPEX) 유지 사용량 기반 과금 (Usage-Based Billing)<br>- 비즈니스 가치에 직접 비례하는 정밀 비용 제어
핵심 기술 Auto 라우팅 엔진 적용<br>- 모든 요청의 정확도, 속도, 비용을 실시간 평가하여 최적 모델로 자동 라우팅 최상위 성능 모델 및 첨단 프론티어 모델 직접 선택 및 제어 가능
엔터프라이즈 빌링 제어 사용자 그룹별 라이선스 할당 및 모델 접근 범위 제한 API 기반 지출 한도 설정, 사용자 크레딧 승인 워크플로우 연동
  • Auto 라우팅 엔진의 역할:
    • USL의 핵심인 Auto 엔진은 고정 요금 체계 내에서 서비스 품질을 최적화하기 위한 마이크로소프트의 내부 오케스트레이션 레이어입니다. 사용자의 요청이 들어올 때마다 비용, 속도, 필요한 정확도를 실시간 평가하여 최상의 결과를 낼 수 있는 최적 모델로 자동 배정합니다.
AI FinOps (FinOps for AI) 주요 역량

조직이 AI 지출에 대한 가시성을 확보하고 투자가치(ROI)를 최적화할 수 있도록 AI FinOps 제어 역량이 대폭 강화되었습니다.

  • Agent 365 비용 관리 확장:
    • 비용 관리 범위를 기존 Cowork 및 Work IQ API 중심에서 Code 및 Copilot Managed Runtime으로 확장합니다. (10월 중 Copilot Studio 생성 에이전트 지원 예정)
  • IT 관리자 제어 역량:
    • API 기반 지출 정책 설정 및 조직 내 크레딧 요청의 기존 승인 워크플로우 연동을 지원합니다.
    • 사용자 그룹별로 접근 가능한 모델 패밀리를 제한할 수 있으며, 이 정책은 Auto 엔진이 자동 선택할 수 있는 모델 후보 범위에도 동일하게 적용됩니다.
  • 비즈니스 리더 및 최종 사용자 투명성:
    • 리더는 Cowork 성과 분석을 통해 어떤 과업이 가장 높은 가치를 창출하는지 분석하여 사용 확대를 결정할 수 있습니다.
    • 최종 사용자는 Copilot 내에서 자신의 실시간 크레딧 잔액, 사용 이력, 남은 한도를 직접 조회하여 주도적으로 AI 자원을 관리할 수 있습니다.

[비용 관리 관점의 핵심 요약]
고정가 형태의 USL(일상 작업)과 사용량 기반의 UBB(자율 에이전트)를 분리하고 Auto 엔진 및 API 지출 정책을 결합함으로써, IT 재무 관리자는 AI 도입 확장에 따른 비용 변동성을 예측 가능하게 통제할 수 있습니다.

5. 향후 공개될 신규 기능 프리뷰 (A Sneak Peek)

발표 하단에서는 향후 추가될 두 가지 주요 핵심 기능에 대한 예고가 포함되었습니다.

  • Today (Home 내 탑재 예정):

    • 메일, 일정, Teams 쓰레드, 회의, 할 일을 한곳에서 통합 관리하는 선제적·맞춤형 명령 센터입니다.
    • 단순히 알림 목록을 보여주는 차원을 넘어, 처리해야 할 작업을 선제적으로 준비(Pre-package)합니다. (예: 즉시 편집 가능한 초안 자동 작성, 변경될 일정 자동 제안, 맥락이 포함된 팔로우업 메일 대기 등)
    • 출시 일정: 10월 중 Copilot 내 프라이빗 프리뷰(Private Preview)로 시작되어, 향후 Outlook 및 Teams로 확대 적용될 예정입니다.

  • @Copilot in Teams:

    • Teams 채널, 그룹 채팅, 회의의 공유 맥락과 접근 권한을 파악하는 통합 에이전트 기능입니다.
    • 과거 대화 내용을 분석하여 특정 제품 결정이 내려진 이유나 의사결정 배경을 요약 제공합니다.
    • 의사결정이 제조, 패키징, 출시 일정 등에 미치는 영향을 파악하여 의존성, 담당자, 미결 사항, 결정 내용이 포함된 부서 간 검토 보고서를 자동 작성합니다.
    • 출시 일정: 이번 달 말 Teams 환경 내 프라이빗 프리뷰(Private Preview) 형태로 제공될 예정입니다.
6. 결론 및 종합 타임라인 요약

Jared Spataro 수석 부사장의 발표를 종합하면, 차세대 Microsoft Copilot은 단순히 질문에 답하는 보조 도구를 넘어 질의(Ask), 위임(Delegate), 앱 구축(Build), 자동화(Automate)를 단일 플랫폼에서 수행하는 종합 엔터프라이즈 AI 시스템으로 진화하고 있습니다. 기업은 Microsoft IQ와 강화된 AI FinOps 통제 기능을 통해 데이터 보안과 비용 효율성을 유지하면서 AI 도입 범위를 안전하게 확장할 수 있습니다.
