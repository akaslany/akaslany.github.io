1. Project Astra의 함의: 지각과 추론의 아키텍처적 격리

Google의 Project Astra는 비디오 프레임의 지속적 인코딩, audiovisual event timeline의 결합, 그리고 이를 효율적으로 캐시하여 회상하는 기술적 실증을 보여줍니다. 이는 고대역폭의 원시 비디오 데이터를 매 추론 단계마다 유지하는 대신, 이를 시간적으로 구조화된 이벤트로 압축하여 저장하는 것이 실무적으로 유용함을 입증합니다.

분석가적 견해: Astra는 '지각(Perception)'과 '상위 추론(Reasoning)'이 표현적으로 분리될 수 있음을 보여주는 사례이지, 시스템 내부의 모든 인지(Cognition)가 텍스트나 심볼로만 이루어진다는 증거는 아닙니다. 오히려 지각적 압축 이후의 추론 단계에서 어떤 표현(Representation)을 선택할 것인가에 대한 논의의 시작점이라 할 수 있습니다.

2. 인지 가설의 다섯 명제 분해 및 검증

현재의 연구 지형을 바탕으로 인지 아키텍처에 관한 다섯 가지 핵심 가설을 다음과 같이 판정합니다.

명제 판단 핵심 근거 및 설계 지침
Native representation은 지각과 그라운딩의 토대이다 강한 지지 원시 감각 데이터는 환경과의 직접적인 접지에 필수적임
지각과 인지는 표현적으로 분리(Decoupled)될 수 있다 강한 지지 고대역폭 지각과 저대역폭 추론의 모듈적 분리 가능
Task-relevant state가 확보되면 추론이 가능하다 강한 지지 원시 스트림 없이 압축된 상태만으로 유효한 의사결정 수행
Compact representation은 언어/심볼 형태가 유용하다 조건부 지지 의미론적 추론에는 강력하나, 모든 도메인에 범용적이지 않음
모든 인지를 언어/코드 시퀀스로 통일하는 것이 최선이다 미지지 물리, 공간, 정밀 제어 등에서 명확한 성능 하락 반례 존재

핵심 설계 원칙은 "압축된 표현(Compact representation)의 필요성"을 인정하되, "그 표현이 반드시 언어여야 한다"는 언어 중심적 편향을 경계하는 것입니다.

3. POMDP 기반 상태 압축과 Task-State Compiler의 설계 요건

의사결정 이론(POMDP) 관점에서 인지는 전체 관측 이력을 미래 의사결정에 충분한 신념 상태(Belief state)로 요약하는 과정입니다.

  • 상태 압축의 수학적 정의: 현재 목표 $g$에 대해 시스템 상태 $z_t = f(o_{\le t}, a_{< t}, g)$가 다음 조건을 만족할 때: $P(\text{relevant future} \mid o_{\le t}, a_{\le t}, g) \approx P(\text{relevant future} \mid z_t, g)$ 여기서 $z_t$는 Task-State Compiler의 목표 출력이 됩니다.

이 아키텍처는 인과적 추상화(Causal abstraction)와 이시뮬레이션(Bisimulation)을 통해 불필요한 감각 변수를 제거합니다. 다만, 정보 병목(Information bottleneck)에 의한 치명적 정보 유실을 방지하기 위해, 시스템은 반드시 다해상도 멀티모달 메모리(Multiresolution Multimodal Memory)를 유지해야 합니다. 이는 압축된 $z_t$ 상태에서 필요 시 원본의 세부 정보로 회귀할 수 있는 '고해상도 메모리 포인터(High-resolution memory pointer)'를 보존하기 위함입니다.

4. RAPID: 지각-추론 분리의 실증적 우월성

ICLR 2026 연구인 RAPID(Reasoning-Aligned Perception Decoupling)는 지각 모듈을 '질문에 필요한 상세 텍스트 표현(Detailed textual representation)' 생성기로 재정의합니다.

  • 메커니즘: 지각 모듈이 추출한 사실적 정보를 기반으로 별도의 Text-only reasoner가 최종 판단을 내립니다.
  • 학습 전략: 원문 보고에 따르면, 지각과 추론을 동시에 학습시키는 것보다 지각 모듈을 선행 학습시킨 후 추론 성능에 맞춰 최적화하는 단계적 학습(Staged training)이 Joint training보다 우수한 성능을 보입니다.
5. Neuro-symbolic 인터페이스와 검증 가능성

NS-VQA, VeriCoT, VIRO 등의 연구는 심볼릭 표현이 단순한 데이터 압축을 넘어선 가치를 지님을 보여줍니다.

  • 데이터 흐름: Image → Scene Representation → Question Program → Symbolic Execution
  • 심볼릭 검증(Symbolic Verifiability): 심볼릭 상태는 중간 연산 과정을 인간이나 시스템이 감사(Audit)할 수 있는 인터페이스 역할을 합니다. 그러나 이러한 검증 가능성이 모든 인지 영역(예: 예술적 감성, 미세 운동 제어)에서의 보편적 우월성을 의미하지는 않습니다.
6. 코드는 '보편적 사고 기질'이 아닌 '범용 제어 평면'

PAL(Program-Aided Language Models)과 Code as Policies의 사례를 분석할 때, 코드를 모든 인지 과정을 대체하는 '보편적 사고 기질(Universal thought substrate)'로 오해해서는 안 됩니다.

  • 정의: 코드는 이기종 모듈(Heterogeneous modules)을 오케스트레이션하고 상호 운용성을 보장하는 '보편적 제어 평면(Universal control plane / Interoperability layer)'으로 기능할 때 가장 강력합니다.
7. 로보틱스: 의미적 계획과 물리적 실행 가능성의 이원화

로보틱스 분야에서는 고수준 시퀀싱과 저수준 실행의 분리가 필수적입니다.

  • SayCan 및 TAMP: '의미론적 계획(Semantic planning, 언어/심볼)'과 '물리적 실행 가능성(Grounded continuous feasibility)'을 분리하여 상호 검증합니다.
  • RT-2 vs $\pi_0$: 행동을 토큰화하는 RT-2와 달리, $\pi_0$는 의미론적 백본과 연속 액션 전문가(Continuous action expert)를 분리합니다. 이는 정밀한 물리적 제어를 굳이 언어 공간으로 투사할 필요가 없음을 시사합니다.
8. 공간 인지: 언어 중심 패러다임의 한계 실증

ACL 2026(Kancheti et al.)의 연구는 텍스트 기반 연쇄 사고(Textual CoT)가 특정 도메인에서 오히려 인지적 방해 요인이 됨을 보여줍니다.

  • 실증 데이터: 16개 모델 조사 결과, Textual CoT 사용 시 공간 변형 성능은 최대 17.5%, 객체 추적 성능은 13.2% 하락했습니다. 반면 Visual CoT는 성능을 23.1% 개선했습니다. 이는 공간 정보를 문장으로 직렬화하는 과정에서 발생하는 정보 왜곡과 인지 부하를 증명합니다.
9. 물리적 세계 모델: 연속 잠재 공간의 추론 역량

PlaNet, Dreamer, V-JEPA 2-AC와 같은 모델은 자연어 매개 없이도 고도의 추론이 가능함을 보여줍니다.

  • 핵심 메커니즘: 미래 상태 예측과 계획이 자연어 토큰이 아닌 연속 잠재 공간(Continuous latent space)에서의 롤아웃(Rollout)을 통해 수행됩니다. 물리적 인과관계 예측에는 언어보다 잠재 역학 모델이 더 적합한 표현입니다.
10. Latent Reasoning과 언어 토큰의 병목 현상

Coconut 및 HyRea 연구는 자연어 토큰화가 내부 연산에서 병목이 될 수 있음을 지적합니다.

  • 언어 토큰의 한계: 가독성과 감사 가능성(Explicit token)은 높으나, 장황하고(Verbose) 병렬 처리가 어려우며 불확실성을 표현하기에 부적합합니다.
  • 잠재 추론(Latent reasoning)의 이점: 효율적인 병렬 표현과 연속적인 확률 상태 유지가 가능합니다. 현대 아키텍처는 이 둘 사이의 Trade-off를 관리하는 하이브리드 방향으로 진화하고 있습니다.
11. 차세대 인지 아키텍처: 계층적 표현 라우팅 시스템

본 분석을 종합하여 제안하는 시스템 흐름은 다음과 같습니다.

[1] Native Encoders: 고대역폭 감각 정보 수신
[2] Multiresolution Multimodal Memory: 세부 증거(Raw evidence) 및 다해상도 데이터 보존
[3] Task-State Compiler: 목표($g$) 기반의 Compact state ($z_t$) 추출
[4] Representation Router: 문제 특성에 따른 최적 작업 공간 할당
[5] Specialized Workspaces:
　- Language / Code / Latent / Visual / Continuous
[6] Verification & Action: 실행 및 감각 피드백을 통한 재접지(Grounding)

핵심 아키텍처 규칙: 모든 압축된 상태는 반드시 원본 메모리(Multiresolution memory)로 회귀할 수 있는 포인터를 보유해야 합니다.

12. 문제별 표현 특성화(Representation Specialization)

'표현의 단일화(Unification)'보다 '표현의 특성화(Specialization)'가 현재로서는 더 강력한 가설입니다.

  • Language: 의미론적 작업 분해, 도구 선택, 인간 소통.
  • Code: 알고리즘적 도구 활용, 수학적 엄밀성.
  • Visual: 정밀 공간 변형, 기하학적 추론.
  • Latent: 물리적 미래 예측, 연속적 월드 모델링.
  • Continuous: 정밀 모터 및 동적 제어.
13. 신경과학적 비유: 언어와 추론 네트워크의 분리

실어증(Aphasia) 환자가 언어 능력을 상실하고도 복잡한 논리 및 수학적 추론을 유지하는 사례는, 지능 시스템에서 언어 네트워크와 도메인 일반 추론 네트워크가 분리될 수 있음을 시사합니다. 이는 AI 아키텍처 설계에 있어 언어를 '생각의 본질'이 아닌 '생각의 인터페이스'로 정의하는 모델의 타당성을 뒷받침합니다.

14. 실용적 아키텍처 실패 모드 및 평가 지표

시스템 구축 시 설계자가 경계해야 할 사항은 다음과 같습니다.

  • 실패 모드:
    • 비가역적 압축(Irreversible compression): 초기 단계의 과도한 정보 유실.
    • 텍스트 편향 환각(Textual-prior hallucination): 시각 정보보다 텍스트 통계에 의존한 판단.
    • 심볼릭 취약성(Symbolic brittleness): 예외 상황에서의 논리 붕괴.
  • 평가 기준: Task success, Evidence recall (근거 회상 정확도), Routing regret (잘못된 공간 선택 비용), Dynamic feasibility.
15. 결론 및 증거 수준 요약

AI가 "언어로 생각한다"는 주장은 일부분만 진실입니다.

  • 높은 확신: 지각과 추론의 모듈적 분리 가능성, 특정 영역(공간/물리)에서의 비언어적 표현의 우월성.
  • 중간 확신: 범용 에이전트의 상위 계획(High-level planning)에서의 언어/코드 인터페이스 주도 가능성.
  • 불확실성: 잠재 추론과 토큰 기반 추론의 장기적 비중 변화, OOD(Out-of-Distribution) 상황에서의 비가역적 압축의 일반화 성능.

최종 결론: 미래의 AI 아키텍처는 언어를 공용 인터페이스 및 제어 평면으로 사용하되, 작업 특성에 따라 특화된 표현(심볼, 잠재, 시각 등)을 호출하고 필요 시 원시 증거(Native evidence)로 재접지하는 계층적 표현 라우팅 시스템으로 정의됩니다.

향후 연구 방향 (Future Research Directions)
  1. Task-Sufficient State의 정식화: POMDP 신념 상태와 객체 중심 표현(Object-centric representation)을 결합하여, 미지의 작업(Future task)에 대해서도 유효한 정보 유실 최소화 전략 연구.
  2. 적응형 표현 라우팅(Adaptive Routing): 문제의 불확실성과 인지 비용을 계산하여 Text/Code/Visual/Latent 공간 중 최적의 추론 기질을 선택하는 정책(Routing Policy) 및 벤치마크 설계.
  3. 다해상도 메모리 포인터 메커니즘: 압축된 심볼릭 상태에서 원본 감각 데이터의 특정 세부 정보(Visual pixel/Audio frequency)로 즉각적으로 접근할 수 있는 동적 포인팅 기술 최적화.
