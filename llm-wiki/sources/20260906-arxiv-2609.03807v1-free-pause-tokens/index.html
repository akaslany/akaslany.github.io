Free Pause Tokens 논문 해설: Almost Free State Prediction Separation

먼저 확인할 제목과 범위

이 자료는 arXiv:2609.03807v1의 고정된 PDF만을 설명한다. arXiv 표시 제목과 PDF 메타데이터는 Free Pause Tokens이지만, PDF 첫 페이지에 인쇄된 원고 제목은 Almost Free State Prediction Separation이다. 이 둘은 서로 다른 논문으로 취급할 제목 충돌이 아니라 같은 v1 원고 안에서 노출된 제목 차이다. 따라서 공개 제목에는 arXiv 표시 제목을 쓰되, 본문에서는 PDF 제목도 그대로 밝힌다.

저자는 John Langford, Nathan Godey, Giovanni Monea, Yoav Artzi, Harry Dong, Ying Fan, Gustavo de Rosa, Zheng Zhan이다. 논문은 2026년 9월 3일 제출된 cs.LG/cs.AI 프리프린트이며, 아래 수치는 모두 저자들이 이 PDF의 설정에서 보고한 결과다. 독립 재현이나 다른 규모·데이터·서빙 환경에서의 보편성을 뜻하지 않는다.

1. SPS가 분리하려는 두 부담

표준 디코더 Transformer에서 위치 i의 숨은 상태 h_i는 두 일을 동시에 해야 한다. 첫째, 뒤 위치들이 읽을 수 있도록 지금까지의 문맥 x_0:i를 요약하는 상태가 되어야 한다. 둘째, 바로 다음 토큰 x_i+1을 잘 예측해야 한다. 저자들이 따르는 state–prediction separation, 즉 SPS 가설은 이 두 목적이 한 벡터를 서로 다른 방향으로 당긴다고 본다.

SPS는 하나의 weight-shared backbone 위에 두 계산 흐름을 둔다. state stream a는 일반적인 인과적 forward pass다. 입력 토큰을 임베딩하고 각 층에서 지속되는 key와 value를 써서 다음 위치가 읽을 상태를 만든다. prediction stream p는 예측만 맡는다. 각 위치에서 하나의 학습된 predict_embedding, 즉 pause embedding으로 시작하고, 각 층에서 state stream이 만든 K/V에 query를 보낸 뒤 LM head로 다음 토큰을 예측한다. 학습 손실은 prediction stream의 출력에만 걸린다.

핵심은 prediction stream이 자기 key와 value를 전혀 쓰지 않는다는 점이다. p_i는 a_≤i를 읽지만 자기 K/V를 남기지 않는다. 두 stream은 모든 backbone 가중치를 공유하며, 새로 더해지는 실질적 텐서는 pause embedding 하나다. 그래서 이 방법은 새로운 어휘 토큰을 문장에 삽입하는 방식이 아니다.

2. 왜 ‘free pause token’인가

일반적인 textual pause token이나 thinking token은 새 sequence position을 차지한다. 그러면 context length가 늘고, 그 위치의 KV cache가 생기며, 생성 과정에서 추가 decode step이 필요할 수 있다. 이 논문의 free pause는 다르다. 기존 각 위치 옆에서 prediction stream이 병렬로 한 번 더 계산할 뿐 새 위치를 만들지 않는다. 논문 표현대로 기존 위치를 ‘타고 간다’.

따라서 이것을 chain-of-thought와 동일시하면 안 된다. 공개된 추론 문장을 더 길게 쓰는 기법도 아니고, 모델의 사적 사고과정을 복원했다는 주장도 아니다. 제공하는 것은 현재 위치에서 state stream과 병렬로 수행되는 추가 계산이다. 또한 speculative decoding과도 목적이 다르다. speculative decoding의 추가 query는 미래 후보를 검증해 생성 속도를 높이려는 반면, free pause의 두 번째 query는 현재 위치의 다음 토큰 예측 품질을 높이기 위해 항상 사용된다.

추론 시 prefill에서는 prediction이 필요하지 않아 입력 x_i만 forward하고, state stream만 K/V를 만든다. decode에서는 x_i와 p_i가 한 층씩 함께 전진한다. state stream이 x_i의 K/V를 cache에 추가하고 prediction stream은 그 K/V를 읽는다. sequence position, persistent KV cache, decode-step 수는 늘지 않지만 prediction stream의 행렬 계산 때문에 추론 FLOPs 자체는 증가한다. ‘free’는 모든 비용이 0이라는 뜻이 아니라, 논문이 측정한 작은-batch B200 decode-step 환경에서 추가 병렬 계산이 처리량 병목이 아니었다는 뜻이다.

3. 학습비용을 줄이는 네 가지 장치

3.1 FlashAttention과 맞는 two-pass split

state stream을 먼저 돌려 K/V를 만든 뒤 prediction stream을 그 위의 plain cross-attention으로 실행한다. interleaved SPS mask는 causal, sliding-window, packed block-diagonal mask 어느 쪽에도 깔끔히 맞지 않지만, 분리된 두 pass는 FlashAttention이 직접 처리할 수 있다. 저자들은 Blackwell용 FlashAttention-4와 B200에서 flexible-mask 단일 pass의 GPU당 16k tokens/s 대신 73k tokens/s를 측정해 약 4배의 kernel throughput 차이를 보고한다. 이것은 전체 방법이 표준 모델보다 4배 빠르다는 뜻이 아니다.

3.2 prediction window를 w=0으로

원래 SPS는 prediction stream 내부에 w개 토큰의 작은 sliding window를 남긴다. 이 논문은 더 엄격한 w=0을 택해 prediction K/V 자체를 없앤다. w가 0보다 크면 log-sum-exp로 합치는 두 번째 attention 호출이 필요해 w=0 prediction pass 대비 1.22배 계산이 든다. 반면 100B token 실험에서 w=64가 w=0보다 개선한 CE는 0.0047 nats였다. 저자들은 이 품질 이득과 추가 비용을 비교해 archive-only state K/V를 읽는 w=0을 빠른 기본값으로 삼는다.

3.3 shared gated FFN

attention 뒤 state residual a와 prediction residual p를 scalar gate로 섞고 FFN을 위치당 한 번만 평가한다. 그 출력을 다시 두 scalar gate를 통해 각 stream에 돌려준다. zero-bias로 gate를 0.5에서 시작하기 때문에 기존 checkpoint를 backbone으로 이어 쓸 수 있다. 이 변경은 full pause의 wall-clock 비용을 control 대비 1.57배에서 1.35배로 낮추지만, two-pass 형태 대비 약 0.005–0.010 nats의 품질을 포기한다. 비용과 품질의 실제 교환이다.

3.4 training tail에만 phasing

pause embedding 외 backbone parameter가 같으므로 표준 checkpoint에서 separation을 뒤늦게 켤 수 있다. 전체 schedule 중 표준 학습 비율을 f라 하면 논문이 쓰는 wall-clock 모델은 f + (1−f)·1.57이다. optimizer, data order, schedule, backbone state는 계속 이어지고 predict_embedding만 새로 초기화된다. 그러면 두 번째 pass 비용은 마지막 1−f 구간에만 지불한다.

4. 정확한 실험 설정

주요 실험은 1B decoder Transformer 한 규모다. 24 layers, hidden size 1536, grouped-query attention의 16 query heads와 8 KV heads를 사용한다. 대부분 층은 2048-token sliding window이고 6개 층마다 full-attention layer가 있다. sequence length는 8192다.

최적화는 Muon-family optimizer, peak learning rate 2e−2, 짧은 warmup과 stable 구간 뒤 마지막 25%에서 2e−3까지 선형 cooldown이다. global batch는 524,288 tokens이며 micro-batch 4, gradient accumulation 2, 8×B200에서 학습한다. activation은 bf16, matmul은 mxfp8이다. 데이터는 Phi-4 derived pretraining data다. 강한 control은 prediction stream만 제거하고 model, optimizer, data order, schedule, global batch를 맞췄다.

주요 학습 budget은 100B tokens다. control은 iso-compute curve를 만들기 위해 150B까지도 측정했다. 저자들은 prediction pass가 KV projection을 건너뛰어 FLOPs가 정확히 2배가 아니라 약 1.9배라고 계산한다. 실제 two-pass wall-clock은 약 1.57배인데, compute-dense prediction pass의 utilization이 micro-batch-4 control보다 약 20% 높기 때문이다. 그러므로 논문의 기본 iso-compute는 동일한 8×B200 node-hours이고, 엄격한 iso-FLOP 비교는 별도로 봐야 한다.

5. iso-token 품질과 ablation

100B tokens에서 강한 control의 cooled CE는 2.8957이고, full pause w=0은 2.8673이다. 차이는 −0.0284 nats, 즉 약 2.84 centinats다. 이것이 초록의 ‘2–3 centinats’ 범위를 구체화한다. w=64는 2.8626으로 w=0보다 0.0047 nats 더 낮지만, 앞서 본 추가 attention 비용이 따른다.

Table 2의 two-pass phasing 결과는 다음처럼 읽어야 한다. full pause는 2.8673에서 1.57배 wall-clock이다. 42.5B까지 표준 학습 후 pause를 켜면 최종 CE 2.8691, 비용 1.33배이며 full-pause gain의 약 94%를 회수한다. 75B까지 표준 학습하고 cooldown 구간에서만 pause를 켜면 CE 2.8756, 비용 1.14배이며 약 71%를 회수한다. 1.33×와 94%는 이 42.5% two-pass 설정에 묶여 있다.

phase switch는 즉시 큰 손실 spike 없이 이어지고, pause를 켠 뒤 주요 이득은 약 15B tokens 안에 쌓인다. 하지만 full pause를 처음부터 학습한 cold start는 초기 약 1.5B tokens 동안 control보다 오히려 나빴다. 이는 논문이 보여 주는 중요한 음성 결과다.

6. shared FFN의 비용과 품질

sequence length 8192, micro-batch 4에서 shared FFN은 peak memory를 GPU당 105GB에서 91GB로 약 14GB 줄인다. 이 여유로 two-pass가 OOM이 나는 더 큰 micro-batch를 쓸 수 있었다. throughput은 control의 약 128k tokens/s/GPU에 대해 약 95k, 즉 0.74배다. 일반 two-pass의 0.64배보다는 낫지만 control과 같은 속도는 아니다.

Table 3은 global batch가 조금 작은 operating point에 맞춘 별도 control 2.9064를 쓴다. 이 control은 원래 2.8957보다 약 0.011 nats 나쁘므로 두 표의 절대 CE를 섞으면 안 된다. shared-FFN full pause는 CE 2.8825, delta −0.0239, 비용 1.35배다. 42.5% phase는 2.8886, delta −0.0178, 1.20배다. 75% phase는 2.8966, delta −0.0098, 1.09배다. as low as 1.09×는 이 가장 싼 shared-FFN late-phase 점이며, full gain을 그대로 보존한 설정이 아니다.

7. 같은 계산량에서 남는 이득

Table 4의 node-hour iso-compute 비교는 100B와 150B control endpoint에서 약 0.037 nats/doubling slope를 잡아 중간 token 수를 보간하고 157B는 짧게 외삽한다. full pause 100B는 같은 1.57배 node-hours의 control 157B CE 2.872와 비교해 −0.005다. 42.5% phase는 control 133B CE 2.881 대비 −0.012, 75% phase는 control 114B CE 2.889 대비 −0.013이다. 저자들의 node-hour 기준에서는 세 점 모두 control보다 낮다.

하지만 엄격한 약 1.9배 iso-FLOP 비교에서는 margin이 줄어든다. phased runs는 −0.005에서 −0.009로 남지만 full pause는 +0.006으로 약간 나빠진다. 따라서 ‘isocompute improvement’를 말할 때 wall-clock node-hours와 FLOPs를 혼동하면 안 된다. 논문의 요지는 가장 늦게 separation을 켠 싼 schedule이 같은 실제 node-hours에서 오히려 가장 효율적인 frontier를 만든다는 것이다.

8. 추론 비용: 길이, cache, step, FLOPs, latency, throughput

free pause는 새 sequence position을 만들지 않는다. 따라서 inference context length 증가 0, persistent KV cache 증가 0, generated token당 decode step 증가 0이다. prefill은 표준 Transformer와 같은 경로를 쓴다. decode에서 state와 prediction의 projection을 batch하고 두 query가 같은 KV read를 공유한다.

Appendix A의 vLLM microbenchmark는 B200에서 두 stream을 하나의 2T-row batch로 실행하고, layer weights를 한 번 load하며, paged KV를 cross-layer KV-sharing으로 읽는다. 이 fused free-pause decode step은 표준 decode step의 약 1% 이내였다. 그러나 이는 작은-batch decode-step microbenchmark다. 다양한 batch, 긴 context, tail latency, scheduler, memory pressure, multi-GPU production serving 전체를 검증한 결과가 아니다. 추가 inference FLOPs는 실제로 존재하며, 논문은 그것이 해당 throughput 병목에서 보통 숨겨진다고 주장할 뿐이다.

9. downstream 결과

Table 5의 DCLM CORE는 21개 multiple-choice tasks의 centered mean이다. 100B control은 0.327, 100B full pause는 0.347이다. held-out climbmix bits-per-byte는 0.777에서 0.769로 0.008 낮아진다. 150B control은 DCLM 0.348, BPB 0.770으로 100B pause와 measurement error 안에서 비슷하다. 42.5% phase는 0.348/0.769, 75% phase는 0.348/0.771이다. sequence length는 모두 8192이고 표준오차는 DCLM 약 0.01, BPB 약 0.004다.

개별 lm-eval task는 모두 각자의 95% confidence interval 안에 있어 논문은 개별 점수를 보여주지 않는다. 따라서 ‘모든 task가 좋아졌다’고 말할 근거는 없다. 저자들의 결론은 aggregate accuracy와 dense compression에서 CE 개선과 일관된 작은 신호가 보인다는 범위다.

10. pause embedding 관찰

하나뿐인 pause embedding은 초기값에서 per-coordinate RMS 약 1까지 약 40배 커졌고, norm은 token embedding norm의 약 0.4배다. 그러나 사용 전 RMS normalization을 거치므로 방향이 중요하다. 자주 나오는 comma, period, newline, ‘the’, ‘and’가 cosine 0.25–0.46의 가까운 token들이다. 일부 좌표는 ±3–4, 약 4 sigma까지 올라가며 top 10 dimensions가 energy 약 11%를 가진다. 이런 관찰은 embedding의 성격을 묘사하지만 어떤 좌표가 gain을 인과적으로 만든다는 증명은 아니다.

11. 무엇을 결론 내릴 수 있고 없는가

저자들의 실험 범위에서는 state–prediction separation이 표준 next-token training보다 iso-token CE를 낮췄고, late phasing과 shared FFN으로 wall-clock tradeoff를 줄였다. 하지만 학습비용은 사라지지 않는다. 구현에는 two-stream execution, FlashAttention-compatible split, shared KV read, vLLM/kernel 변경이 필요하다. 추론 FLOPs도 늘어난다.

가장 큰 제한은 single 1B scale, single primary seed, 하나의 Phi-4-derived data recipe와 특정 B200 kernel/hardware 환경이다. per-task 유의한 보편적 향상도 보이지 않았고, production serving 전반은 측정하지 않았다. 따라서 이 논문은 모든 모델, 데이터셋, 규모, accelerator, batch regime에서 이득이 난다는 증명이 아니다. 제목의 ‘Almost Free’는 저자들이 이 제한된 실험에서 training wall-clock을 1.33배 또는 tradeoff상 1.09배까지 낮추고 inference depth/cache/position 비용을 없앴다는 요약으로 읽어야 한다.
