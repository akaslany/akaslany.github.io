사람을 흉내 내는 AI, Persimmon이 던지는 질문

1. 무엇을 공개했나

humans&는 2026년 9월 10일 연구 프리뷰 「Persimmon」을 공개했다. 글의 표현에 따르면 Persimmon은 여러 사람이 여러 차례 대화하는 환경에서 인간의 행동을 현실적으로 모사하려는 대규모 사용자 모델이다. 하나의 “정답 행동”을 맞히기보다, 한 사람의 응답 안에서 그리고 사람·상황·시간 사이에서 나타나는 행동의 분포를 넓게 포착하는 것이 목표다. 공개 버전 표기는 Persimmon v0.1이며, 플레이그라운드와 API는 제한적 연구·평가 프리뷰로 제공된다.

이 영상과 보고서는 해당 발표문 한 편을 설명하는 변형적 해설이다. 수치와 평가 결과는 모두 humans&가 발표문에서 보고한 저자 보고 내용이며 독립적으로 재현하거나 검증하지 않았다. 원문 도표, 화면 구성, 사례 대화는 복제하지 않는다.

2. 핵심 발상: 평균적인 사람 대신 행동의 분포

일반적인 AI 벤치마크는 과제를 끝냈는지를 효용의 대리값으로 삼기 쉽다. 그러나 사용자 모델에는 모든 사람에게 적용되는 단일 성공 행동이 없다. 발표문은 미리 정한 성격 특성 목록을 검사하면 측정하기 쉬운 차이만 강조하고 중요한 변이를 놓칠 수 있다고 지적한다. 그래서 Persimmon의 중심 평가 철학은 ‘분포 매칭’이다. 특정 특성을 직접 열거하는 대신, 모델 응답이 실제 인간 응답과 같은 분포에서 나온 것처럼 보이는지를 묻는다.

이 목표는 “더 유능한 비서”를 만드는 목표와 다르다. 비서 모델의 친절함과 완결성은 사용자를 연기할 때 과잉 설명이나 너무 이른 정보 공개로 바뀔 수 있다. Persimmon 발표는 바로 그 간극을 평가 대상으로 삼는다.

3. 다중 사용자 튜링 테스트가 보여 주는 것과 보여 주지 않는 것

발표문은 여러 사람이 참여한 실제 대화와 AI가 사람들 역할을 생성한 대화를 판별자에게 제시하는 다중 사용자 튜링 테스트를 설명한다. k=8 조건에서 세 데이터셋 평균의 judge fooled rate는 Persimmon 19.8%로 보고되며, 비교 모델들은 1.2% 이하로 제시된다. 데이터셋별 Persimmon 수치는 TIDES 21.1%, 내부 워크스페이스 대화 18.6%, TutorMoments 19.8%다. 50%는 판별자가 우연 수준으로만 맞히는 인간 동등점이다.

따라서 19.8%는 “인간과 구별 불가능”을 뜻하지 않는다. 비교 모델보다 판별자를 더 자주 속였다는 저자 측 결과이지만, 여전히 50%와 거리가 있다. 오차막대도 데이터셋 또는 반복 실행 간 표준편차이며 신뢰구간과 동일하지 않다. 내부 데이터가 포함되고, 저자들이 프롬프트 최적화로 찾은 최선 전략을 보고했다는 경계도 함께 읽어야 한다.

프로필을 모델과 판별자 모두에게 보여 주는 변형에서는 점수가 대체로 높아졌다고 발표문은 말한다. Pangram 탐지 결과도 내부 대화에서 인간 1.3%, Persimmon 2.3%, Astra 54.3%, Fable 5 94.3%가 AI로 표시됐다고 보고한다. 그러나 특정 탐지기에서 낮게 잡힌다는 사실은 일반적인 인간성, 안전성, 진실성의 증명이 아니다.

4. 사용자 행동을 쪼개 보는 USI와 정보 공개 시점

User-Sim Index 평가는 의사소통 스타일, 정보 패턴, 명확화 행동, 오류 반응을 규칙·어휘 기반 특징으로 추출해 인간 행동과 비교한다. 발표문 자체도 이 접근의 한계를 인정한다. 고정 차원 밖의 행동을 놓치고, 손으로 만든 규칙이 취약하며, 고정 턴 수가 자연스럽지만 느린 사용자를 불리하게 만들 수 있다. 더구나 Persimmon과 비교 모델의 프롬프팅 계약과 종합 점수 구성 항목이 달라 전체 USI 평균을 직접 순위로 비교할 수 없다고 명시한다.

Trickle Test는 사람이 대화 중 사실을 언제 얼마나 공개하는지 재생한다. recall은 그 시점까지 인간이 공개한 사실을 모델도 공개했는지, precision은 모델이 공개한 사실이 당시 공개될 차례였는지를 본다. 발표문에서 Persimmon은 높은 precision과 경쟁력 있는 recall을 보였다고 주장한다. 이 평가는 도움을 주려는 비서 모델이 질문받지 않은 정보까지 미리 쏟아내는 경향을 사용자 모사 실패로 포착한다는 점에서 흥미롭다.

5. 시간이 지나도 사람 같은가

80턴 상호작용에서는 서로 떨어진 16턴 구간을 비교해 성격과 행동의 일관성을 본다. 발표문은 실제 인간도 완벽하게 일관적이지 않으므로, 계속 똑같은 반응만 하는 것이 목표가 아니라고 설명한다. Persimmon의 일관성은 인간처럼 시간이 지나며 감소하지만 짧은 구간에서는 아직 인간 패턴과 맞지 않고, GPT 6 Astra 결과는 일부만 존재한다고 밝힌다. 즉 “오래 대화해도 완벽히 사람 같다”가 아니라, 과도한 기계적 일관성과 무너지는 일관성 사이의 시간적 패턴을 평가하려는 시도다.

6. 어떻게 만들었고 어떤 한계가 남았나

Persimmon은 NVIDIA의 5500억 파라미터 Nemotron 3 Ultra 베이스에서 시작했다고 발표문은 설명한다. 공개 인터넷의 사람 간 대화를 다양하게 사용해 미드트레이닝했고, 장기 대화에서 오류가 누적되는 문제를 줄이기 위해 자체 생성물과 적응형 판별자를 이용한 강화학습 후훈련을 적용했다. 저자들은 장기 일관성이 개선됐지만 일반적인 분포 매칭은 눈에 띄게 바뀌지 않았다고 보고한다.

발표문은 안전 경계를 분명히 적는다. 인간 행동을 폭넓게 모사하려는 목적은 비서형 가드레일과 충돌할 수 있고, 모델은 인간의 편향을 반영할 수 있으며 개인정보와 공정성 한계가 있다. 그래서 사칭, 개인정보 침해, 착취적 조작, 실제 사람에 대한 중대한 의사결정에 쓰이지 않도록 배포를 제한한다고 설명한다. 서비스 약관은 합성 응답에서 나온 통계나 정서를 실제 인간 의견처럼 제시하지 말고, 합성 추정치와 불확실성을 밝혀야 한다고 요구한다.

결론: 유사성 점수는 사람에 대한 증거가 아니다

Persimmon 발표의 중요한 기여는 사용자 시뮬레이션을 단순한 문체 모방이 아니라 분포, 정보 공개 시점, 장기 변화의 문제로 재정의한 데 있다. 동시에 공개된 수치는 저자 측 데이터·판별자·프롬프트·평가 설계에 묶여 있다. 이 모델의 출력은 실제 사람의 동의나 판단을 대신하지 않으며, 합성 집단 결과를 실제 여론으로 포장해서도 안 된다. 연구 프리뷰의 가치는 인간을 대체했다는 선언이 아니라, 사람 같은 행동을 측정할 때 무엇을 함께 검증해야 하는지를 더 구체적으로 드러냈다는 데 있다.
