1. Bonsai 2 27B 개요 및 주요 업데이트

PrismML이 발표한 Ternary Bonsai 2 27B는 27B 파라미터급 멀티모달 모델을 효율적으로 로컬 배포할 수 있음을 증명한 Bonsai 시리즈의 최신 진화형입니다. 본 모델은 최신 저비트 표현 기술을 통해 모델 크기를 획기적으로 줄이면서도 성능 저하를 최소화하여, 실질적인 ‘무손실 배포’의 임계점을 돌파했습니다.

  • 최첨단 베이스 모델 기반: Qwen3.8 27B를 베이스 모델로 채택하여 기초적인 추론 및 지식 처리 능력을 대폭 상향했습니다.
  • 사실상의 무손실 압축 달성: 이전 세대 모델의 성능 유지율(95%)을 넘어, 풀 프리시전(Full-precision) 모델 대비 **98.2%**의 종합 성능 유지율을 달성했습니다. 이는 압축 모델이 실무 환경에서 원본 모델을 완전히 대체할 수 있음을 시사합니다.
  • 심화된 실행 역량: 특히 추론(Reasoning), 코딩, 비전 및 장기 실행 에이전트(Long-horizon agentic performance) 작업에서 이전 세대 대비 괄목할만한 성능 향상을 이루었습니다.

2. 핵심 기술 사양 및 아키텍처

Bonsai 2 27B는 언어 모델 전반에 걸쳐 엔드 투 엔드(End-to-end) 저비트 표현을 적용하여 메모리 효율성과 연산 속도를 동시에 확보했습니다.

항목 상세 사양
양자화 스키마 (Quantization Scheme) Ternary {-1, 0, +1} 가중치 및 FP16 그룹 단위 스케일링(Group-wise scaling)
유효 비트 수 (Effective Bits) 가중치당 1.76 bits
모델 풋프린트 (Footprint) 5.9GB (풀 프리시전 대비 약 9.2배 축소)
컨텍스트 윈도우 262K 토큰
지원 모달리티 텍스트 및 이미지 (멀티모달)
라이선스 Apache 2.0

3. 벤치마크 성능 및 성능 유지율 분석 (Thinking Mode)

Ternary Bonsai 2 27B는 모델 크기를 9배 이상 축소했음에도 불구하고, 고난도 추론 작업에서 베이스 모델과 거의 대등한 결과를 보여줍니다. 특히 모델의 기가바이트(GB)당 성능을 나타내는 ‘지능 밀도(Intelligence density per GB)’ 측면에서 기존의 저비트 대안 모델들이 코딩이나 비전 능력을 희생했던 것과 달리 압도적인 효율성을 입증했습니다.

평가 카테고리 (주요 벤치마크) Ternary Bonsai 2 27B (Thinking Mode) Qwen3.8 27B (Full-Precision) Qwen3.6 27B (Full-Precision)
Agentic & Tool Calling (τ²-bench, BFCLv3) 77.57 79.74 80.05
Coding (HumanEval+, LiveCodeBench v6, MBPP+, BigCodeBench) 81.58 82.17 82.57
Instruction Following (IFBench, IFEval) 82.66 81.25 74.53
Knowledge & Reasoning (MMLU-Redux, GPQA Diamond, AA-LCR) 83.95 86.66 84.71
Math (AIME 2026, AIME 2025, GSM8K, MATH-500) 96.57 97.06 94.64
Vision (CharXiv, A-OKVQA, OmniDocBench v1.6, RealWorldQA, OCRBench v2) 78.59 81.64 79.82
Overall Score (종합 점수) 83.9 85.4 83.6

분석 결과, 본 모델은 코딩 에이전트 및 도구 사용 시스템과 같이 작은 오류가 치명적인 결과로 이어질 수 있는 ‘Long-horizon’ 작업에서 탁월한 복원력을 보여줍니다.

4. 처리량(Throughput) 및 에너지 효율성

최적화된 저비트 커널을 통해 하드웨어 자원을 극도로 효율적으로 활용합니다.

  • 하드웨어별 처리량:
    • NVIDIA GeForce RTX 5090: 최대 143 tokens/s 기록
    • Apple M5 Max: 46.8 tokens/s 기록
  • 에너지 소비 효율:
    • NVIDIA RTX 4090 기준, 토큰당 에너지 소비량은 0.714 mWh/token 수준입니다.
    • 이는 풀 프리시전으로 구동되는 8B 모델보다 40% 더 뛰어난 에너지 효율성을 제공하는 것으로, 대형 모델의 지능을 소형 모델보다 더 적은 비용으로 구현하는 ‘배포의 혁신(Deployment Unlock)’을 의미합니다.
  • 실무적 이점: 높은 처리량은 코딩 어시스턴트의 ‘수정-디버깅’ 루프를 즉각적으로 처리하며, 낮은 전력 소비는 모바일 기기의 배터리 수명을 보존하면서도 백그라운드에서 AI 에이전트를 상시 구동할 수 있는 환경을 제공합니다.

5. 배포상의 함의 및 실질적 활용 사례

Bonsai 2 27B는 AI 인프라의 경제성과 설계 방식을 근본적으로 재정의합니다.

  1. 고도화된 로컬 워크플로우: 코딩 에이전트 루프, 컴퓨터 사용(Computer-use) 워크플로우, 프라이빗 문서 분석, 멀티모달 디버깅 등 민감한 데이터를 다루는 작업을 로컬에서 완결성 있게 수행합니다.
  2. 지능형 하이브리드 시스템: 로컬에서 고성능 추론을 수행하되, 모델이 스스로 판단하여 복잡도가 극도로 높은 작업만 클라우드로 전달하는 "Dynamically decide what should run locally and what should run in the cloud" 전략 구현이 가능합니다.
  3. 경제적 데이터센터 운영: 동일한 메모리 용량 내에 더 큰 모델을 배치하거나, 동일 하드웨어에서 더 많은 동시 사용자를 수용함으로써 인프라 비용과 에너지 사용량을 획기적으로 절감합니다.
  4. 광범위한 플랫폼 지원: NVIDIA GPU(CUDA)뿐만 아니라 **Apple의 Mac, iPhone, iPad(MLX)**를 위한 전용 저비트 커널을 지원하여 모바일 환경까지 커버합니다. (Apache 2.0 라이선스 적용)

6. 결론: AI 배포의 새로운 패러다임

이제 AI 모델의 진정한 가치는 단순히 절대적인 벤치마크 점수에 있지 않습니다. 핵심은 **'제한된 메모리, 연산, 그리고 전력 예산 내에서 얼마나 유용한 지능을 사용자에게 전달할 수 있는가'**입니다. Ternary Bonsai 2 27B는 성능 유지율을 98.2%까지 끌어올림으로써, 저비트 모델이 로컬 장치부터 대규모 데이터센터에 이르기까지 AI 배포를 위한 최선의 선택지임을 증명하고 있습니다.
