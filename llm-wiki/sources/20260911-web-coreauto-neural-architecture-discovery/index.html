1. Core Automation 및 Ehsan Amid의 주장: 아키텍처의 비중립성

Ehsan Amid는 "데이터가 아키텍처를 형성했다(Data shaped the architectures)"는 도발적인 명제를 통해, 현대 딥러닝 아키텍처가 결코 데이터 중립적인 계산 구조가 아님을 역설합니다.

  • 역사적 선택의 산물: 현재 표준으로 자리 잡은 ResNet, Transformer 등의 아키텍처는 지난 수십 년간 CIFAR, ImageNet과 같은 벤치마크 데이터셋에서 살아남기 위해 인간에 의해 '선택'된 결과물입니다.
  • 초기화 상태의 '마법'에 대한 재해석: 무작위로 초기화된 ResNet-18이 학습 없이도 원시 픽셀보다 높은 데이터 분리 성능을 보인다는 사실은, 해당 구조가 이미 자연 데이터의 통계적 특성을 추출하도록 설계 단계에서부터 '하드코딩된 사전 분포(Hard-coded Priors)'를 가지고 있음을 시사합니다.
  • 에이전트 기반 패러다임 전환: Amid는 이제 아키텍처 발견의 주체가 인간에서 에이전트로 이동함에 따라, 우리가 제공하는 데이터의 편향이 미래 아키텍처의 형태를 결정할 것이라는 비전을 제시합니다.
2. 기술적 방법론: NNPK와 NRF의 이론적/실무적 구현

본 보고서는 무작위 신경망의 잠재력을 측정하기 위해 2022년 arXiv v1 논문이 제안한 두 가지 핵심 개념을 구분하여 정의합니다.

  • Neural Network Prior Kernel (NNPK): 특정 아키텍처와 초기화 분포($\pi$)가 주어졌을 때, 네트워크 로짓(Logits) 내적의 기댓값($\kappa_{NNPK}(x, x') = E_{\theta \sim \pi}[\langle f_{\theta}(x), f_{\theta}(x') \rangle]$)으로 정의됩니다. 이는 특정 아키텍처의 고유한 '지문'과 같은 결정론적(Deterministic) 커널입니다.
  • Neural Random Features (NRF): NNPK의 유한 표본 근사(Finite-sample approximation)입니다. 여러 번 무작위 초기화된 네트워크들의 출력을 이어 붙여 유한 차원의 특징 벡터를 생성합니다.
  • 실험적 통제 ($n=3072$): NRF가 단순히 높은 차원성으로 인해 성능이 우수해지는 함정을 방지하기 위해, CIFAR-10 실험에서는 특징 차원 $n$을 입력 차원과 동일한 3072로 고정하여 구조적 이점만을 순수하게 측정했습니다.
  • 최적화 방법론: 특징 추출 이후의 선형 분류기 학습에는 **L-BFGS(2차 최적화 방법)**를 적용했습니다. 이는 SGD의 수렴 실패 가능성을 배제하고, 순수하게 아키텍처가 생성한 특징(Feature)의 품질만을 반영한 정확도를 도출하기 위함입니다.
3. 검색 및 자동화 방법론에 대한 비판적 검토

본 자료는 에이전트 기반 자동화의 잠재력을 논하고 있으나, 실제 자동화된 신경망 아키텍처 탐색(NAS)의 결과물은 포함하고 있지 않음에 유의해야 합니다.

  • 성과 보고서가 아닌 전망: 자료 내에는 에이전트가 새롭게 발견한 독창적인 아키텍처 설계도나 기존 NAS 알고리즘 대비 효율성(Wall-clock cost 등)을 입증하는 벤치마크 수치가 부재합니다.
  • 가속화의 가정: "수십 년이 걸린 CNN에서 Transformer로의 진화를 수일 내로 단축할 것"이라는 주장은 실험적 증명이 아닌 저자의 '기술적 전망'에 해당하며, 실제 자동화 도구의 구현 수준은 명시되지 않았습니다.
4. 아키텍처별 성능 분석: 비단조성과 데이터 증강의 인과관계

실험 데이터는 아키텍처의 복잡도와 NRF 성능이 반드시 비례하지 않는다는 **비단조성(Non-monotonicity)**을 명확히 보여줍니다.

  • CIFAR-10 핵심 지표 ($n=3072$):
    1. 원시 픽셀(Raw Pixel) 선형 분류기: 약 42%
    2. MLP 기반 NRF: 약 50%
    3. ResNet-18 기반 NRF: 약 60%
  • ImageNet-1K의 압도적 효율성: NRF의 확장성은 대규모 데이터셋에서 더욱 두드러집니다. 원시 픽셀(15만 개의 특징)이 3.4%의 정확도에 머문 반면, **ResNet-18 기반 NRF는 37배 적은 4,096개의 특징만으로 10.3%**의 정확도를 기록하며 이론의 유효성을 증명했습니다.
  • 비단조성 관찰 및 해석: CNN-S와 같은 얕은 구조가 CNN-M이나 LeNet보다 우수한 성능을 보였으며, ResNet-101에서 ResNet-200으로 깊어질 때 성능이 정체되거나 오히려 소폭 하락하는 경향이 관찰되었습니다.
  • 핵심 제약 사항: 이러한 비단조성의 주된 원인은 데이터 증강(Data Augmentation)의 부재입니다. 논문은 데이터 증강이 있을 경우 성능이 규모에 비례해 확장되지만, 증강이 없는 초기 상태에서는 구조적 적합성(Inductive Bias)이 규모보다 더 지배적인 변수임을 시사합니다.
5. 인과적 해석: Conjecture 1과 시각화의 경계

저자는 실험 결과를 바탕으로 아키텍처의 기원에 대한 도발적인 가설을 제시합니다.

  • Conjecture 1 (역사적 선택 가설): 현존 아키텍처들이 학습 전부터 높은 성능을 내는 이유는, 이들이 수동 설계 과정에서 특정 데이터 구조에 최적화되도록 '사전 튜닝'되었기 때문입니다. 이는 우리가 아키텍처의 수학적 층(Layers) 내부에 이미 특정 편향을 각인시켰음을 의미합니다.
  • 시각적 해석의 한계: TriMap을 활용한 시각화 자료는 클래스 간 분리 경향을 보여주는 정성적 도구일 뿐입니다. TriMap은 비선형 차원 축소 기법이므로, 실제 수치상으로는 존재하지 않는 클러스터를 시각적으로 과장하거나 왜곡(Hallucination)할 위험이 있음을 분석 시 인지해야 합니다.
6. 미래 전망: 에이전트 기반 탐색의 확장

Ehsan Amid는 자동화를 통해 인간 설계자의 인지적 한계를 넘어서는 새로운 패러다임을 예고합니다.

  • 탐색 공간의 확장: 기존 Transformer 구조의 변형에 머물지 않고, 전혀 다른 메커니즘을 가진 효율적 모델(지속 학습, 저전력 연산 등)의 발견 가능성.
  • 데이터-중심 아키텍처 발견: 검색 알고리즘의 보상 체계를 결정하는 것은 결국 데이터이므로, 특정 도메인(코딩, 수학 등)에 근본적으로 최적화된 구조를 도출하기 위한 데이터 선정의 중요성 강조.
7. 독립 검증 상태 및 재현의 한계

본 분석은 저자의 블로그와 2022년 arXiv v1 논문을 기초로 하며, 다음과 같은 기술적 공백을 포함합니다.

  • 미공개 컴퓨팅 자원 정보: 실험에 사용된 구체적인 GPU/TPU 사양, 총 연산량(FLOPs), 실제 소요된 시간(Wall-clock cost)이 명시되지 않아 경제적 효율성을 객관적으로 평가할 수 없습니다.
  • 일반화의 제약: 본 결과는 데이터 증강이 배제된 특정 벤치마크 환경에서의 수치이며, 모든 도메인과 데이터 분포에 보편적으로 적용되는 일반 법칙으로 해석하기에는 독립적인 재현 증거가 부족합니다.
