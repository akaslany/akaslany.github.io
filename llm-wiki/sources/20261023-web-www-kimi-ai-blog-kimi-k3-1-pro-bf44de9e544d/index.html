Kimi K3.1 Pro 기술 해설 보고서: 오픈 지능(Open Intelligence)의 진보

1. 개요 (Overview)

Kimi K3.1 Pro는 K3.1 시리즈의 첫 번째 모델이자 1백만 토큰(1-million-token) 컨텍스트 윈도우를 갖춘 최신 3T 클래스 오픈 웨이트(open-weight) AI 모델이다. 본 모델은 코딩, 3D 생성, 금융 연구 및 기타 에이전트(agentic) 능력 전반에서 대폭적인 성능 향상을 제공한다. 이와 함께 더욱 신속한 상호작용 환경을 필요로 하는 사용자 및 애플리케이션을 위해 K3.1 Pro 대비 2~3배 빠른 응답 속도를 구현한 Kimi K3.1 Pro Highspeed 모델이 동시에 공개되었다.

K3.1 Pro는 이전 Kimi K3의 사후 학습(post-trained) 버전으로, 사후 학습 컴퓨트 규모를 크게 확장하여 개발되었다. 수백 개의 다운스트림 도메인에 걸쳐 대규모 공동 강화학습(RL)을 안정적으로 적용하기 위해 RL 프레임워크, 장문 맥락 추론, 학습 효율성, 샌드박스 인프라, 롤아웃 스케줄링, 환경 품질 검사 공유 플랫폼 등 인프라 스택 전반을 최적화했다. 이를 통해 각 RL 컴퓨트의 증가가 안정적이고 예측 가능한 성능 향상으로 이어지도록 설계되었다.

Kimi K3.1 Pro 및 K3.1 Pro Highspeed는 현재 Kimi.ai 웹사이트, 모바일 앱(iOS, Android, HarmonyOS), Kimi Work 데스크톱 앱(버전 3.1.0 이상, Windows 및 Apple silicon Mac 지원), Kimi Code(/model 명령어로 선택 가능), Kimi API를 통해 즉시 이용할 수 있다. Kimi API 플랫폼에서는 kimi-k3.1-pro 및 kimi-k3.1-pro-highspeed 모델명으로 제공되며 Zero Data Retention 옵션을 지원한다. 전체 모델 웨이트(full model weights)는 2026년 11월 4일까지 배포될 예정이다. 기업용 환경인 Kimi Business의 경우 조직 관리자 설정을 통해 활성화할 수 있으며 출시 시 기본 설정은 비활성화(off by default) 상태이다.

2. 주요 논점 (Key Arguments & Technical Achievements)

2.1 대규모 강화학습(RL) 기반의 인프라 최적화 및 성능 향상
  • [Fact] 사후 학습(post-training) 컴퓨트 규모를 대폭 확장하고 RL 프레임워크, 장문 맥락 추론, 학습 효율성, 샌드박스 인프라, 롤아웃 스케줄링, 환경 품질 검사 공유 플랫폼 등 인프라 스택의 모든 레이어를 최적화하여 수백 개 다운스트림 도메인에 걸친 대규모 공동 RL(joint RL)을 성공적으로 적용함.
  • [Claim] 인프라 최적화를 통해 사후 학습 컴퓨트 투입량이 증가하더라도 성능의 불확실성이나 저하 없이 예측 가능하고 안정적인 성능 향상(returns)을 보장함.
  • [Interpretation] 단일 도메인에 국한된 RL 적용을 넘어 전 분야 인프라 최적화를 병행함으로써, 대규모 컴퓨트 확장이 코딩·금융·에이전트 등 다각도 영역의 성능 상승으로 직접 전환되는 사후 학습 인프라 역량을 입증함.
2.2 코딩 및 장기 실행(Long-Horizon) 에이전트 능력
  • [Fact] 리소스가 제한된 실제 터미널 환경 작업을 평가하는 Terminal-Bench 4.0(Claude-Code harness 적용)에서 65.7%를 기록하여 GPT-6 Astra(58.2%)를 상회하고 Claude Opus 5.5(66.4%) 수준에 근접함. 다단계 실행 및 엔드투엔드 문제 해결을 평가하는 자체 Kimi Code Bench 3.0 Long-horizon에서는 61.2%를 기록해 K3(55.95%) 대비 크게 향상됨.
  • [Fact] Unity, Unreal Engine, Godot 등 게임 엔진과 웹 검색, 3D 생성을 연동하여 상호작용 경험을 제작함. 296개 골격과 402개 근육 구성요소를 포함하는 오픈소스 인체 해부학 모델 human-atlas 기반 시뮬레이터 개발 테스트에서 167개 미션과 420회 독립 검토를 수행하며, 초기 수 초 내에 쓰러지던 시뮬레이션을 11.2초 동안 교차 걸음으로 연속 보행하도록 개선함. 리워드 shaping으로 팔 동작이 개선되지 않자 오픈루프 프로브(open-loop probes)를 실행해 어깨 근육 모멘트 암(moment-arm) 계산 오류 36개를 직접 찾아 수정한 후 컨트롤러를 재학습시킴.
  • [Claim] 사후 학습 단계의 대규모 RL을 통해 단순한 코드 작성을 넘어 장기 실행(long-horizon) 디버깅 및 복잡한 물리 시뮬레이션 환경 제어 능력까지 정밀하게 고도화함.
  • [Interpretation] 리워드 조절 실패 시 하위 동역학 수식의 오류를 역추적하여 수정한 사례는 에이전트가 단순 시행착오(trial-and-error)를 넘어 시스템 원인을 분석하고 문제를 해결하는 수준에 도달했음을 보여줌.
2.3 3D 모델링, 디자인 및 파라메트릭 모델링
  • [Fact] 다중 시점 렌더링 기반 3D 복원을 평가하는 BenchCAD(툴 사용 시, Claude Code harness 적용)에서 92.7%를 기록해 Claude Opus 5.5(96.2%), GPT-6 Astra(95.9%) 수준에 근접함.
  • [Fact] MCP 커넥터 없이 Blender 및 CAD 소프트웨어용 스크립트를 직접 작성·실행하여 기계 부품, 건축 모델, 가구 등 파라메트릭 모델링을 수행함. Kimi.ai 및 Kimi 앱을 통해 '3D Make' 기능을 제공하며, 온라인 프리뷰/편집, 3D 프린팅용 파일 다운로드, 비디오 및 Live Photos 형태의 수출을 지원함.
  • [Claim] 텍스트 브리프, 스케치, 참조 이미지로부터 형상, 비율, 공간적 관계를 추론하여 실용적인 3D 자산을 구축할 수 있으며, 기존 자산 라이브러리에 대한 이해도가 뛰어남.
  • [Interpretation] 직접 스크립트를 작성하여 CAD 툴을 제어하는 파라메트릭 모델링 능력은 단순한 시각적 3D 형상 생성을 넘어 실무 정밀 설계 및 제작 파이프라인으로 AI 활용 범위를 확장시킴.
2.4 금융 워크플로우 처리 및 환각(Hallucination) 감소
  • [Fact] 실제 재무 문서 대상 다단계 수치 추론을 평가하는 OfficeQA Pro v2에서 64.4 점수를 기록함 (평가 시 전체 PDF 코퍼스를 텍스트 없이 이미지로만 렌더링하여 제공). Frontier Finance에서도 K3 대비 발전된 성능을 보임.
  • [Fact] 자체 금융 벤치마크 평가 결과: Financial Modeling(+7.2점 향상), Financial Research(+11.6점 향상), Business Operation(K3 대비 약 4.2배 성능 달성).
  • [Fact] 사실적 정확도 스트레스 테스트인 Kimi Hallu Bench Hard 평가에서 주장 단위 환각율(claim-level hallucination rate)이 기존 K3의 23.4%에서 8.3%로 감소함. 최소 1개 이상의 사실 오류를 포함하는 응답 비율 역시 K3 대비 42.4% 수준으로 감소함.
  • [Claim] 환각 현상의 획기적 감소와 추론 능력 강화를 바탕으로 엔드투엔드 금융 분석, 재무 모델링, 투자 연구 워크플로우를 완결성 있게 수행 가능함.
  • [Interpretation] 스트레스 테스트 조건에서 주장 단위 환각율을 8.3%까지 낮춘 성과는 고도의 수치적·사실적 정밀성이 요구되는 전문 산업군에 에이전트를 실무적으로 도입할 수 있는 기반을 마련함.
2.5 사이버 보안 능력 통제 및 오픈 웨이트 출시 정책
  • [Fact] 중간 학습(mid-training) 코퍼스 및 RL 환경에 포함된 사이버 관련 데이터/태스크를 식별하고 이를 제거하는 위험 경감 조치를 적용함. 데이터 제거를 적용하지 않은 내부 모델은 코드 기반 취약점 발견 및 익스플로잇 평가 벤치마크인 xdev-bench-hard(pass@3)에서 90.5%를 해결했으나, 최종 K3.1 Pro는 81.0%로 정량적 능력이 조정됨.
  • [Fact] 추가 사이버 보안 벤치마크인 ExploitBench(300-turn budget)에서 pass@5 max capability score 평가를 진행했으며, ExploitGym(6-hour wall-clock budget per task) 평가도 실시됨. K3.1 Pro의 공격적 사이버 능력은 최소 3개월 이상 공개된 최상위 프론티어 독점 모델(GPT-6 Astra, Claude Opus 5.5, Claude Mythos 5.1 등)의 수준보다 낮게 통제됨.
  • [Claim] 오픈 웨이트 공개 정책: 절대적 공격 능력의 최첨단(frontier)을 확장하는 오픈 웨이트는 공개하지 않되, 방어 목적의 사용을 유도하기 위해 점진적으로 오픈 웨이트의 보안 검증 능력을 높임. 제어 가능한 인프라에서 레거시 시스템을 포함한 전체 소프트웨어 생태계의 안전을 제고하는 것을 목표로 함.
  • [Interpretation] 일반 코딩 및 장기 실행 능력이 발전함에 따라 사이버 작업 능력도 자동적으로 상승(전이)하지만, 사전/사후 학습 단에서의 타깃팅된 데이터 제거 조치를 통해 오남용 위험 능력을 효율적으로 제어할 수 있음을 보여줌.

5. 한계와 불확실성 (Limitations & Uncertainties)

  • 환각율 평가의 조건적 한계: Kimi Hallu Bench Hard 벤치마크 결과(주장 단위 환각율 8.3%)는 오류가 발생하기 쉬운 특수 상황을 의도적으로 유도한 스트레스 테스트 수치이다. 따라서 일상적인 일반 사용 환경에서의 전체 응답 오류율을 직접적으로 나타내지는 않는다.
  • 사이버 공격 능력의 통제적 한계: 사이버 관련 데이터 및 RL 환경 제거 조치로 인해, K3.1 Pro의 공격적 사이버 능력은 최소 3개월 이상 공개된 최상위 프론티어 독점 모델의 수준에 미치지 못하도록 통제되었다.
  • 평가 환경 및 하네스 조건 제약:
    • 기본 추론 설정: 별도 명시가 없는 한 모든 K3.1 Pro 평가 수치는 reasoning effort 'max', temperature = 1.0, top-p = 0.95 설정 하에 측정되었다.
    • 하네스(Harness) 적용: Terminal-Bench 4.0, DeepSWE v1.1, SWE-Marathon v1.1, PostTrainBench, BenchCAD 등의 주요 코딩 평가 시 Claude-Code harness가 적용되었다.
    • 시각적 멀티모달 제약: OfficeQA Pro v2 평가 시 각 작업의 전체 PDF 코퍼스는 기계 읽기 가능한 텍스트 없이 1,152픽셀 크기의 이미지로만 렌더링되어 제공되었다. (외부 모델 궤적 중 온라인 참조 답안을 검색한 경우 0점 처리함).
    • 웹 탐색 제약: BrowseComp 테스트에서는 200K 토큰 시점 컨텍스트 압축(context compaction) 전략이 적용되었으며, 최대 500단계 제한 하에서 미완료 시 강제 답변을 제출받아 평가했다 (temperature=1.0, top-p=1.0).
    • 타사 모델 비교: 타사 독점(proprietary) 모델 평가 시 일부 시스템 대체(fallback) 동작이 포함되었을 가능성이 존재한다.
