1. 언어 모델의 '형태(Shape)'와 하네스(Harness)의 개념 정의

1.1 입력·출력 구조 계약으로서의 모델 형태

언어 모델의 **'형태(Shape)'**란 모델의 **입력과 출력 구조 간에 체결된 시스템적 계약(contract)**을 의미한다. 현재 가장 널리 쓰이는 디코더 전용(Decoder-only) 트랜스포머는 가장 유연한 입출력 계약 형태를 대표한다.

  • 입출력 구조 계약의 주요 특성
    • 범용적 입출력 유연성: '임의의 텍스트 입력 → 임의의 텍스트 출력' 구조 계약을 통해 사실상 모든 자연어 처리 과제에 동일한 아키텍처를 적용할 수 있는 유연성을 제공함.
    • 시스템 절충점의 한계: 극대의 유연성을 확보하는 대가로 연산 효율성, 장문 컨텍스트 유지 비용, 특정 제어 요구사항 충족 등 시스템 최적화 측면에서 명확한 절충(trade-off) 제약을 수반함.
1.2 기존 패러다임: 모델 형태에 하네스를 맞추는 방식

프런티어 모델 연구소들은 막대한 자본과 리스크가 소요되는 대안 아키텍처 탐색 대신, 이미 성능이 검증된 디코더 전용 트랜스포머 구조를 지속적으로 유지해 왔다. 이에 따라 에이전트(Agent) 구축은 고정된 자기회귀(Autoregressive) 모델 형태를 전제로 외부 제어 프로그램인 **하네스(Harness)**를 맞추어 설계하는 '모델 우선(Model-first)' 패러다임으로 제약되어 왔다.

여기서 하네스란 모델을 제어 루프 내에서 호출하고, 검색 도구(Grep 등) 활용이나 터미널 인터페이스 제어 등을 통해 복잡한 단계를 수행하도록 돕는 외부 코드 및 실행 환경을 뜻한다. 기존 방식은 모델 아키텍처의 입출력 형태를 변경하지 않는 대신, 하네스 차원의 제어 로직을 복잡하게 구성하여 시스템적 한계를 극복하려는 접근법이었다.

1.3 제안하는 패러다임: 하네스에 모델 형태를 맞추는 역발상

저자(알렉스 장)는 고정된 모델 형태에 하네스를 맞추던 기존 방식을 뒤집어, 특정 하네스 구조와 과제의 특성에 맞추어 언어 모델의 형태 자체를 변경하는 패러다임 전환을 제안한다. 단기적으로는 하네스 로직만 수정하는 것이 저렴해 보일 수 있으나, 복잡한 하네스 제어 루프와 인퍼런스/컨텍스트 유지 비용을 종합적으로 고려하면, 모델 형태를 하네스에 최적화하여 개조하는 초기 상각 비용(amortized cost)이 장기적인 전체 시스템 비용을 획기적으로 낮출 수 있다는 시스템 분석가적 시각이다.

구분 비교 및 시스템 분석
기존 패러다임 (Model-first) 디코더 전용 트랜스포머 형태 고정: '임의 텍스트 → 임의 텍스트' 계약을 고정한 채 외부 하네스를 복잡하게 구축함. 초기 아키텍처 탐구 비용은 없으나, 장문 컨텍스트 및 반복 호출에 따른 인퍼런스 운영 상각 비용이 지속적으로 높게 발생함.
제안하는 패러다임 (Harness-first) 하네스 및 과제 맞춤형 모델 형태 변경: 특정 제어 루프(예: 제약된 출력 공간)에 맞춰 모델 아키텍처를 변형함. 초기 모델 학습 및 설계 상각 비용이 발생하지만, 간결한 하네스 제어와 극대화된 연산/비용 효율성을 확보함.

2. 기존 아키텍처의 한계 및 절충안(Trade-offs)

2.1 디코더 전용 트랜스포머와 밀집 어텐션의 특성

디코더 전용 아키텍처와 밀집(dense) 다음 토큰 예측 목적함수가 현대 AI 연구의 지배적인 표준으로 자리 잡은 이유는 다음과 같다.

  1. 압도적인 유연성과 범용성: 디코더 전용 구조는 단일 모델 형태만으로 거의 모든 자연어 작업에 직접 적용 가능한 최적의 유연성을 가짐.
  2. 스케일링 과정에서의 리스크 방지: 모델 규모를 확장하는 대규모 투자 과정에서 검증되지 않은 아키텍처를 채택함으로써 발생하는 수백만 달러 규모의 경제적 손실 위험을 회피함.
  3. 자연스러운 학습 목적함수: 임의의 텍스트 수집 데이터에 대해 밀집 다음 토큰 예측(dense next-token prediction)을 수행하는 방식이 가장 손쉽고 직관적인 목적함수로 작동함.

이로 인해 현대 아키텍처 연구는 전체적인 '모델 형태'를 디코더 전용 트랜스포머로 유지한 채, 레이어의 내부 순서나 세부 속성을 조정하는 수준에 주로 집중되어 왔다.

2.2 순환 구조(SSM, 맘바)와 밀집 어텐션의 결합 한계

상태 공간 모델(SSM)이나 맘바(Mamba) 같은 순환 아키텍처(Recurrent architecture)는 연산 효율성 측면에서 주목받았으나, 디코더 전용 트랜스포머 형태를 완전히 대체하지 못했다. 순환 모델이나 선형 어텐션(Gated DeltaNet 등) 단독 구조는 과거 이력 데이터에서 정밀한 팩트 인출(accurate retrieval)을 수행하는 데 기술적 한계를 지니기 때문이다.

이로 인해 전통적으로 최소 하나 이상의 전역 밀집 어텐션(global dense attention) 레이어를 유지해야만 했으며, 결과적으로 새로운 아키텍처들은 트랜스포머 레이어 사이에 수직으로 교차 배치되는 '하이브리드(Hybrid)' 형태로 흡수되어 소비되는 한계를 보였다.

"새로운 순환 구조들이 병렬 잔차 스트림에서 작동하는 대신 어텐션 레이어와 수직으로 교차 배치되는 하이브리드 형태로 채택된 현상은 매우 흥미롭습니다. 이러한 레이어들은 트랜스포머와 구별되는 독자적 특성을 지니고 있어, 하네스 차원에서 더욱 적극적으로 활용될 잠재력이 있습니다."

3. 제한된 출력 공간 모델 사례 분석: 예브(Jev)

3.1 출력을 제약한 사전 채우기 전용(Prefill-only) 모델

타입세이프 AI(Typesafe AI)가 공개한 예브(Jev) 모델은 모델 형태 변경을 통해 새로운 시스템적 절충점(trade-off)을 제시한 대표적인 사례이다.

  • 출력 공간의 명시적 제약: 모델의 출력 공간(output space)을 실수 구간 R[0, 1]로 엄격하게 제약하는 입출력 계약을 채택함.
  • 사전 채우기 전용(Prefill-only) 메커니즘: 출력이 수치 구간으로 제약됨에 따라 텍스트 토큰을 순차적으로 생성하는 디코딩 과정이 불필요하며, 사전 채우기(prefill) 단계만으로 샘플링 연산을 완료함.
  • 극단적 연산 속도 및 비용 최적화: 특정 부류의 판단 및 분류 과제에 대해 프런티어 모델 대비 압도적으로 빠른 응답 속도와 우수한 연산 비용 효율성을 제공함.
3.2 수정된 학습 목표(RLCD)와 하네스 활용

예브와 같이 출력이 제약된 아키텍처를 올바르게 최적화하기 위해서는 기존의 다음 토큰 예측 방식을 벗어난 새로운 학습 목표가 요구된다. 예브는 **'보정된 결정을 위한 강화학습(RLCD, Reinforcement Learning for Calibrated Decisions)'**이라는 수정된 목적함수를 도입하였다.

이처럼 형태가 변경된 모델은 재귀적 언어 모델(RLM, Recursive Language Model) 하네스 등에서 신속하고 유연한 **조건적 판단 로직(Fuzzy condition logic)**을 수행하는 제어 도구로 통합될 수 있다. 예브가 일반적 지능 수준에서 프런티어 모델을 능가하는 것은 아니지만, 특정 조건부 예측 과제에서 탁월한 비용 대 효과를 창출하는 대안적 절충 공간을 증명한다.

4. 에이전트 아키텍처 재설계: 최근 관측과 과거 이력의 분리

4.1 기존 에이전트 궤적(Trajectory) 처리의 비효율성

ReAct 구조의 언어 모델 에이전트는 작업 진행에 따라 궤적(Trajectory)을 컨텍스트에 축적한다. 에이전트의 행동 결정 공식은 다음과 같다.

$$a_{t+1} \sim \pi_\theta(\cdot | H_{<t}, o_t)$$

여기서 정책 $\pi_\theta$는 누적된 과거 이력 $H_{<t}$ (초기 프롬프트 $P$, 과거 행동 $a$, 과거 관측 $o$의 시퀀스)와 가장 최근의 관측 $o_t$를 받아 다음 행동 $a_{t+1}$을 생성한다. 기존 디코더 전용 트랜스포머는 $H_{<t}$와 $o_t$ 전체를 단일 토큰 시퀀스로 전달받아 밀집 어텐션을 수행하며, 이로 인해 두 가지 명확한 비효율성이 발생한다.

  1. 컨텍스트 창 제약과 압축 비용: 궤적이 누적됨에 따라 컨텍스트 한계에 도달하므로 주기적인 외부 '컨텍스트 압축(Compaction)' 작업이 강제됨.
  2. 무차별적 밀집 어텐션 연산: 정밀한 분석이 필요한 최근 관측($o_t$)과 상대적 중요도가 낮아진 과거 이력($H_{<t}$)의 모든 토큰에 대해 무차별적으로 연산량이 큰 밀집 어텐션을 수행함.
4.2 최근 관측과 과거 이력의 분리 설계 가설

저자는 에이전트 궤적 처리 시 시간에 따른 정보 감쇄 특성을 아키텍처에 반영하고, 최근 관측과 과거 이력을 분리 처리하는 새로운 모델 형태 가설을 제안한다.

  1. 시간적 중요도 감쇄의 아키텍처 내재화(Baking in)
    • 에이전트 궤적 내 관측, 도구 호출, 행동 요소는 시간이 흐름에 따라 중요도가 감소(Decaying importance)하는 구조적 특성을 가짐.
    • 이러한 중요도 감쇄 구조를 하네스의 편법적 압축에 의존하지 않고 모델 형태 아키텍처 자체에 직접 내재화(Bake in)함.
  2. 이원화된 컨텍스트 처리 아키텍처
    • 최근 관측 ($o_t$): 정밀한 맥락 분석이 필수적이므로 국소적 밀집 어텐션(Local dense attention)을 적용함.
    • 과거 이력 ($H_{<t}$): 순환 모델(Recurrent model) 아키텍처를 결합하여 이력을 자동으로 압축(Auto-compacting)함으로써 명시적 컨텍스트 압축 작업 없이 장기 메모리를 유지함.
  3. 개략적 파악 기반의 작업 컨텍스트 복원
    • 순환 구조 단독 사용 시 발생하는 정밀 팩트 인출의 한계를 극복하기 위해, 과거 이력에 대해서는 정보의 개략적 파악(Coarse view) 수준만을 유지함.
    • 에이전트가 개략적 파악을 바탕으로 필요한 세부 정보만을 현재의 작업 컨텍스트(Working context)로 선별하여 다시 불러오도록 설계하여, 정밀 인출 능력 손실 없이 연산 효율성을 극대화함.

5. 새로운 모델 형태 연구의 가능성과 주의점

5.1 지식 증류(Distillation) 및 탐구 가능성

단일 라운드 질의응답 중심이었던 과거(2022년~2026년 초)의 연구 환경은 모델 자체의 지능 달성 여부와 스케일링의 가능성을 탐구하는 데 집중되었다. 그러나 프런티어 모델의 높은 역량이 검증되고 이를 재현할 수 있는 오픈 데이터, 오픈 모델, 학습 레시피가 풍부해진 현재 시점에서는 연구 패러다임이 변화하고 있다. 거대한 디코더 전용 트랜스포머의 능력을 다른 형태의 아키텍처로 증류(Distillation)하거나 변형된 모델에 새로운 학습 목표를 적용하는 기술적 환경이 갖추어짐에 따라, 독립 연구자 및 학계에서도 프런티어 연구소의 단순 스케일링 경쟁과 독립된 독창적 모델 형태 탐구가 실질적으로 가능해졌다.

5.2 입증된 성능 개선에 대한 경계 및 연구의 의의
