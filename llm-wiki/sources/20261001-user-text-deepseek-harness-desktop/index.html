DeepSeek Harness for Desktop Is Here

문서 · 2026-10-01

요약

딥시크 하네스는 **"모든 것이 플러그인이다(Everything is a plugin)"**라는 단일 제품 철학을 바탕으로 개발되었습니다.

주제 색인 · 문서 · 2026년 10월 · 보고서 영상

원문

딥시크 하네스 데스크톱 공개 보고서 (v0.2 프리뷰)

1. 주요 변화

1.1 데스크톱 앱 지원 및 전반적 개선
  • v0.2 프리뷰 출시 및 지원 OS: 딥시크 하네스(DeepSeek Harness) v0.2 프리뷰 버전이 데스크톱 애플리케이션 형태로 공식 출시되었으며, 맥오에스(macOS) 및 윈도(Windows) 운영체제를 지원합니다.
  • 기본 내장 기능 탑재: 일상적인 업무와 개발 작업에 필요한 핵심 도구들이 기본 탑재되어 제공되므로 복잡한 별도 설정 없이 즉시 활용할 수 있습니다.
  • 대화 화면 내 정보 표시 커스텀: 작업 스타일에 맞추어 대화 화면 내 에이전트 진행 단계 표시 유무, 기능별 정보 출력의 상세 수준을 사용자가 직접 유연하게 커스텀하여 설정할 수 있습니다.
1.2 파일 및 코드 변경 미리보기
  1. 대화 창 내 코드 변경 검토: 대화 화면 내부에서 에이전트가 생성하거나 수정한 코드 변경 사항을 직접 확인하고 정밀하게 검토할 수 있습니다.
  2. 우측 사이드바 기반 작업 흐름: 우측 사이드바에서 파일 미리보기, 코드 검사, 전체 변경 사항을 심층 검토한 후, 추가적인 수정 요구사항을 대화 창을 통해 딥시크 하네스에 전달하여 피드백을 반영하는 직관적인 작업 흐름을 제공합니다.
  3. 로컬 응용 프로그램 직접 연동: 작업 중 생성된 파일이나 변경된 코드는 사용자의 로컬 환경 내 응용 프로그램으로 직접 열어 추가 편집 및 후속 작업을 지속할 수 있습니다.
1.3 플러그인 관리 및 실험적 제작자 모드

딥시크 하네스는 **"모든 것이 플러그인이다(Everything is a plugin)"**라는 단일 제품 철학을 바탕으로 개발되었습니다. 개별 단일 도구부터 전체 제품 인터페이스 영역에 이르기까지, 사용자는 플러그인을 추가하고 결합하여 자신만의 작업 환경을 자유롭게 확장할 수 있습니다.

구분 주요 기능 및 제어 방식
플러그인 관리자 (Plugin Manager) - 터미널 명령어 실행 없이 패키지 이름 입력만으로 손쉽게 플러그인 설치 가능<br>- 설치된 플러그인의 비활성화 및 삭제 관리 기능 지원<br>- 플러그인의 제공 출처(where they come from) 및 상세 설명 정보를 한곳에서 명확히 확인 가능
실험적 제작자 모드 (Experimental Creator Mode) - 사용자가 원하는 기능을 자연어로 설명하면 딥시크 하네스가 실시간으로 플러그인을 직접 생성 및 설정<br>- 생성된 플러그인은 즉시 적용되며, 향후 재사용을 위해 자동 저장되어 플러그인 관리자 목록에 자동 등록
1.4 자동화 태스크 (Automation Task)
  • 반복 작업 예약 및 관리: 정기적으로 반복되는 업무를 예약하고 효율적으로 관리할 수 있는 전용 플러그인 기능입니다.
  • 플러그인 패널 내 활성화: 필요할 때 언제든지 '플러그인(Plugins)' 패널에서 해당 기능을 활성화하여 사용할 수 있습니다.
  • 체계적인 세부 관리: 태스크 실행 기록 검토, 반복 수행 주기 조정, 작업 지침(Instructions) 업데이트 등 상세 제어 기능을 제공합니다.
  • 다양한 미리보기 스타일 제공: 작업 진행 상황 추적, 단계별 처리 과정 이해, 문제 해결(troubleshooting)을 도모할 수 있도록 다각화된 미리보기 방식을 지원합니다.

2. 활용 예시

2.1 문서·데이터 정리 및 콘텐츠 생성
  • 문서 및 데이터 종합 처리: 문서, 스프레드시트, PDF 파일을 전달하여 정보의 요약 및 정리, 데이터 분석, 차트 생성, 발표용 슬라이드 제작을 지시할 수 있습니다.
  • 다양한 형태의 콘텐츠 생성: 여행 가이드 제작 요청 시 슬라이드 덱(Slide deck) 형태뿐만 아니라 HTML 웹 페이지 형태로도 동시에 결과물을 생성할 수 있습니다.
2.2 실시간 플러그인 제작 및 자동화 예약 예시
  • 실시간 플러그인 생성 요청: 사용자가 프롬프트로 요구사항을 전달하여 실시간 뽀모도로 타이머(Pomodoro timer) 플러그인을 제작 및 등록하도록 지시하는 예시.
  • 주간 단위 자동화 태스크 설정: 매주 인공일반지능(AGI) 달성 여부를 정기적으로 조사 및 확인하도록 자동화 태스크 지침을 예약 설정하는 예시.

3. 발표의 범위와 한계

3.1 공급자 발표 주장 및 수치 데이터의 한계

[주의] 공급자 발표 데이터 및 지표의 한계

공급자(딥시크) 발표에 따르면, 공식 딥시크 API 이용자 기준 딥시크 하네스는 일일 활성 이용자 수(DAU) 및 일일 세션 수(daily sessions) 등의 지표에서 가장 널리 활용되는 코딩 에이전트로 집계되었습니다. 또한 공식 API로 모델에 접근하는 이용자 중 약 60%가 제3자(외부) 플러그인을 활용하고 있다고 밝혔습니다.

필수 유의 사항: 본 보고서에 포함된 모든 이용자 수치, 순위, 활용 비율 데이터는 공급자(딥시크) 측의 내부 집계 발표 주장에 한정됩니다. 해당 수치는 전체 코딩 에이전트 시장을 대상으로 독립 기관의 검증을 거친 객관적 통계가 아니므로, 시장 전체의 객관적 점유율이나 검증된 표준 지표로 확대 해석해서는 안 됩니다.

3.2 출처 및 미확인 정보에 대한 제한
  • 제공 원문 기반 작성: 본 보고서는 사용자가 제공한 텍스트 자료(DSH.txt)를 기반으로 구성되었으며, 제3자 기관에 의한 외부 사실 확인(Fact-check)을 거치지 않았습니다.
  • 원문 내 공식 접속 정보: 원문에 게재된 설치 및 접속 주소(https://deepseek.com/harness/)와 피드백 접수 이메일(harness@deepseek.com)은 원문 출처에 기술된 공식 안내 정보이나, 본 보고서 작성 과정에서 별도의 독립적인 외부 입증 절차를 진행한 것은 아닙니다.
  • 미수록 정보의 작성 배제: 원문에 서술되지 않은 수치나 정보(공식 출시 일자, 가격 정책, 객관적 성능 시험 지표, 타사 제품과의 비교 순위, 보안 보증 규격, 실제 검증된 사용 결과 데이터)는 일절 추측하거나 왜곡하여 추가하지 않았습니다.

4. 향후 계획 (미출시 기능 및 로드맵)

4.1 향후 개발 예정 기능 (현재 미출시)
  1. 브라우저 및 기타 그래픽 사용자 인터페이스(GUI) 응용 프로그램 자동화
  2. 개인화된 장기 기억(Long-term memory) 기능
  3. 에이전트 팀(Agent teams) 기능의 효과성 강화 및 사용 편의성 개선
  4. 원격 및 모바일 접근 환경 지원
  5. 세션 공유 및 협업 기능 탐색
  6. 샌드박스(Sandbox) 기능 확장 및 보안성 강화
4.2 플러그인 생태계 및 모델 연동 로드맵
  • 공식 플러그인 마켓플레이스 구축: 제3자 플러그인의 탐색, 설치, 관리를 일관되고 단순하게 처리할 수 있도록 공식 플러그인 마켓플레이스 구축을 추진할 예정입니다.
  • API 안정성 및 버전에 따른 호환성 확보: 한층 명확하고 안정적인 플러그인 API를 제공하며, 차기 버전 출시 시 기능 파괴적 변경(Breaking changes)을 최소화 및 회피하고 상·하위 버전 간 호환성을 유지하기 위한 다각도의 기술적 노력을 기울입니다.
  • 신규 딥시크 모델과의 지속적 최적화: 향후 공개될 신규 딥시크 모델에 맞추어 하네스를 지속적으로 최적화하고, 모델 학습을 통해 실전 코딩 및 업무 성능을 끌어올리며 제품 기능 혁신을 위한 모델 연구를 긴밀히 연계합니다.
  • 오픈소스·협업 중심의 개발자 생태계 비전 확립: 더 많은 플러그인 개발자가 생태계에 참여하도록 독려하여 AI의 가능성을 확장하고, 오픈소스(open source), 협업(collaborative), 재사용성(reusable), 조합 가능성(composable)을 갖춘 AI 제품을 함께 만들어가는 것을 주요 로드맵으로 설정하고 있습니다.
