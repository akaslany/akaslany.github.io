1. 개요 (Overview)

Liquid AI는 2026년 10월 27일, 특화 지능(Specialized Intelligence) 구현을 위한 차세대 리퀴드 파운데이션 모델(Liquid Foundation Models) 시리즈인 LFM3를 공식 발표하였다. LFM3는 텍스트, 비전, 오디오, 옴니(Omni), 의사결정(Decision) 등 다양한 모달리티를 단일 공유 백본(Shared Backbone) 상에 통합한 멀티모달 모델 패밀리이다. 이번 첫 번째 출시에서는 2B 파라미터 급의 모델 6종이 공개되었으며, 공통 백본으로 LFM3-1.7B-Base를 활용한다. [사실]

LFM3 시리즈는 숏 컨볼루션(Short Convolution), 슬라이딩 윈도우 어텐션(SWA), 글로벌 어텐션(Global Attention)을 결합한 새로운 트라이하이브리드(Tri-hybrid) 아키텍처를 기반으로 설계되었다. 22조(22T) 토큰의 사전 학습 데이터를 바탕으로 구축된 LFM3는 기존 LFM2 시리즈 대비 표현력을 대폭 향상시키면서도 온디바이스(On-device) 추론 효율성을 유지하는 데 초점을 맞추었다. 작고 빠른 모델 스펙을 통해 단일 GPU 환경에서의 로컬 파인튜닝(Fine-tuning) 및 엣지 디바이스 배포를 용이하게 지원한다. [사실]

발표된 LFM3의 베이스 모델 및 포스트 트레이닝 모델은 개방형 가중치(Open-weight) 형태로 제공되며, Hugging Face, Liquid AI Playground, Liquid AI API를 통해 즉시 이용할 수 있다. 소스 문서에 명시된 공식 가중치 배포 및 API 제공 여부는 확정된 객관적 사실이며, 기존 LFM2.5 모델 대비 성능 향상 및 엣지 디바이스 최적화 효율성에 관한 언급은 소프트웨어 및 개발사 측의 주장에 해당한다. [사실 / 소스 주장]

2. 주요 논점 (Key Points & Arguments)

2.1. 아키텍처 혁신 및 하드웨어 최적화 (Architectural Innovation & Hardware Optimization)

LFM3는 에이전트(Agentic) 사용 환경과 긴 컨텍스트(Long-context)에 대한 빠른 추론 속도를 확보하기 위해 자동화된 하드웨어 루프 검색(Hardware-in-the-loop search)을 거쳐 설계되었다. [사실]

LFM3-1.7B-Base 레이어 구성 및 아키텍처 특성
구성요소 상세 설명
총 레이어 수 및 패턴 총 24개 레이어 구성.<br>교차 레이어 패턴: C C F C S C F C S C F C S C F C S C F C S C F C C<br>(C: Gated Short Conv 13개, F: Full Attention GQA 6개, S: Sliding Window GQA 5개)
트라이하이브리드 조합 게이티드 숏 컨볼루션(13개), 슬라이딩 윈도우 어텐션(5개), 글로벌 GQA(6개) 레이어 교차 배치
숏 컨볼루션 (Short Conv) 게이티드 숏 컨볼루션 구조 적용, 커널 크기(Kernel Size)를 기존 LFM2의 3에서 7로 확대
슬라이딩 윈도우 어텐션 (SWA) 윈도우 크기 256 토큰 적용, 연산 속도와 품질 간의 최적 트레이드오프 제공
글로벌 어텐션 (GQA) Grouped Query Attention 적용, 전체 컨텍스트 문맥 파악 담당
헤드별 게이트 어텐션 헤드 출력단에 시그모이드(Sigmoid) 게이트를 적용하여 비활성화 제어, 양자화 및 학습 안정성 향상
부분 RoPE (Partial RoPE) 글로벌 어텐션 레이어에서 각 헤드의 고주파 영역 절반에만 RoPE 적용 (SWA는 전체 RoPE 유지)
샌드위치 노름 (Sandwich Norm) 각 블록의 입력과 출력을 모두 정규화하여 활성화 값 스케일링 유지
어휘집 및 컨텍스트 128K 어휘집(Vocabulary) 채택 (비라틴 문자 토큰화 효율화) 및 256K 컨텍스트 윈도우 지원
하드웨어 최적화 및 학습 데이터 구성
  • 하드웨어 루프 검색 환경 [사실]: LFM2의 2개 디바이스 환경에서 확장하여 총 14개의 디바이스 및 백엔드 조합(삼성 갤럭시 S26 울트라, 원플러스 15, 라즈베리 파이 5, 애플 M4 Max, AMD 라이젠 AI, Arm 및 x86 클라우드 CPU, GPU, 퀄컴 헥사곤 NPU 등)에서 검색 및 평가 진행.
  • 사전 학습 데이터 [사실]: 22T(22조) 토큰으로 사전 학습 수행. 과학 논문, 저장소 수준 코드, 수학 데이터 비율 대폭 확대.
  • 미드트레이닝 (Mid-training) [사실]: 고품질 정제 데이터 3.5T(3.5조) 토큰을 추가 학습. 에이전트 트레이스 및 도구 호출 데이터를 포함하며 컨텍스트 윈도우를 256K로 확장.
  • 긴 컨텍스트 속도 향상 [소스 주장]: 엣지 디바이스 상의 8K 토큰 컨텍스트 환경에서 LFM3-1.7B가 LFM2-1.2B 대비 약 25% 빠른 추론 속도를 제공함.
2.2. 멀티모달 모델 파이프라인 및 포스트 트레이닝 (Multimodal Lineup & Post-Training Pipeline)

LFM3 패밀리는 공통 백본인 LFM3-1.7B-Base에서 파생된 2B 클래스 모델 6종으로 구성된다. [사실]

LFM3-1.7B-Base ──┬──> SFT ──> Mixed RL ──> MOPD ──> Agentic RL ──> LFM3-1.7B (Text)
                 ├──> Mid-train (Vision) ──> SFT ──> Vision RL ──> MOPD ──> LFM3-VL-2B (Vision) ──> SFT ──> d1-2B (Decision)
                 ├──> Mid-train (Audio)  ──> SFT ──> Text/Audio RL ──> Agentic RL ──> LFM3-Audio-2B (Audio)
                 └──> Mid-train (Omni)   ──> SFT ──> Text/Vision/Audio RL ──> LFM3-Omni-2B (Omni) ──> SFT ──> D1-Omni-2B (Decision)
파생 모델 라인업
  1. LFM3-1.7B (Text): 256K 컨텍스트 윈도우를 갖춘 로컬 에이전트 및 특화 애플리케이션용 텍스트 모델. [사실]
  2. LFM3-VL-2B (Vision): 1.9B 파라미터 규모의 비전 모델. 비디오 이해, 단계별 추론(Thinking), 공간 및 체화 추론(Embodied reasoning) 기능 제공. [사실]
  3. d1-2B (Decision): LFM3-VL-2B에서 파생되어 감독 미세조정(SFT)을 거친 비전 기반 의사결정 모델. [사실]
  4. LFM3-Audio-2B (Audio): 오디오 미드트레이닝, SFT, 텍스트/오디오 RL 및 에이전틱 RL을 거쳐 병합된 오디오 모델. [사실]
  5. LFM3-Omni-2B (Omni Generative): 옴니 미드트레이닝 및 텍스트/비전/오디오 RL을 거쳐 병합된 생성형 옴니 모델. [사실]
  6. D1-Omni-2B (Omni Decision): LFM3-Omni-2B에서 SFT를 거쳐 파생된 옴니 의사결정 모델. [사실]
4단계 포스트 트레이닝 파이프라인 (Post-Training Pipeline)
  • 1단계: 감독 미세조정 (SFT) [사실]: 대화, 추론, 툴 호출, 에이전트 트레이스 등을 포함한 다양한 작업에 대해 1.75T(1.75조) 토큰 학습 진행.
  • 2단계: 혼합 강화학습 (Mixed RL) [사실]: 수학, 코드, SQL, 구조화된 출력 등 다중 영역을 동시 학습. 답변의 간결성을 유지하기 위해 길이 패널티(Length penalty) 보상 적용.
  • 3단계: 다중 영역 온정책 증류 (MOPD) [사실]: 코드, 수학, 도구 사용, 긴 컨텍스트, 에이전트 작업, 기업 워크플로우 등 6개의 전문 RL 교사 모델의 지식을 단일 모델로 증류.
  • 4단계: 에이전틱 강화학습 (Agentic RL) [사실]: 웹 브라우징부터 사무 작업까지 실제 에이전트 하네스(Harness) 내부에서 작업 시뮬레이션을 수행하여 배포 환경 최적화.
2.3. 벤치마크 성과 및 추론 성능 평가 (Benchmark & Inference Performance Analysis)
주요 벤치마크 결과 분석

  • 텍스트 모델 (LFM3-1.7B)

    • [사실] LiveClaw(45.60), BFCL V4(71.39), IFEval(96.66) 등의 지표 기록.
    • [소스 주장] LFM3-1.7B는 35% 적은 파라미터를 사용함에도 이전 세대인 LFM2.5-2.6B의 성과를 능가하며, 지시 이행 및 함수 호출(BFCL, ToolSandbox)에서 우수함. 웹 및 비즈니스 앱 장기 작업(WebArena-Verified 38.42, AutomationBench 41.29)에서 Qwen3.5-9B(28.94 / 15.10)를 크게 상회함.
    • [작성자 해석] 에이전틱 특화 RL 및 MOPD 기법 적용이 파라미터 체급 한계를 극복하고 도구 활용 및 긴 컨텍스트 태스크 성능을 끌어올리는 데 핵심적인 역할을 한 것으로 분석됨.

  • 비전 모델 (LFM3-VL-2B)

    • [사실] 62개 비전 평가 항목 평균 점수 71.4점 기록 (General 66.0, Perception 75.6, Document/OCR/Chart 83.9, Math/Logical 68.8, Visual Grounding 77.3, Video 61.2 등).
    • [사실 / 소스 주장] GUI 이해 (GUI Understanding: 83.1점) 및 비전 에이전틱 (Agentic: 42.5점) 항목에서 동급 및 대형 경쟁 모델인 Qwen 3.5 2B(GUI 67.2 / Agentic 15.2) 및 Gemma 4 E2B(GUI 44.3 / Agentic 23.8)를 압도적인 격차로 제침. 6배 이상 큰 Gemma 4 12B(GUI 76.1 / Agentic 43.6) 및 Gemini 3.5 Flash Lite(GUI 71.0 / Agentic 62.4)와 비교해도 높은 GUI 및 에이전틱 시각 처리 경쟁력을 입증함.
    • [작성자 해석] 단계별 추론(Thinking) 및 시각적 에이전틱 RL 도입이 단순 이미지 인식을 넘어 복잡한 GUI 조작 및 다단계 문제 해결 능력을 획기적으로 개선시켰음을 보여줌.
온디바이스 및 GPU 추론 측정 조건 (Methodology) [사실]
  • 엣지 디바이스 추론 조건: llama.cpp 프레임워크 사용, Q4_0 GGUF 양자화 적용, 배치 크기 1, 출력 100 토큰(텍스트) / 256 토큰(비전). 텍스트 모델은 32K 컨텍스트 조건, 비전 모델은 F16 비전 엔코더 및 512x512 이미지 + 1,024 텍스트 토큰 입력 조건.
  • GPU 추론 조건: 단일 NVIDIA B300, BF16 정밀도, SGLang 0.5.22 환경. 텍스트는 1,024 토큰 입력 / 256 토큰 출력, 비전은 512x512 이미지 + 1,024 토큰 입력 / 256 토큰 출력 조건 (3회 측정 평균치).
  • 지연 시간 측정 조건: 단일 NVIDIA B200 GPU, 무작위 요청 트래픽 환경. LFM 모델은 RIPL 엔진, 타 모델은 vLLM 엔진 적용 후 p95 요청 지연 시간 측정.

5. 한계와 불확실성 (Limitations & Uncertainties)

  • 상세 벤치마크 데이터 미비: 발표 자료 내 텍스트(LFM3-1.7B) 및 비전(LFM3-VL-2B) 모델에 대한 성능 지표는 정밀하게 제공되었으나, LFM3-Audio-2B, LFM3-Omni-2B, d1-2B, D1-Omni-2B 모델에 대한 정량적 벤치마크 수치 및 성능 결과는 수록되어 있지 않음.
  • 파라미터 세부 수치 불명확성: LFM3-1.7B(1.7B) 및 LFM3-VL-2B(1.9B)를 제외한 나머지 2B 클래스 파생 모델들의 정확한 개별 파라미터 수치 정보가 소스 문서 내에 구체적으로 명시되지 않음.
  • 학습 인프라 스펙 정보 부재: 22T 토큰 사전 학습 및 미드트레이닝 과정에 사용된 클러스터 규모, GPU 구동 장비 구성 및 소비 전력 등 하드웨어 인프라 세부 사항을 확인할 수 없음.
  • 검증 범위의 한계: 본 보고서의 분석 내용은 전적으로 제공된 소스 문서(Liquid AI 블로그)의 기술된 데이터에만 의존하므로, 외부 제3자 검증 기관을 통한 교차 검증 데이터는 반영되지 않음.
