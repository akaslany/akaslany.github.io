Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training

논문 · 2026-08-09

요약

사전공개 논문은 일부 모델에서 중간층 하나의 강화학습이 전체 층 훈련과 대등하거나 앞섰다고 보고했다.

문서 정보

  • 원제: Is One Layer Enough? Training a Single Transformer Layer Can Match Full-Parameter RL Training
  • arXiv 번호: 2607.01232v2 (Preprint, 동료 검토 전 단계)
  • 핵심 요약: LLM의 강화학습 시 모든 층을 훈련하는 대신, 특정 중간층 하나만 훈련해도 전체 훈련과 대등하거나 더 높은 성능을 얻을 수 있음을 발견하고 그 구조적 원인을 분석한 연구입니다. 본 리포트는 논문 본문과 상세 팩트카드를 기반으로 작성되었습니다.
2. 비전공자를 위한 배경지식: RLVR이란 무엇인가?

**RLVR(검증 가능한 보상을 통한 강화학습)**은 정답이 객관적으로 확인 가능한 태스크(수학 문제 풀이, 코드 작성 등)를 통해 모델을 정렬하는 기법입니다. 모델이 내놓은 결과가 정답이면 보상을 주고, 틀리면 주지 않는 방식으로 스스로 정답에 이르는 경로를 학습하게 합니다.

  • 기존 방식: 모델을 구성하는 수십 개의 모든 층(Layer)의 파라미터를 동시에 업데이트합니다.
  • 본 논문의 의문: "모든 층이 강화학습에 똑같이 기여할까? 혹시 특정 층이 개선의 핵심은 아닐까?"라는 질문을 던졌습니다.
3. '층별 기여도(Layer Contribution)'의 수사적·수학적 정의

연구진은 각 층의 중요도를 정량화하기 위해 층별 기여도($C(k)$) 지표를 도입했습니다. 이는 '전체 층을 훈련했을 때의 개선분' 대비 '특정 층 하나만 훈련했을 때의 개선분'의 비율을 의미합니다.

  • 수학적 정의: $$C(k) = \frac{S_k - S_{base}}{S_{full} - S_{base}}$$

    • $S_k$: $k$번째 층 하나만 훈련했을 때의 성능
    • $S_{base}$: 기초 모델의 성능
    • $S_{full}$: 전체 층을 훈련했을 때의 성능

  • 데이터 해석의 주의점: 예를 들어 Qwen3-1.7B 모델의 10번 층 기여도가 **1.14(114%)**라는 것은, 전체 층을 다 훈련해서 얻은 성능 향상 폭을 100이라고 했을 때 단일 층 훈련만으로 그보다 14% 더 큰 향상을 이루어냈다는 뜻입니다. (절대적인 정확도 수치가 아닙니다.)

4. 핵심 발견: "RL 적응의 중심축(Central Axis)은 중간층에 있다"

연구진은 7개 모델, 2개 모델 계열, 3개 알고리즘에 걸친 광범위한 실험을 통해 고기여 층이 네트워크 깊이의 **중간 구간(40~60%)**에 집중되어 있다는 공통된 패턴을 발견했습니다.

    • 전체 층 훈련(Full RL): 50.8
    • 10번 층(Layer 10) 단독 훈련: 51.8 ($C=1.14$)
5. [기술 체크] 오해 바로잡기: "훈련 계산량이 1/L로 줄어드는가?"

파라미터 업데이트를 한 층만 한다고 해서 훈련 속도가 드라마틱하게 빨라지는 것은 아닙니다.

  1. 역전파(Backpropagation)의 특성: 업데이트 대상은 한 개 층이지만, 그 층의 가중치를 얼마나 수정할지 결정하는 경사(Gradient) 값을 계산하려면 데이터가 여전히 전체 네트워크의 모든 층을 통과해야 합니다.
  2. 구조적 필수성: 나머지 층들은 업데이트되지 않을 뿐, 데이터를 전달(Forward)하고 오차 신호를 전달(Backward)하는 통로 역할을 수행해야 하므로 전체 모델이 여전히 메모리와 연산에 필요합니다.
6. 실험의 일관성: 모델의 고유한 구조적 특성

중간층의 높은 기여도 패턴은 이 논문의 Qwen3-1.7B 실험에서 데이터나 태스크가 바뀌어도 유의한 순위 상관을 보였습니다. 이는 저자들이 보고한 경험적 일관성이며, 모든 모델에 대한 구조적 법칙을 통계적으로 증명한 것은 아닙니다.

  • 데이터셋 변경: 수학 데이터셋을 바꿔도 층별 기여도 순위의 상관계수는 $\rho=0.76(p < 0.001)$로 매우 높았습니다.
  • 태스크 변경: 수학과 코드라는 서로 다른 도메인 사이에서도 $\rho=0.59(p < 0.001)$의 유의미한 상관관계를 보였습니다.
7. 실용적 전략: '선별적 층(Selected-Layer)' 훈련의 성과

연구진은 단일 층 실험을 넘어, 기여도가 높은 층들만 골라 훈련하는 전략을 제시했습니다.

  • 용어 정의: **B10(Best 10)**은 기여도 상위 10개 층을, **W10(Worst 10)**은 하위 10개 층을 의미합니다.
  • 성과 비교 (Qwen3-8B):
    • 전체 층 훈련(Full RL): 66.43 ± 0.40 (3회 평균값)
    • 상위 10개 층 선택 훈련(Only B10): 69.11 ± 0.10
    • 참고: 논문 Table 2의 단일 실행 수치와 Section 4의 3회 평균 수치에 미세한 차이가 있으나, 선별 훈련이 우세하다는 결론은 동일합니다.
8. 심층 분석: 왜 중간층 하나로 충분한가? (전문가적 통찰)

본 연구가 제공하는 가장 중요한 기술적 통찰은 '다양성'과 '파라미터 공간'의 효율성입니다.

  • 층별 출력의 다양성(Diversity): 서로 다른 고기여 층만 훈련한 모델들은 해결한 문제 집합이 완전히 같지 않았습니다. 상위 기여 층들 간의 정답 집합 Jaccard similarity는 약 **34.1%**로 보고됐고, 이를 다수결(Majority Voting)로 합칠 경우 해당 OlympiadBench 실험에서 전체 훈련 모델보다 높은 성능(26.9% → 33.6%)을 보였습니다. 이것은 출력의 상호 보완성을 시사하지만, “각 층이 서로 다른 지식을 저장한다”는 직접 증거는 아닙니다.
  • 가중치 변화량의 관찰: 실험 결과(Figure 9), 전체 훈련 시 층별 가중치 변화량은 대체로 비슷했으며, 변화량만으로 기여도 차이를 설명하지 못했습니다. 저자들은 중간층의 파라미터 하위 공간이 RL 적응에 더 유리할 가능성을 제시하지만, 그 원리에 대한 이론은 아직 확립되지 않았습니다.
9. 이 연구의 한계와 경계 (비판적 검토)
  • [ ] 도메인 편향: contribution-guided·선별 층 훈련 전략의 개선 효과는 현재 수학 추론에서 검증되었습니다. 코드·agentic task에서 관찰된 것은 주로 층별 contribution 패턴이며, 같은 전략의 성능 개선 검증은 future work입니다.
  • [ ] 부분 스캔: Qwen2.5 agentic 모델과 DeepSeek-Distilled-Qwen-7B는 계산 제약으로 대표 층만 훈련했으므로 전 층 순위를 직접 확인한 결과가 아닙니다.
  • [ ] 실질 자원 데이터 부재: 실제 시간(Wall-clock time)이나 VRAM 절감에 대한 구체적 벤치마크 수치가 부족합니다.
  • [ ] 이론적 근거 미비: 왜 중간층이 '고효율 하위 공간'을 형성하는지에 대한 심층적인 이론은 아직 연구 과제로 남아 있습니다.
  • [ ] 모델 규모의 한계: 주로 8B 이하 Qwen 계열 모델에서의 실험 결과이며, 독립적인 재현 절차가 필요합니다.
10. 결론: 실무적 의미와 향후 관전 포인트

이 연구는 자원이 한정된 LLM 훈련 환경에서 모든 파라미터를 업데이트하는 비효율을 줄일 수 있는 가능성을 열어주었습니다. 특히 중간층에 집중하는 전략은 복잡한 프로파일링 없이도 적용 가능한 강력한 휴리스틱이 될 수 있습니다.

[향후 검증 질문 — 제작 검토] 논문이 다루지 않은 70B 이상 모델, MoE 아키텍처, 다른 RL 목적에서도 중간층 집중이 재현되는지 확인해야 합니다. 반대 결과가 나오면 이번 발견의 일반화 범위를 Qwen 계열 중소 규모와 해당 실험 설정으로 낮춰야 합니다.
