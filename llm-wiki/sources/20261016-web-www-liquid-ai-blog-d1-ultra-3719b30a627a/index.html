1. 개요

리퀴드 에이아이(Liquid AI)는 2026년 10월 15일 최첨단 성능을 갖춘 다중 모달(multimodal) 의사결정 모델인 '디원 울트라(d1-ultra)'의 공식 출시를 발표하였다. 본 모델은 단순하고 일반적인 결정 과제를 넘어서, 현실 세계의 복잡하고 다루기 힘든(messier) 유스케이스를 해결하는 데 특화되어 개발되었다.

d1-ultra의 대표적인 실제 적용 사례로는 사양서와 대조하여 회로 기판의 결함을 감지하는 작업이나, 고객이 제출한 사진을 기반으로 손해 배상 청구 건을 검증하는 작업 등이 포함된다. 이는 기존 의사결정 모델들이 손쉬운 작업 영역에서만 제한적으로 유효했던 한계를 극복하기 위함이다.

현재 d1-ultra는 리퀴드 에이아이 API(Liquid API)를 통해 입력 토큰 1,000,000개당 0.042 달러($0.042)의 비용으로 즉시 이용할 수 있다. 1회 순방향 패스 기반의 확률 반환 메커니즘과 정교한 확률 보정(calibration) 기술을 바탕으로 고도화된 의사결정 성능을 제공하며, 향후 다양한 모델 크기 제공, 지연 시간(latency) 단축, 신규 기능 추가 등 지속적인 성능 업데이트가 예정되어 있다.

2. 주요 논점

2.1 d1-ultra의 핵심 기능 및 작동 방식

본문 내 'What d1-ultra does' 섹션에 명시된 d1-ultra의 기술적 특성 및 비구조화 데이터 처리 방식은 다음과 같다.

  • 입력 데이터 다중 모달성: 텍스트, 이미지, 또는 두 매체가 혼합된 비구조화 데이터(unstructured data)와 함께 하나 이상의 질문을 입력받는다.
  • 1회 순방향 패스(One Forward Pass): 단 한 번의 순방향 패스로 입력 전체를 통합적으로 읽어 들여 연산 효율성을 극대화한다.
  • 토큰 미생성 및 확률 반환: 기존 생성형 모델과 달리 텍스트 토큰을 생성하지 않으며, 각 가능한 답변에 대한 확률(probability)만을 직접 반환한다.
2.2 질문 유형 및 입력 형태

d1-ultra는 기존 모델인 d1과 동일하게 다음 3가지 유형의 질문 구조를 지원한다.

  • noul: 예/아니오(yes/no) 형태의 단답형 질문으로, 0에서 1 사이의 확률값으로 응답한다.
  • Choice: 여러 라벨 항목 중 하나를 선택하는 질문으로, 각 라벨별 확률값을 제공한다.
  • Score: 정의된 척도(scale) 상에서의 위치를 결과값으로 제시한다.
2.3 성능 평가 및 확률 보정(Calibration) 결과

본문 내 'Results' 섹션에서는 단순 정확도 추구 이상의 기술적 성과와 평가 결과를 다룬다.

  • 기술적 배경 및 보정의 필요성: 의사결정 모델에서는 단순 정확도(Accuracy)뿐만 아니라 모델이 제시하는 확률의 신뢰도가 필수적이다. 기존 의사결정 모델들은 자신의 예측에 대해 과잉 확신(overconfident)하는 경향을 보여 현실 세계의 복잡한 문제 적용 시 오류를 유발하였다. d1-ultra는 더 큰 오픈 웨이트(open-weight) 모델에 리퀴드 특화 커스텀 및 학습 파이프라인을 적용하여, 현실 문제에 신뢰할 수 있는 보정된 확률을 출력하도록 맞춤 학습되었다.
  • 벤치마크 평가 및 우수성: 기존 모델인 d1 및 제브 1.14(Jev 1.14)를 대상으로 총 112개의 고유 평가를 수행하였으며, 동일한 가격 조건에서 Jev 1.14 대비 우수한 정확도와 보정 성능을 입증하였다. 또한, 아티피셜 애널리시스 의사결정 인덱스(Artificial Analysis Decision Index)에서 타 의사결정 모델 대비 최소 8점 이상 우수한 성과를 기록하였다.
  • 실무 데모 제공: d1-ultra의 실제 동작 사례는 디원 플레이그라운드(d1 Playground, d1.liquid.ai)를 통해 직접 확인할 수 있다.
평가 범주 기능 및 성능 상세
기반 아키텍처 대형 오픈 웨이트 모델 기반 + 리퀴드 전용 커스텀 기법 및 훈련 파이프라인 적용
평가 규모 d1 및 Jev 1.14 모델과 총 112개 고유 평가(unique evaluations) 비교 수행
확률 보정 특성 과잉 확신(overconfident) 문제 해결을 통해 현실 예측 확률의 신뢰성 극대화
벤치마크 지표 아티피셜 애널리시스 의사결정 인덱스에서 타 모델 대비 최소 8점(8 points) 이상 우수
2.4 가격 정책 및 API 이용 가이드

본문 내 'Availability and Pricing' 섹션에서는 요금체계, 토큰 계산 방식, API 연동 구조 및 향후 로드맵을 제시한다.

  • 가격 체계: 입력 토큰 1,000,000개당 0.042 달러($0.042)가 부과되며, 출력 토큰 비용은 발생하지 않는다.
  • 이미지 토큰 산정: 이미지는 텍스트와 동일한 비율로 토큰화된다. 32×32 피스 패치당 1.5 토큰으로 계산되며, 1024×1024 크기 이미지는 1,536 토큰으로 환산된다.
  • 질문 단위 청구: 각 질문은 텍스트 및 포함된 모든 이미지를 포함하여 별도의 프롬프트로 계산 및 청구된다.
  • 배포 및 플랫폼 연동: 현재 리퀴드 에이아이 API(Liquid AI API)에서 즉시 이용 가능하며, 향후 버셀(Vercel) 및 오픈루터(OpenRouter) 플랫폼을 통해서도 확장 제공될 예정이다.
  • API 구현 파이썬 코드 구조 분석:
    • 라이브러리 구성: base64, os, requests 모듈을 활용한다.
    • 이미지 전처리: board.jpg 바이너리 데이터를 베이스64(base64)로 인코딩하여 텍스트 문자열 형식으로 전환한다.
    • 엔드포인트 호출: POST 방식으로 https://api.liquid.ai/decisions/v1/systemone 엔드포인트에 요청을 전송한다.
    • 인증 헤더: LIQUID_API_KEY 환경 변수를 호출하여 Authorization: Bearer 형태의 토큰 인증을 수행한다.
    • 요청 페이로드(JSON) 구조: 모델명(model: "d1-ultra"), 인코딩된 이미지 배열(images), 현재 상황 설명(state: "Camera image of a circuit board..."), 그리고 질문 객체(questions)로 구성된다. 질문 객체 내부에는 질문 키(defect), 질문 유형(type: "noul"), 세부 지시문(instructions: "Does this circuit board have a defect?")을 정의한다.
    • 결과 추출: 응답 JSON 객체 내 response.json()["answers"]["defect"]["noul"] 경로를 통해 해당 질문에 대한 최종 확률값을 반환받는다.
  • 지속적 개발 로드맵: 리퀴드 에이아이는 다양한 크기의 의사결정 모델 개발, 신규 기능 추가, 의사결정 품질 향상, 지연 시간(latency) 단축을 목표로 정기적인 업데이트를 지속 제공할 계획이다.
