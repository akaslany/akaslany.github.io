Recurrent Looped Transformer (RLT) 기술 보고서

본 기술 보고서는 Yifan Zhang의 2026년 9월 12일자 기술 보고서 "Recurrent Looped Transformer"를 바탕으로 작성되었습니다. 본 보고서는 외부 자료를 배제하고 원문의 기술적 정의, 수식 및 아키텍처 분석 내용을 충실히 반영하며, 수석 AI 연구원의 관점에서 시스템의 메커니즘을 심층 분석합니다.

1. RLT의 세 가지 핵심 설계 원칙

RLT는 기존 트랜스포머의 구조적 한계를 하드웨어 및 알고리즘과의 공동 설계(Co-design)를 통해 해결하고자 하며, 다음 세 가지 원칙을 기둥으로 삼습니다.

  • 무한한 시간적 깊이(Unbounded Temporal Depth)를 통한 잠재 추론: '무한한 시간적 깊이'는 단일 토큰 내부의 무한한 연산을 의미하는 것이 아니라, 시퀀스가 길어질수록 시간적 계산 경로(Temporal computation path)가 아키텍처적 제한 없이 확장됨을 의미합니다. $L_D$개의 디코더 층을 가진 모델이 $t$번째 토큰을 처리할 때, 상태 경로(State path)가 통과하는 누적 블록 깊이는 $t \times L_D$에 달합니다. 이는 표준 트랜스포머의 깊이가 레이어 수($L$)에 의해 물리적으로 캡핑(Capping)되는 것과 대조되는 핵심적인 차별점입니다.
  • 모델-하드웨어 공동 설계(Model-Hardware Co-design): 병렬 처리가 가능한 인코더의 특징 추출과 순차적인 디코더 상태 업데이트를 분리하여 효율적인 실행을 도모합니다. 이를 통해 벌크 인코더 커널(Bulk encoder kernels) 사용과 시퀀스 간 배치 처리가 가능해지며, 메모리 내 가중치 상주 및 KV 캐시 재사용 효율을 극대화합니다.
  • 모델-RL 알고리즘 공동 설계(Model-RL Algorithm Co-design): 사전 학습(Pretraining), 미세 조정(SFT), 롤아웃 샘플링, RL 재현(Replay) 전 과정에서 동일한 상태 전이(State transition) 메커니즘을 공유합니다. 이는 프롬프트와 응답 경계에서의 구조적 불일치를 제거하여 일관된 정책 최적화를 가능케 합니다.

2. 아키텍처 상세 구조 및 수식 분석

RLT는 입력을 처리하는 Causal Encoder와 상태를 반복 업데이트하는 Recurrent Decoder로 구성됩니다.

2.1 Causal Encoder 및 Global Memory

인코더 $E_\theta$는 입력 $x_{1:T}$를 병렬로 처리하여 각 토큰의 표상 $e_t$를 생성합니다. 이를 통해 다음과 같이 글로벌 KV 메모리(Global KV Memory) $M_{\le t}$를 구축합니다.

  • $k^g_t = P_K^g(e_t, t), \quad v^g_t = W_V^g \text{RMSNorm}_E(e_t)$
  • $M_{\le t} = { (k^g_j, v^g_j) }_{j=1}^t$ 이 메모리는 인코더 표상에 기반하며, 디코더 상태와는 독립적으로 생성되어 디코더의 크로스 어텐션(Cross-attention) 시 공급됩니다.
2.2 Gated Merge 메커니즘

인코더의 출력 $e_t$와 이전 시점의 디코더 출력 $s_{t-1}$은 게이팅 메커니즘을 통해 결합됩니다.

  • $r_{t-1} = \text{RMSNorm}s(s{t-1})$
  • $g_t = \sigma(W_g[e_t; r_{t-1}] + b_g)$
  • $u_t = e_t + \alpha g_t \odot W_s r_{t-1}$ 여기서 $\sigma$는 시그모이드(Sigmoid) 활성화 함수이며, $\alpha$는 피드백 스케일(Feedback scale)을 조절하는 파라미터입니다. $u_t$는 다음 디코더 블록의 입력이 됩니다.
2.3 Recurrent Decoder와 상태 정의

전체 디코더 상태는 $H_t = (s_t, C^D_t)$로 정의됩니다. 여기서 $s_t$는 최종 hidden-state 피드백이며, $C^D_t$는 층별 슬라이딩 윈도우 어텐션(SWA) 캐시입니다. 윈도우 크기 $W$ 내의 Key/Value 값만을 유지하여 상태의 크기를 제어합니다.

2.4 디코더 블록 연산 (Layer $\ell$)

각 디코더 층은 로컬 SWA와 글로벌 메모리 어텐션을 순차적으로 수행합니다.

  1. Causal SWA: $q^{D,\ell}_t, k^{D,\ell}_t, v^{D,\ell}t$를 생성한 후, 윈도우 $W$ 내의 디코더 캐시 $C^D{t-1}$을 참조하여 로컬 문맥을 처리합니다.
  2. Encoder-Memory Cross-Attention: 인코더가 제공하는 글로벌 메모리 $M_{g(\ell) \le t}$에 대해 어텐션을 수행하여 전역 문맥을 결합합니다.
  3. FFN 및 출력: 최종적으로 FFN과 Residual Connection을 거쳐 $s_t = z^{L_D}_t$를 산출합니다.

3. 운영 프로세스 및 불변성 원리

3.1 Prefill 및 Generation의 연속성

RLT는 프롬프트와 응답을 구분하지 않는 단일 반복 계산(One recurrent computation) 구조를 가집니다.

  • 서빙 경계(Serving Boundary): 프롬프트 처리가 완료된 시점 $T$에서도 상태 $H_T$는 리셋되지 않습니다. 응답 생성 단계는 $H_T$를 초기 상태로 하여 $H_{T+1}$을 계산하는 연속적인 과정입니다.
  • 상태 유지: 인코더 메모리는 한 번 계산되면 불변(Immutable) 상태로 유지되며, 디코더 SWA 캐시는 매 토큰마다 업데이트되어 최근 $W-1$개의 상태를 보존합니다.
3.2 정리 3.1: 서빙 분할에 대한 불변성 (Invariance to serving split)

수학적으로 RLT는 특정 접두사(Prefix)를 배치 프리필(Batched prefill)로 처리하든 증분 디코딩(Incremental decoding)으로 처리하든 동일한 상태와 다음 토큰 확률 분포를 생성합니다. 이는 정책 정의에서 프롬프트-응답 경계에 따른 수치적 불일치를 원천적으로 제거함을 증명합니다.

4. 48+48 Tied Configuration 분석

효율성 극대화를 위해 인코더($L_E=48$)와 디코더($L_D=48$) 간의 가중치 공유(Weight Sharing)를 채택합니다.

  • 공유 대상: Query, Key, Value, Output 투영 행렬 및 FFN 가중치.
  • 논리적 패스: 이는 단순한 활성화 복사가 아닌 매개변수의 재사용입니다. 토큰당 연산은 인코더와 디코더를 합쳐 총 96개의 논리적 블록 평가(Logical block evaluations)를 수행하지만, 메모리상 파라미터 점유는 48층 수준으로 최적화됩니다.
  • 연산량(FLOPs) vs 파라미터: 파라미터는 공유되지만, 각 토큰당 96개 블록 분량의 FLOPs가 발생하며, 이를 통해 고정된 파라미터 대비 더 깊은 논리적 계산 경로를 확보합니다.

5. 하드웨어 및 RL 공동 설계의 실현

5.1 하드웨어 병렬성 및 최적화
  • 벌크 인코더 커널: 이미 알려진 프롬프트 시퀀스에 대해 인코더 특징 및 메모리 투영을 병렬로 처리하여 대역폭 효율을 높입니다.
  • 독립 시퀀스 간 배치 처리: 서로 다른 시퀀스들의 디코더 전이(Transition)를 하나의 배치로 묶어 행렬 연산 크기를 확대합니다.
  • 메모리 상주성: 인코더 메모리가 불변이므로 가중치와 KV 데이터의 빈번한 이동을 최소화하는 최적화가 가능합니다.
5.2 RL 알고리즘 및 정밀 재현 (Exact Replay)

RLT의 강화학습은 재현 정밀도(Replay Fidelity)를 엄격히 준수합니다.

  • 정밀 재현(Exact Replay): RL 학습 시 샘플러에서 생성된 오래된 상태(Stale states)를 재사용하지 않습니다. 현재 업데이트된 파라미터 하에서 프롬프트부터 응답까지의 모든 상태($s_t, C^D_t$)를 처음부터 재구축(Reconstruct)합니다.
  • Full BPTT (Backpropagation Through Time): 손실(Loss)은 응답 토큰에만 적용되더라도, 그래디언트는 프롬프트 구간의 인코더 메모리와 디코더 상태 전이 과정을 모두 통과합니다. 이는 프롬프트 문맥이 정책 결정에 미치는 영향을 정확히 역전파하기 위함입니다.
  • 정밀 중요도 샘플링(Exact Importance Sampling): 행동 로그 확률(Log-probabilities) 기록 시 온도(Temperature), 절단(Truncation, top-k/p) 등의 모든 메타데이터를 포함하여 분모의 정확성을 보장해야 합니다.

6. 결론 및 연구적 제언

RLT는 하드웨어 인지적 반복 실행과 신뢰할 수 있는 RL 스케일링을 위한 명확한 아키텍처적 명세(Specification)를 제시합니다.

  • 목표의 명확화: 본 보고서에서 언급된 추론 능력 향상, 실행 속도 개선, RL 스케일링의 안정성은 실제 측정치가 아닌 아키텍처 설계를 통해 달성하고자 하는 연구 목표입니다.
  • 핵심 의의: 프롬프트와 응답 사이의 구조적 단절을 제거하고 '무한한 시간적 깊이'를 제공함으로써, 대규모 언어 모델이 시퀀스 길이에 비례하여 논리적 추론을 심화할 수 있는 물리적 기반을 마련했다는 데 의의가 있습니다.

본 설계는 고성능 하드웨어 활용과 정교한 RL 최적화가 결합된 차세대 AI 시스템의 프로토타입으로서 기능할 것입니다.
