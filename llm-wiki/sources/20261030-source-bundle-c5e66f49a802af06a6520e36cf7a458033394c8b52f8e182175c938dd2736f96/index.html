1. 개요 (Overview)

인공지능(AI) 연구에서 리처드 서튼(Richard Sutton)이 2019년에 제안한 '쓴 교훈(Bitter Lesson)' 철학은 인간이 수공업적으로 설계한 사전 지식(Priors)을 배제하고, 대규모 연산 자원을 활용해 로우 데이터(Raw data)로부터 직접 학습하는 일반화된 방법론이 AI의 장기적 발전을 이끈다는 핵심 메시지를 담고 있습니다. 현재의 언어 모델은 트랜스포머 아키텍처와 다음 토큰 예측 알고리즘 등을 통해 커다란 성공을 거두었으나, 여전히 바이트(Byte) 레벨의 로우 데이터를 직접 처리하지 못하고 수작업으로 정의된 토큰화(Tokenization) 및 사전 토큰화(Pretokenization) 정규식에 의존하고 있습니다. 이러한 인위적 인코딩 단계는 모델이 데이터 본연의 구조로부터 엔드투엔드(End-to-end)로 학습하는 능력을 근본적으로 제약합니다. [출처: web-www-cartesia-ai-blog-from-tokens-to-bytes-part-1-29f0d4517b8b (https://www.cartesia.ai/blog/from-tokens-to-bytes-part-1)]

기존 BPE(Byte Pair Encoding) 방식 및 정규식 기반 사전 토큰화가 지닌 구조적 한계를 극복하기 위해, 카르테시아 연구진(Cartesia Research)은 계층적 네트워크(Hierarchical Networks, H-Net)를 제안했습니다. H-Net은 데이터를 정적으로 사전 처리하는 대신, 모델 내부에서 데이터 의존적(Data-dependent)이고 동적인 청킹(Dynamic chunking)을 엔드투엔드로 수행하여 문자에서 단어, 단어에서 구문, 구문에서 개념으로 이어지는 다단계 추상화 구조를 직접 학습합니다. 이를 통해 인위적 편향을 제거하고 로우 데이터로부터 직접 의미를 추출하여 데이터 및 연산 효율성을 극대화하는 것을 목표로 합니다. [출처: web-www-cartesia-ai-blog-from-tokens-to-bytes-part-1-29f0d4517b8b (https://www.cartesia.ai/blog/from-tokens-to-bytes-part-1)]

본 분석 해설 보고서는 카르테시아 연구진이 공개한 기술 보고서 Part I과 Part II의 핵심 내용을 종합 정리합니다. Part I에서는 BPE 트랜스포머와 비교한 H-Net의 스케일링 사다리(Scaling ladder), 대규모 SmolLM3 레시피 대조군에서의 10배 이상 효율성 달성, 추상화 행동에 대한 질적 분석, DNA 및 컴퓨터 비전으로의 확장성을 다룹니다. Part II에서는 사전학습 검증 손실과 다운스트림 평가 손실 간의 손실 대 손실(Loss-to-Loss) 스케일링 법칙, 사전 토큰화 정규식의 영향력, 그리고 프록시 기반 청킹 대비 엔드투엔드 동적 학습이 제공하는 우수성을 체계적으로 분석합니다. 2. 주요 논점 (Key Arguments & Evidence)

2.1 기존 토큰화 및 사전 토큰화(Pretokenization)의 구조적 한계

기존 언어 모델은 텍스트를 바이트 단위로 직접 다루는 연산 비용을 줄이기 위해 BPE 및 사전 토큰화 정규식(Regex)을 사용하여 텍스트를 고정된 서브월드 단위로 압축합니다. 그러나 정규식 기반 사전 토큰화는 인간의 언어학적 편향과 공백 분리 규칙에 국한되는 한계를 가집니다.

토큰화 방식 / 모델 적용 정규식 및 주요 분리 규칙 주요 특징 및 한계

사전 토큰화 규칙 없이 바이트 단위에서 직접 BPE를 학습하는 BPE-NP(No Pretokenization)는 압축률 측면에서 6.03 바이트/토큰을 기록하여 일반 BPE(4.57 바이트/토큰)보다 높지만, 공백을 넘나들며 의미적 경계와 무관하게 텍스트가 잘려 다운스트림 전이 성능이 심각하게 저하되는 성능 역전 현상이 발생합니다.

또한, 기존 토큰화 방식은 프롬프트 경계 문제(Prompt boundary problem / Marginalization problem)를 유발합니다. 하나의 텍스트 표현이 여러 토큰 분할 시퀀스로 표현될 수 있음에도 표준 모델은 단일 정규 분할(Canonical tokenization)만을 평가하므로, 프롬프트가 단어 중간이나 공백에서 끝날 경우 모델이 올바른 다음 토큰 확률을 할당하지 못하는 구조적 오류를 범합니다.

2.2 계층적 네트워크(H-Net)의 아키텍처 및 동작 원리

H-Net은 데이터를 고정된 offline 토큰으로 분할하지 않고, 모델 내부에서 엔드투엔드로 dynamic chunking을 실행하는 5개 핵심 모듈 구조로 이루어져 있습니다.

[입력 (Raw Bytes)] 
       │
       ▼
1. 인코더 (Encoder)          ─── (외부 네트워크: 하위 레벨 바이트 읽기)
       │
       ▼
2. 동적 청킹 (Dynamic Chunking) ─── (학습된 데이터 의존적 경계 형성)
       │
       ▼
3. 메인 네트워크 (Main Network) ─── (내부 네트워크: 압축된 고차원 의미 청크 연산)
       │
       ▼
4. 디청킹/상태 복원 (Dechunking)─── (원래 해상도로 복원 및 잔차 연결)
       │
       ▼
5. 디코더 (Decoder)          ─── (외부 네트워크: 최종 출력을 합성)
  • 내부 및 외부 네트워크 구분: 인코더와 디코더는 '외부 네트워크(Outer networks)', 메인 백본은 '내부 네트워크(Inner network)'로 구분됩니다. 1단계 H-Net은 1회의 동적 청킹을 수행하며, 메인 네트워크 자체를 H-Net으로 중첩 구성하여 2단계 이상의 재귀적 구조를 형성할 수 있습니다.
  • 동적 청킹 매커니즘: 사전 처리 단계에서 고정 압축을 수행하는 대신, 외부 인코더가 바이트 레벨의 맥락을 분석하여 데이터의 정보량과 의미 구조에 따라 가변적인 크기의 의미 청크(Chunk)를 형성합니다.
  • LH-Net(초기 H-Net) 대비 개선점: 과거 초기 모델인 LH-Net(Lookahead/Lazy H-Net)은 다음 청크의 시작 지점을 관찰한 이후에야 청크 경계를 결정을 짓는 방식을 사용했습니다. 이는 추가적인 문맥 파악에는 유용했으나 다음 바이트 예측의 인과성(Causality)을 저해하고 다단계 계층구조 모델링 시 손실을 유발했습니다. 반면 개선된 현재 H-Net은 미래 참조 없이 인과적(Causal) 동적 청킹을 완벽히 구현하여 인과적 다음 바이트 예측 능력을 온전히 보존합니다. 이를 통해 영어 단어 어근(Stem) 분할 정확도(예: trackers $\rightarrow$ track + ers)가 크게 향상되었으며, CJK(한국어, 중국어, 일본어) 다중 바이트 문자 세그먼테이션 오류를 해결했습니다.
2.3 H-Net 스케일링 법칙 및 연산 효율성 검증 (1단계 및 2단계 H-Net)

동일 연산 자원 및 데이터 조건 제어 하에 BPE 트랜스포머 대비 H-Net이 거둔 연산 승수(Compute multiplier) 비교 수치는 다음과 같습니다.

평가 영역 대조군 (BPE Transformer) 대비 H-Net 연산 승수 (Compute Multiplier) 주요 내용 및 세부 수치
사전학습 검증 손실 (In-domain Validation) 1.28배 동일 검증 BPB 도출 시 연산 자원 22% 절감.
다운스트림 벤치마크 (Paloma / OLMES) 1.83배 (Paloma) / 2.06배 (OLMES) 평가 영역으로 확장 시 BPE 대비 약 2배 성능 우위.
인도메인 코드 (In-distribution Code) 1.49배 ~ 2.40배 (중간값 2.04배) Markdown 1.49배 ~ Go 2.40배 등 15개 코드 언어 전체 상향.
OOD 코드 (Out-of-distribution Code) 2.19배 ~ 5.37배 (중간값 3.10배) 학습에 미포함된 10개 언어(Haskell 2.19배, Prolog 5.37배).

2단계 H-Net(3.67B 파라미터)은 Hugging Face의 SmolLM3(3.08B 파라미터) 사전학습 레시피를 복제하여 대조한 실험에서 SmolLM3가 11조(11T) 토큰을 소비해 달성한 최종 벤치마크 성능을 단 1조(1T) 토큰 학습만으로 도달하여 10배 이상의 효율성을 입증했습니다.

또한 영역별 압축 특성 분석 결과, BPE 토큰화는 출현 빈도가 높은 영어 텍스트를 더 많이 압축(영어로 된 web text에 더 많은 바이트 할당)하는 반면, H-Net은 가변적 구조를 가진 코드 영역을 더 크게 압축(H-Net 바이트/청크 $\div$ BPE 바이트/토큰 비율이 SQL 1.40, Go 1.26으로 높음)하면서도 모델링 성능을 대폭 향상시키는 특성을 보였습니다.

2.4 손실 대 손실(Loss-to-Loss) 스케일링 법칙 및 평가 전달력

사전학습 검증 손실(Validation bpb)이 다운스트림 평가 손실(OLMES bpb)로 전이되는 관계를 나타내는 Loss-to-Loss 법칙 분석 결과는 다음과 같습니다.

[다운스트림 전이 성능 (Loss-to-Loss Transfer)]
높음 ▲  1. Isotropic Byte Transformer  (로우 데이터 접근성 최상, 손실 전이 상한선)
     │  2. H-Net (Byte-level Interface)  (동적 청킹으로 Byte와 동일 전이력 유지)
     │  3. BPE (with Pretokenization)   (정규식 편향으로 인해 전이 성능 저하, 1.54배 손실)
     │  4. BPE-NP (No Pretokenization)  (비의미적 토큰으로 인해 전이 성능 최하)
낮음 ─────────────── 사전학습 검증 손실 (Validation bpb) ───────────────►

실험 결과, 로우 데이터(바이트 레벨)에 직접 접근할 수 있는 모델일수록 사전학습 손실 대비 다운스트림 평가 전달력이 뛰어났습니다.

  • Byte Transformer: 입력 인코딩으로 인한 의미 왜곡이 없어 가장 뛰어난 Loss-to-Loss 전달 성능(전이 상한선)을 제공하지만, 연산 효율성(Compute-to-loss)이 매우 낮음.
  • BPE (사전 토큰화 포함): 연산 효율성은 높으나 Byte 모델 대비 1.54배의 연산 손실을 초과 발생시킴.
  • BPE-NP: 정규식이 없어 의미와 무관하게 잘린 토큰으로 인해 BPE 대비 추가로 1.3배(Byte 대비 약 1.93배) 성능이 저하됨.
  • H-Net: 바이트 레벨 인터페이스를 유지하면서 내부 동적 청킹을 수행함으로써, Byte Transformer가 가지는 최고 수준의 Loss-to-Loss 전이력을 손실 없이 완벽히 회복하는 동시에 높은 연산 효율성을 동시에 확보함을 입증했습니다.

2.5 엔드투엔드(End-to-End) 학습의 중요성 및 타 기법과의 비교

외부 프록시(Proxy) 모델이나 엔트로피 휴리스틱 기반으로 청킹 경계를 고정하는 방식(BLT-like)과 H-Net 간의 검증 손실(Validation BPB) 비교 수치는 다음과 같습니다.

FLOPs 연산 자원 (Proxy FLOPs) BLT-like (엔트로피 임계값) H-Net Proxy (고정 경계) H-Net (엔드투엔드 학습)
$10^{19}$ ($10^{18.5}$) 0.8160 BPB 0.8139 BPB 0.8001 BPB
$10^{19.5}$ ($10^{19}$) 0.7623 BPB 0.7504 BPB 0.7488 BPB
$10^{20}$ ($10^{19.5}$) 0.7138 BPB 0.7057 BPB 0.7027 BPB

비교 분석 결과, 외부 모델의 엔트로피 헵틱(BLT-like)보다 H-Net 프록시가 제공하는 경계 품질이 우수하였으며, 사전 고정된 프록시 경계를 사용하는 것보다 모델 내부에서 경계 형성 매커니즘을 엔드투엔드로 직접 학습하는 H-Net이 모든 연산 구간에서 가장 낮은 검증 BPB를 달성했습니다. 이는 청킹 프로세스를 외부 휴리스틱으로 분리하지 않고 모델 내부 파라미터로 통합하여 직접 단층/다층 추상화를 학습하는 것이 성능 극대화의 핵심임을 증명합니다.

2.6 인컨텍스트 토큰화(In-context Tokenization) 및 창발적 행동

H-Net은 추상화된 고정 사전 없이 추론(Inference) 시점의 문맥에 따라 가변적으로 토큰화 행동을 조절하는 인컨텍스트 토큰화(In-context Tokenization) 창발 행동을 보여줍니다.

  1. 새로운 개념/단어 (New concepts): borvexila, mipralune와 같이 텍스트에 처음 등장하는 생소한 신조어는 여러 개의 세분화된 청크로 나누어 읽지만, 동일 단어가 문맥 내에서 반복 등장함에 따라 단어를 단일 청크로 통합하여 인지함.
  2. 반복 포맷 및 패턴 (Repeated formats): 반복되는 문장 구조나 고정 양식 문구가 지속될 경우, H-Net은 매우 대형 청크(Large chunks)를 형성하여 메인 네트워크의 연산량을 대폭 절감함.
  3. 문자/숫자 블록 패턴 (Recurring motifs): 무작위 문자열(LURD, WHYV)이나 숫자 배열(2526, 3987) 내에 숨겨진 반복 모티프를 감지하여 묶어냄.
  4. 미학습 프로그래밍 언어 (OOD Programming Languages): 학습 데이터에 전혀 없던 언어(Haskell, Prolog 등)에서도 식별자(quicksort', filter), 괄호 구문([a], []), 코드 들여쓰기 공백을 일관된 단일 청크로 유지함.
2.7 텍스트 이외의 모달리티 확장 (생물학 DNA 및 컴퓨터 비전)

H-Net의 동적 청킹 원리는 텍스트를 넘어 다중 모달리티 영역으로 확장 적용되었습니다.

  • 생물학 (DNA): DNA 4개 염기(A, C, G, T) 입력을 6배 목표 압축률로 설정하여 학습한 결과, 트랜스포머 대비 6~7배의 연산 효율성 향상을 달성했습니다. 별도의 사전 지식 주입 없이도 코딩 영역의 코돈(Codon, 3개 염기) 경계 인지, 엑손(Exon)/인트론(Intron) 구별, tRNA의 단일 염기 단위 축소, 히스톤 유전자(H2BC17) 구조 자동 세그먼테이션 등 생물학적 구조 인지 행동이 창발되었습니다.
  • 컴퓨터 비전 (Vision): N차원 H-Net 구조를 이미지 및 비디오에 적용하고 픽셀 스페이스 플로우 매칭 모델(JiT)과 결합했습니다. spatial(공간), integration time(디노이징 단계), samples(샘플 복잡도)의 3가지 축에 따라 연산을 가변 할당하며, 지도 학습 없이도 2D 평면 이미지에서 3D 구조 및 객체 의미 세그먼테이션을 비지도 방식으로 형성함을 확인했습니다.

    • 다운스트림 평가: Paloma 벤치마크 1.83배, OLMES 벤치마크 2.06배

  • SmolLM3 3B 대조군 성능 수치:
    • 모델 규모: H-Net 3.67B 파라미터 vs SmolLM3 3.08B 파라미터
    • 학습 효율: H-Net 1조(1T) 토큰 학습 결과 = SmolLM3 11조(11T) 토큰 최종 성능 도달 (>10배 연산 및 데이터 효율성)
  • DNA 생물학 데이터셋:
    • 학습 데이터량: OpenGenome GTDB 데이터셋 2,740억 염기쌍 (274 billion nucleotides)
    • 연산 효율 향상: 트랜스포머 대비 6~7배 연산 승수 도달

5. 한계와 불확실성 (Limitations & Uncertainties)

  • 데이터 및 연산 매칭의 모순점: BPE 토큰화는 자주 나타나는 영어 텍스트를 더 크게 압축하는 반면, H-Net은 규칙성이 높은 코드 텍스트를 더 크게 압축합니다. 이처럼 서브도메인별 압축 특성이 서로 반대로 작용하기 때문에, 단일 실험에서 데이터 자원 비율과 연산 자원 비율을 동시에 완전하게 제어하고 비교하는 데 구조적 어려움이 존재합니다.
  • 포스트 트레이닝(Post-training) 미검증: 본 보고서의 연구 범위는 사전학습(Pretraining) 및 평가 전이(Evaluation transfer) 단계에 한정되어 있으며, 지시 이행 및 미세조정과 같은 사후 학습(Post-training/Fine-tuning) 단계에서 H-Net의 동적 청킹이 미치는 영향은 향후 연구 과제로 남아 있습니다.
  • 기타 소스 미기재 정보: H-Net 내부 모듈의 세부 수학적 수식, 동적 청킹 게이팅 알고리즘의 세부 손실 함수 수식, 및 미공개 가중치 값 등 소스에 기술되지 않은 명시적 정보는 확인 불가 항목에 해당합니다.
