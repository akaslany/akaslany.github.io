1. 개요 (Overview)

마이크로소프트 AI(Microsoft AI)는 2026년 11월 17일 Ignite 행사에서 기업의 일상적인 코딩 작업(Everyday enterprise coding tasks)에 최적화된 새로운 AI 모델인 MAI Code 2와 MAI Code 2 Flash를 공개했습니다. 본 보고서는 공개된 블로그 발표 자료 및 내장 벤치마크 데이터를 기반으로 두 모델의 핵심 특징, 성능 지표, 비용 효율성, 그리고 마이크로소프트 주요 제품군으로의 확장 적용 현황을 객관적으로 분석합니다.

이 모델 라인업의 최우선 과제는 최상위 모델의 최고 비용 대비 압도적인 가성비(Price-performance)를 제공하는 것입니다. 기존의 거대 언어 모델들이 방대한 컴퓨팅 자원과 높은 비용을 요구하는 데 비해, MAI Code 2 및 Code 2 Flash는 기업 엔지니어가 실제 업무 현장에서 가장 자주 수행하는 코딩 작업을 타깃으로 삼아 비용 부담을 혁신적으로 줄이면서도 프로덕션급 고품질 출력을 제공하도록 설계되었습니다.

또한 마이크로소프트는 Code 2 Flash 기술을 바탕으로 단일 모델 최적화를 거친 MAI Work Flash를 구축하여 Microsoft 365(Excel, PowerPoint, Word, Teams) 및 Fabric IQ 전반으로 인공지능 엔지니어링 역량을 확장 적용하고 있습니다. 이를 통해 코딩 영역을 넘어 일반 업무 프레임워크 전반의 토큰 효율성과 처리 품질을 동시에 향상시켰음을 밝히고 있습니다.

본 발표의 주요 서술 내용 중 기본 사실(벤치마크 데이터 수치 및 공식 제품 명세)과 기업 측의 주장(경쟁 모델 대비 성능 우위 및 최적화 효과)은 명확히 구분되어 기재되었으며, 관련 세부 사항은 다음 논점에서 구체적으로 서술합니다.

2. 주요 논점 (Key Points)

2.1 일상적 코딩 작업에서의 비용 대비 성능 최적화 (MAI Code 2)
  • [논점] MAI Code 2는 프로덕션 환경 수준의 업무 처리 능력을 보유하면서 경쟁사의 프론티어(Frontier) 모델 대비 획기적으로 낮춘 비용으로 높은 성능을 구현함.
  • [근거] 엔지니어들이 일상적으로 수행하는 핵심 코딩 업무(프로덕션 코드 반영, 심층 디버깅, 다중 파일 구현, 레포지토리 단위 추론, UI 및 시각적 코딩 등)에 모델을 집중 최적화하여 코드 유지보수 담당자가 즉시 병합(Merge)할 수 있는 수준의 품질을 달성함.
  • [사례/성능 지표]
    • 주요 벤치마크 평균 평가: GitHub Copilot에서 자주 접하는 일상적 코딩 업무를 반영한 4개 벤치마크(DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas, FrontierCode v1.1)의 평균 Pass Rate 및 비용 측정 결과(최대 추론 노력/Max reasoning effort 조건):
      • GPT 6.1 Sol 대비: 98% 수준의 성능 달성 (Pass Rate 63.2% vs 64.1%) / 비용은 40% 수준 (작업당 $0.309 vs $0.761).
      • Claude Opus 5.5 대비: 96% 수준의 성능 달성 (Pass Rate 63.2% vs 65.3%) / 비용은 단 5% 수준 (작업당 $0.309 vs $6.306).
    • 세부 벤치마크별 특성 분석:
      • 단말기 명령 및 셸 작업 중심의 Terminal Bench 2.1에서는 84.6%의 높은 통과율을 기록하며 GPT 6.1 Sol(85.0%)과 거의 동등하고 Claude Opus 5.5(78.7%)를 상회함.
      • 이슈 해결 및 실무 코드 수정 벤치마크인 DeepSWE 1.1(73.2%) 및 FrontierCode v1.1(52.0%)에서도 경쟁 프론티어 모델과 대등한 수준을 유지함.
      • 반면, 다중 파일 추론 및 고난도 에이전트 과제인 SWE-Atlas에서는 43.1%를 기록하여 초대형 모델인 Claude Opus 5.5(57.5%) 대비 일정 수준의 격차를 보여, 범용 대형 모델과의 성능 경계 및 타깃 업무 영역의 차이를 선명히 드러냄.
    • 프론트엔드 및 시각적 코딩 평가: 대시보드 및 시각화 생성에 특화되어 있으며, 프론트엔드 앱 블라인드 평가(Blind frontend app evaluations)에서 검수자의 64%가 GPT 6.1 Sol보다 MAI Code 2의 결과를 선호함.

2.2 대량 반복 작업을 위한 고효율 모델 (MAI Code 2 Flash)
  • [논점] MAI Code 2 Flash는 처리량이 많은 대규모 일상 작업에 특화되어 대폭 절감된 비용으로 최상위 수준의 품질과 빠른 반복 속도를 제공함.
  • [근거] 코드 설명 작성, 타깃 코드 편집, 루틴 수정, 신속한 반복 작업(Rapid iterations) 등 대량으로 호출되는 반복 업무에 맞춰 구조를 최적화함.
  • [사례/성능 지표]
    • 3개 주요 벤치마크 평가: 일상적인 고용량 루틴 코딩 작업을 측정하는 3개 벤치마크(DeepSWE 1.1, Terminal Bench 2.1, SWE-Atlas)의 평균 측정 결과:
      • GPT-6 Luna 대비: 성능은 능가(61.0% vs 55.1%)하면서 비용은 65% 수준 ($0.052 vs $0.080).
      • Claude Haiku 5.5 대비: 성능은 능가(61.0% vs 53.9%)하면서 비용은 20% 수준 ($0.052 vs $0.319).
    • 세부 벤치마크 수행 결과:
      • DeepSWE 1.1(59.9%), Terminal Bench 2.1(78.3%), SWE-Atlas(44.8%) 전 영역에서 비교 대상 소형/고효율 경쟁 모델인 GPT-6 Luna 및 Claude Haiku 5.5를 일관되게 앞서는 전방위적 효율성을 검증함.

2.3 마이크로소프트 제품군으로의 적용 확장 (MAI Work Flash)

  • [논점] Code 2 Flash 기술 모델을 바탕으로 추가 최적화된 단일 모델 MAI Work Flash를 통해 마이크로소프트 365 및 Fabric IQ 플랫폼 전반의 엔터프라이즈 업무 생산성과 토큰 효율성을 극대화함.

  • [근거] 개발용 코딩 인프라를 일반 워크플레이스 앱의 내부 핵심 시나리오 벤치마크에 맞춰 단일 모델로 정밀 최적화함으로써, 서비스 품질 손실 없이 토큰 소비량을 획기적으로 감소시킴.

  • [사례/성능 지표]

    • 엑셀 (Excel): 주요 내부 엑셀 고객 시나리오 벤치마크 전반에서 GPT-6 Luna와 정확도 및 토큰 효율성 측면에서 동등한 수준 달성.
    • 파워포인트 (PowerPoint): 자주 발생하는 파워포인트 작업들을 측정하는 주요 프로덕션 벤치마크 시나리오에서 GPT-6 Luna와 품질 및 토큰 효율성 면에서 동등한 성과 기록.
    • 워드 (Word): 5개 주요 내부 벤치마크에서 현저히 작은 모델 크기임에도 GPT 6.1 Sol과 유사한 성능을 발휘하며, 실제 프로덕션 환경 호출당(per call in production) GPT 6.1 Sol 대비 입력 토큰(Input tokens)을 약 42% 절감.
    • 팀즈 (Teams): 의사결정 추적, 지식 공백 채우기, 맞춤형 지시사항 적응 등에서 지시 이행(Instruction following) 및 툴 호출(Tool calling) 시 GPT-6 Luna 대비 최대 28% 적은 토큰을 사용하며 성능 우위 달성.
    • 패브릭IQ (FabricIQ): Power BI 시맨틱 모델의 핵심 기능인 "Chat with your Data"의 인프라 기반이 되는 **DAX 쿼리 생성 오프라인 평가에서 GPT-5.6-sol, GPT-6-astra, Opus-5.5 모델들을 일관되게 능가(Outperforms)**함.

  • [작성자 해석] 코딩 전용으로 개발된 Code 2 Flash 엔진을 일반 생산성 및 데이터 분석 영역(MAI Work Flash)으로 단일 최적화하여 365 앱과 Fabric IQ 전반에 표준화 배치한 것은, 단순한 모델 라인업 확장이 아닌 기업 전체 AI 컴퓨팅 인프라의 토큰 비용을 통합 관리하고 운영 효율을 제어하려는 마이크로소프트의 전략적 인프라 단일화 체계로 분석됩니다.

5. 한계와 불확실성 (Limitations & Uncertainties)

5.1 소스가 명시한 한계 (Explicit Limitations)
  • 고난도 문제 미최적화: 마이크로소프트는 해당 모델들이 기업의 일상적인 코딩 업무 최적화를 목표로 설계되었음을 명확히 밝혔습니다. 따라서 **기초 과학 연구(Fundamental science research)**나 **매우 긴 호흡의 에이전트 작업(Very long horizon agentic work)**과 같은 고난도 문제에는 아직 명시적으로 조정(Tuned)되지 않았습니다.
