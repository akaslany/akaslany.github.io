원문

FlashREINFORCE: 에이전트형 언어 모델을 위한 Critic-Free Single-Rollout 비동기 강화학습 기술 보고서

본 기술 보고서는 도구 호출(Tool calls) 및 장기 추론(Long-horizon reasoning) 환경에서 발생하는 비동기적 병목 현상을 해결하고, 단일 궤적(Single-rollout)만으로도 안정적인 강화학습을 수행할 수 있도록 설계된 FlashREINFORCE 프레임워크의 아키텍처와 성능 데이터를 분석한다.

1. 문제 의식: 장기 에이전트 강화학습의 병목과 도전 과제

비동기 Rollout의 필요성 분석

에이전트형 언어 모델(Agentic LM)은 가변적인 추론 과정과 외부 도구와의 상호작용으로 인해 각 에피소드(Rollout)의 완료 시간이 일정하지 않다. 기존의 동기식 워커 구조는 가장 긴 궤적이 완료될 때까지 전체 학습을 중단시키므로 자원 효율성이 급격히 저하된다. 따라서 각 워커가 추론 완료 즉시 데이터를 제출하고 학습에 반영하는 비동기(Asynchronous) 워커 구조가 필수적이다.

기존 그룹 기반 RL(GRPO 등)의 한계
  • 프롬프트 커버리지 저하: GRPO는 분산 감소를 위해 단일 프롬프트에 대해 여러 번의 실행(Sibling rollouts, $G > 1$)을 요구한다. 이는 고정된 Rollout 예산 내에서 탐색 가능한 프롬프트의 다양성을 제한한다.
  • 그룹 동기화 장벽(Synchronization barriers): 비동기 환경에서도 그룹 내 모든 실행이 끝날 때까지 대기해야 하는 동기화 지점이 발생하여 병렬 처리 효율을 저해한다.
Single-rollout의 기술적 난제

프롬프트당 단 하나의 궤적($G=1$)만 사용하는 방식은 다음과 같은 학술적 난제를 동반한다.

  • 분산(Variance) 및 노이즈: 그룹 기반 베이스라인의 부재는 보상 신호의 분산을 증가시켜 업데이트를 불안정하게 만든다.
  • Staleness(정책 지연) 문제: 비동기 구조에서는 데이터 수집 시점의 정책($\mu_i$)과 현재 학습 중인 정책($\pi_\theta$) 간의 괴리인 Policy Lag이 발생하며, 이는 학습 안정성을 위협한다.
  • 길이 가중치 문제: 실패한 긴 궤적이 토큰 단위 업데이트를 장악하여 정책 학습을 방해하는 'Length-amplified negative feedback' 현상이 발생한다.

2. FlashREINFORCE의 핵심 3요소 및 수식적 직관

FlashREINFORCE는 별도의 가치 모델(Critic) 없이도 안정성을 확보하는 세 가지 기술적 메커니즘을 제안한다.

One-Batch REINFORCE (Reward Centering)

가치 네트워크 없이 신선한 배치(Fresh batch) 내에서 보상을 중앙화하여 부호가 있는 피드백(Signed feedback)을 생성한다. $$A_i = R_i - \bar{R}, \quad \bar{R} = \frac{1}{B} \sum_{j=1}^{B} R_j$$ 이를 통해 배치 내 평균 이상의 성과를 낸 샘플에는 양(+)의 피드백을, 미달하는 샘플에는 음(-)의 피드백을 부여한다.

Sequence Trust Region (신뢰 구역 마스킹)

Token Importance Sampling(IS)의 한계를 보완하기 위해 궤적 수준에서 정책 드리프트를 제어한다. Bernoulli KL Proxy($d_{i,t}$)를 사용하여 계산된 시퀀스 마스크($m_i$)를 통해 정책이 과도하게 변한 궤적을 제외한다. $$d_{i,t} = \mu_{i,t} \log \frac{\mu_{i,t}}{\pi_{\theta,t}} + (1-\mu_{i,t}) \log \frac{1-\mu_{i,t}}{1-\pi_{\theta,t}}$$ $$m_i = 1[\bar{d}i \leq \delta], \quad \bar{d}i = \frac{1}{T_i} \sum{t=1}^{T_i} d{i,t}$$

  • 이론적 근거: $d_{i,t}$는 데이터 처리 부등식(Data-processing inequality)에 따라 전체 범주형 KL의 하한(Lower bound)이 된다. 이 프록시 방식은 전체 행동 분포를 저장할 필요가 없어 메모리 효율적이다.
Sample-Mean Optimization (궤적 정규화)

실패한 긴 궤적이 업데이트를 장악하는 현상을 방지하기 위해, Token-mean이 아닌 Sample-mean($1/T_i$ 가중치) 방식을 채택한다. 구현상으로는 아래와 같은 Detached-ratio Loss($\mathcal{L}$)를 최소화한다. $$\mathcal{L}(\theta) = - \frac{1}{B} \sum_{i=1}^{B} \frac{m_i A_i}{T_i} \sum_{t=1}^{T_i} \text{stopgrad}(\rho_{i,t}) \log \pi_\theta(a_{i,t} | h_{i,t})$$

주요 변수 정의:

  • $B$: 배치 크기
  • $R_i, A_i$: 궤적 $i$의 터미널 보상 및 중앙화된 어드밴티지
  • $T_i$: 궤적 $i$의 토큰 길이
  • $\mu_i, \pi_\theta$: 행동 정책(Behavior policy)과 현재 학습 정책(Learner policy)
  • $\rho_{i,t}$: Importance Sampling 비율 ($\pi_\theta / \mu_i$)
  • $m_i$: 궤적 수용 여부를 결정하는 바이너리 마스크 ($\delta$: 임계값)

3. 기존 방법론(REINFORCE·GRPO)과의 차별점 및 효율성

불필요한 요소의 제거 및 대체

FlashREINFORCE는 아키텍처 단순화를 위해 기존 강화학습의 필수 요소들을 다음과 같이 대체하거나 제거하였다.

  • Critic 제거: Reward Centering을 통해 가치 네트워크 학습 및 추론 비용을 생략함.
  • Ratio Clipping & Reference Model 제거: Sequence Trust Region 마스킹이 PPO 스타일의 클리핑과 KL 페널티(참조 모델 forward pass)를 효과적으로 대체함.
  • Sibling-rollout Wait 제거: 개별 궤적 완료 즉시 학습에 투입하여 동기화 지연을 없앰.
구조적 비교 분석
비교 항목 기존 방식 (GRPO 등) FlashREINFORCE
데이터 수집 프롬프트당 $G$개 궤적 (그룹화) 프롬프트당 1개 궤적 ($G=1$)
베이스라인 그룹 내 궤적 간 상대적 점수 배치 전체 궤적의 평균 보상 ($\bar{R}$)

정책 안정화 PPO Clipping, KL-penalty Sequence Trust Region (KL Proxy)

4. 실험 결과 분석: 논문 보고 데이터 기반 성능 검증

수학적 추론 성능 (DeepSeek-R1-Distill-Qwen-1.5B)
  • 정책 지연 안정성: 정책 지연(Policy lag)이 약 4회 발생하는 환경에서 6,000회 업데이트 동안 학습이 무너지지 않고 유지됨.
  • 성능 추이: AIME24/25 성공률이 초기 21.7%에서 최종 33.7%로 상승했으며, 학습이 진행됨에 따라 응답 길이는 짧아지고 엔트로피는 안정화되는 양상을 보임.
벤치마크 비교 (Qwen2.5-Math-1.5B)
  • 효율성: 5개 벤치마크 평균 점수 38.0을 기록하며 GRPO 베이스라인(36.3) 대비 1.7p 높은 성능을 달성함.
  • 데이터 효율: 성능 우위에도 불구하고 사용된 Rollout 수는 256k로, GRPO(512k)의 절반만 사용하여 더 높은 효율성을 입증함.
도구 사용 및 의사결정 (Qwen3-30B MoE & ALFWorld)
  • 대규모 모델 및 극한 지연: 30B MoE 모델에서 정책 지연이 8회까지 발생하는 비동기 환경에서도 학습 안정성을 유지하며 67.1%의 평균 점수를 기록(GRPO는 동일 예산에서 60.3%).
  • ALFWorld 상호작용: Seen 환경 98.3%, Unseen 환경 96.5%의 성공률을 기록함. 이는 단일 궤적 기반의 경쟁 모델인 C-RF + NTF를 크게 상회하는 수치로, 성능 향상이 단순히 프롬프트 다양성뿐만 아니라 FlashREINFORCE의 아키텍처(Sample-mean, Trust Region)에서 기인함을 입증함.

5. 중요 구현 조건 및 이론적 한계

Sampler Behavior Probability ($\mu_i$)

학습기(Learner)와 추론 엔진의 Prefill/Decode 커널 불일치 등으로 인해 과거 확률을 재계산할 경우 실제 샘플링 확률과 오차가 발생할 수 있다. 따라서 학습 시 실제 행동 확률인 $\mu_i$를 반드시 저장해야 정확한 IS 보정이 가능하다.

History-distribution Mismatch (Proposition B.2)

Token IS는 특정 상태에서의 행동 분포는 교정하지만, 과거 행동들로 인해 발생한 상태 점유(History occupancy)의 분포 불일치는 해결하지 못한다.

  • 이론적 배경: 대리 목적 함수(Surrogate)의 오차는 궤적 길이($T$)에 따라 누적되는 정책 드리프트에 의해 지배된다($|J(\pi) - \mathcal{L}\mu(\pi)| \leq A{max} T^2 \bar{\kappa}$).
  • 해결책: Sequence Trust Region은 이러한 "Surrogate Error"가 궤적 전체에 걸쳐 축적되는 것을 방지하기 위한 실질적인 해법이다.
입력 데이터의 신선도 (Fresh batch)

동일한 데이터를 여러 미니배치로 나누어 업데이트하는 순차적 방식보다, 매 업데이트마다 새로운 신선한 배치(Fresh batch)를 사용하고 폐기하는 스케줄이 더 높은 정확도(28.45% vs 26.80%)를 보였다.

6. 종합 결론: 유용성 및 향후 검증 과제

저자의 해석 및 유용성

FlashREINFORCE는 다음과 같은 시나리오에서 특히 강력한 유용성을 제공한다.

  • 온라인/인터랙티브 서비스: 단 한 번의 실행만 허용되는 실제 온라인 상호작용 환경.
  • 장기 추론 에이전트: 도구 활용이 많고 궤적 길이가 길어 비동기 병렬 처리가 필수적인 경우.
  • 경량화된 학습 인프라: Critic 모델이나 참조 모델을 위한 추가 GPU 메모리 할당이 어려운 경우.
설명자의 균형 잡힌 시각
  • 강점(Strength):
    • 절반의 데이터 예산으로도 기존 그룹 기반 RL을 압도하는 성능 및 효율성.
    • Critic-free 및 Clipping-free 구조를 통한 학습 파이프라인의 획기적 단순화.
    • 극한의 정책 지연(Lag 8) 상황에서도 보장되는 높은 안정성.
  • 검증 과제(Future Work):
    • 샘플링 프록시의 한계: 현재 사용된 Bernoulli KL Proxy가 두 정책 간의 전체 분포 근접성(Full-policy closeness)을 이론적으로 완전히 보장하지는 못함.
    • 환경 복잡도 확장: OSWorld와 같은 더 고도화된 인터랙티브 OS 환경에서의 추가 성능 검증이 필요함.
    • 드리프트 추정 고도화: 보다 정밀한 정책 드리프트 추정 기법에 대한 연구 지속 필요.
