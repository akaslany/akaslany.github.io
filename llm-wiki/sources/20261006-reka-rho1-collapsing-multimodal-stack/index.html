1. 개요 및 모델 정체성

본 보고서는 레카 랩스(Reka Labs)가 공개한 연구 프리뷰(Research Preview) 자료를 바탕으로, 단일 옴니 추론(omni-reasoning) AI 모델인 Rho-1의 구조적 특징, 내부 메커니즘 및 학술·기술적 성과를 종합 분석한 기술 보고서이다.

Rho-1은 기존 멀티모달 모델처럼 사전 학습된 파이프라인에 사후 미세조정(Fine-tuning)을 적용한 모델이 아니며, **190억(19B) 파라미터 규모로 처음부터 학습(trained from scratch)**된 옴니 추론 모델이다. Rho-1은 단일 신경망(single neural network) 구조 안에서 텍스트, 이미지, 비디오의 이해(Understanding)와 생성(Generation), 기호적·시각적 추론(Reasoning), 그리고 로봇 제어를 포함한 엠보디드 행동(Action) 수행까지의 전 과정을 하나의 컨텍스트 내에서 통합 처리하는 패러다임 전환을 보여준다.

2. 핵심 패러다임 전환: 에이전트 파이프라인에서 단일 통합 네트워크로

2.1 기존 에이전트 파이프라인의 구조적 한계

기존의 멀티모달 AI 시스템은 중앙의 거대 언어 모델(LLM)이 전체 계획을 수립하고, 이미지 생성기·비디오 디퓨전 모델·로봇 제어기 등 각 모달리티별 전문 모델에 작업을 전달하는 '에이전트 파이프라인(agentic pipeline)' 구조에 의존해 왔다. 그러나 이 같은 파편화된 구조는 다음과 같은 근본적인 시스템 병목을 야기한다.

  • 지연 시간(Latency) 오버헤드: 모달리티 간 핸드오프(handoff), 프롬프트 확장, 작업 큐 대기, 개별 모델 실행, 결과 수집 및 재조합 과정이 중첩되면서 전체 시스템의 응답 속도가 급격히 저하된다.
  • 맥락 단절(Narrow Request Context): 작업을 위임받는 개별 전문 모델은 전체 대화나 시뮬레이션의 포괄적 맥락을 파악하지 못한 채 전달된 지극히 좁은 요청(narrow request)만 처리하므로, 다턴(multi-turn) 상호작용 시 정보 손실과 상태 불일치가 발생한다.
2.2 멀티모달 스택 해체 및 토큰 통합

Rho-1은 텍스트, 시각 정보(이미지 및 비디오 프레임), 로보틱스 제어 동작 및 고유 감각 신호를 단일 컨텍스트 윈도우 내부의 동일한 '토큰(tokens)'으로 단일화함으로써 기존의 분절된 멀티모달 스택을 단일 구조로 붕괴(collapse)시켰다.

  • 지속적 월드 상태(Persistent World State)로서의 KV 캐시: 모든 대화 기록, 생성된 시각 레이턴트, 내부 사슬형 사고(CoT) 추론, 방출된 로봇 제어 명령은 하나의 **KV 캐시(KV cache)**에 지속적으로 누적된다. KV 캐시는 모델 내에서 시간에 따라 동적으로 진화하는 '지속적인 월드 상태 메모리' 역할을 수행한다.
2.3 성능 및 속도 지표 비교

다음 표는 원문 보고서에서 레카 랩스가 직접 측정하여 보고한 주요 성능 및 처리 속도 수치이다.

참고 및 주의 사항: 본 표에 기술된 수치는 레카 랩스 연구진이 내부 실험 환경에서 직접 측정하여 보고한 내부 측정 수치(measured/illustrative values)이며, 독립적인 외부 검증 기관을 통해 확정된 표준 수치가 아님을 명시한다.

3.1 대칭적 표현 방식 (Discrete vs Continuous Tokens)

기존 시스템은 입력과 출력의 불균형(VLM은 멀티모달 입력을 받아 텍스트만 출력, 비디오 디퓨전 모델은 멀티모달 조건으로 픽셀만 출력)을 보였으나, Rho-1은 완전히 대칭적인 입출력 표현 구조를 취한다.

  • 이산 토큰 (Discrete Tokens): 텍스트, 기호적 추론, 사슬형 사고(Chain-of-Thought) 과정, 고수준 지시 명령 표상에 사용된다.
  • 연속 토큰 (Continuous Tokens): 이미지 레이턴트(latents), 비디오 프레임, 로봇의 관절 작동 행동(actions) 및 고유 감각(proprioception) 데이터를 표상한다. 연속적 물리 동역학을 양자화 손실이 발생하는 이산화 과정 없이 자연스러운 연속 공간 표현으로 직접 다룬다.
3.2 전문 가중치 스트림 및 공유 주의 집중 메커니즘

Rho-1의 트랜스포머 블록 내부 연산은 단일 블록 내부에서 **이해 스트림(Understanding stream)**과 **생성 스트림(Generation stream)**이라는 2개의 **전문 가중치 스트림(expert weight streams)**으로 분할되어 작동한다.

  • 공유 주의 집중(Shared Attention) 및 상태 공유: 두 스트림은 분리된 독립 모델이 아니라, 동일한 트랜스포머 블록 내에서 하나의 KV 캐시와 주의 집중 공간을 공유한다. 사용자의 입력, 모델의 사슬형 사고, 이전 비디오 프레임, 방출된 로봇 제어 명령이 하나의 맥락 안에서 상호 작용한다.
  • 제로-지연 핸드오프 (Zero-Latency Handoff): 이해 스트림이 자기회귀(Autoregressive) 디코딩을 통해 추론 및 샷 계획(shot plan)을 작성한 후 시각적 합성이 필요한 시점이 되면, 연산 과정에서 이산 핸드오프 토큰(예: <|content_media|>)을 방출한다. 이 토큰이 방출되는 즉시 제2의 모델 호출이나 도구 호출(tool call) 없이, 생성 스트림의 디퓨전 타워가 동일한 KV 캐시 상태를 읽어 들여 연속 레이턴트의 디노이징(Denoising) 연산을 연쇄적으로 트리거한다.
  • 동시 최적화 손실 함수: 모델 전체는 이산 시퀀스를 위한 '다음 토큰 예측(Next-token prediction)' 손실과 연속 시각·행동 레이턴트 생성을 위한 '플로우 매칭(Flow matching)' 손실을 통해 단일 신경망으로 엔드투엔드 동시 최적화된다.
  • 상호보완적 스케일링 효과 (Compounding Effect): 두 스트림이 주의 집중 공간을 공유함에 따라 모달리티 간 학습 결합 효과가 발생한다. 언어 사전 학습을 통해 모델의 공간 추론 능력이 향상되면 비디오의 시각적 일관성이 함께 개선되고, 로보틱스 트래젝토리로부터 풍부한 물리 동역학을 학습하면 실시간 시뮬레이션 및 제어 성능이 정밀해진다.

4. Rho-1이 개척하는 3대 프론티어 (Three Frontiers)

4.1 멀티모달 어시스턴트 (Multimodal Assistant)

Rho-1은 포스트혹(post-hoc) 캡셔닝 모델이나 외부 프롬프트 보강 도구 없이 단일 모델의 사슬형 사고(CoT) 및 내부 레이턴트 상태 직접 참조를 통해 복합 단계를 연쇄 처리한다.

  • 5턴(5-turn) 대화 데모 세부 과정:
    1. 정적 장면 생성 (Turn 1): 바다 위 등대 정경 생성을 요청받으면 모델이 스스로 샷 계획을 수립하고 디퓨전 타워를 통해 이미지를 렌더링.
    2. 바운딩 박스 지정 (Turn 2): 생성된 이미지 내 등대 위치에 좌표 토큰을 방출하여 바운딩 박스를 시각화 (외부 객체 탐지 모델 불필요).
    3. 애니메이션 비디오 전환 (Turn 3): 정적 이미지 표현을 다시 인코딩하지 않고 Context 내의 원본 표현을 직접 참조하여 드론이 등대로 접근하는 연속 비디오 생성.
    4. 날씨 편집 (Turn 4): 카메라 이동 경로 및 건물 구도를 유지한 채 폭설이 내리는 환경으로 비디오 편집.
    5. 변화 요소 해설 (Turn 5): 비디오 간 차이점에 대한 질의 시, 프레임을 외부로 추출해 분석하는 대신 비디오를 생성했던 내부 레이턴트 상태를 직접 읽어 일관된 텍스트 해설 제공.
4.2 제어 가능한 실시간 월드 모델 (Steerable Real-time World Model)

Rho-1은 비디오 클립을 끊임없이 이어붙여 시뮬레이션 내의 시간이 멈추지 않는 연속 스트리밍 환경을 제공한다.

  • 실시간 분기(Branching) 시뮬레이션: 스트리밍 도중 이해 스트림으로 새로운 지시가 입력되면 상태 메모리가 업데이트되고 즉시 새로운 경로가 렌더링된다. 예를 들어, 동일한 초기 0.5초 프레임을 공유한 상태에서 '좌회전(bank left)'과 '우회전(bank right)'이라는 상충된 명령이 주어지면, 화면잘림(cut)이나 재시작 없이 동일한 시작점으로부터 즉시 두 개의 서로 다른 유효 경로로 실시간 분기 시뮬레이션이 수행된다.
  • 주요 활용 분야:
    • 요청 기반 생성형 환경 (Generative environments on demand): 자율주행 알고리즘 검증 및 로보틱스 정책 학습에 필요한 3D 엣지 케이스 환경을 대화형으로 상호작용하며 실시간 시뮬레이션.
    • 무한 스트리밍 및 제어: 시청자가 연출가(Director)가 되어 날씨, 물리학적 조건, 제어 경로를 실시간으로 변경하며 중단 없는 스트림 시청 및 제어 가능.
4.3 로보틱스를 위한 월드-언어-행동 모델 (World-Language-Action Model)

Rho-1은 미래의 카메라 프레임을 예측하는 네트워크와 로봇 관절 작동(joint actuation) 명령을 출력하는 네트워크가 동일한 레이턴트 공간을 공유한다.

  • 통합 정책 및 물리 상호작용: 외부 플래너 없이 단일 네트워크가 환경의 미래 변화를 예측함과 동시에 LIBERO 시뮬레이션 환경 기준 7개의 액션 채널 및 손목 카메라(wrist view) 예측 프레임을 직접 출력한다. 텍스트 조건 지정만으로도 물체의 고체성과 물리적 접촉을 직관적으로 이해하여 바나나 들기, 손잡이로 컵 운반하기, 손목 카메라 기반 사과 잡기, 스폰지 집기, 상자 들기, 천 접기 등의 행동을 물체의 파손이나 그래픽 깨짐 없이 정확히 수행한다.
  • 역역학 모델(Inverse Dynamics Model, IDM) 파이프라인: 라벨이 없는 대규모 웹 비디오 데이터에는 로봇 제어 신호가 부재하다. 레카 랩스는 순수 비디오 프레임으로부터 관절 토크 및 조향각 등 숨겨진 제어 신호를 역추정하는 IDM을 적용하여, 웹 규모의 비디오를 로봇 사전 학습용 액션 토큰 데이터로 전환해 Rho-1에 공급한다.

5. 연구 프리뷰의 한계점 및 컴퓨팅 자원 분석

5.1 현재 모델의 실무적 한계 (Failure Modes)

원문 보고서는 현 단계 Rho-1의 명확한 실무적 한계점(Failure Modes)을 다음과 같이 제시한다.

  • 장기 드리프트 (Long-Horizon Drift): 30초 이상의 장시간 연속 스트리밍 시, 세부 질감은 유지되나 방 전체의 구조적·공간적 레이아웃이 와해되거나 공간적 일관성이 변형되는 현상이 발생한다.
  • 시간적 접지 (Grounding Across Time) 미흡: 정적 이미지에서의 위치 및 좌표 추정(Bounding Box)은 정밀하나, 시간 축이 포함된 비디오 내에서의 지속적인 객체 좌표 추적 기능은 미흡하다.
  • 편집 안정성 및 해상도 제한: 다양한 프롬프트 조건에 대한 시각적 편집 일관성이 아직 불안정하며, 기본 비디오 생성 해상도가 672×384로 제한되어 있다.
5.2 학습 자원, 연구진의 주장 및 서빙 인프라 분석
  • 학습 컴퓨팅 자원: Rho-1의 모든 결과물은 단 320개의 H100 GPU를 사용하여 3개월 동안 처음부터 학습시킨 결과이다. 이는 최신 프론티어 AI 모델들에 투입되는 자원에 비하면 매우 적은 수준이다.
  • 저자들의 학술적 주장 및 가설:
    • 저자들은 현재 나타나는 구조적 드리프트 및 해상도 제한 등의 한계가 모델 학습 스케일(컴퓨팅 자원 및 데이터량)을 확장함에 따라 자연스럽게 극복될 수 있는 문제라고 주장한다.
    • 파편화된 모델에 자원을 분산하는 대신 단일 아키텍처를 스케일업하는 것이 추론, 시각 생성, 물리 제어 성능을 상호 보완적으로 성장시키는 길이며, 이러한 단일 옴니 아키텍처로의 통합이야말로 **"물리적 AGI(Physical AGI)로 나아가기 위한 핵심 전제 조건"**이라는 입장을 밝히고 있다.
  • 옴니 모델 배포를 위한 3대 서빙 인프라 병목: 단일 옴니 모델을 실제 프로덕션 서빙 환경에 배포할 때는 기존 LLM 서빙 프레임워크와 다른 3가지 시스템적 과제가 수반된다.
    1. 이종 메모리 레이아웃 (Heterogeneous Memory Layouts): HBM 상에서 고처리량 이산 KV 캐시와 일시적인 연속 레이턴트 상태가 메모리 파편화 없이 공존해야 함.
    2. 동적 연산 집중도 변화 (Shifting Compute Intensity): 시각 합성 시의 연산 중심(Compute-bound) 대량 주의집중 연산과 텍스트 생성 시의 메모리 대역폭 중심(Memory-bandwidth-bound) 자기회귀 디코딩 간의 극심한 가변성 제어 필요.
    3. 엄격한 실시간 지연 시간 (Hard Real-Time Latency): 프롬프트 개입 및 실시간 조종 시 파이프라인 버블(pipeline bubble) 없이 분 단위 이하의 빠른 제어 반응 속도 확보 필요.

6. 결론

Rho-1 연구 프리뷰는 기존의 파편화된 에이전트 파이프라인을 해체하고, 단일 신경망과 통합 KV 캐시 구조 내부에서 이해, 생성, 추론, 행동을 완벽히 정합시킬 수 있음을 입증하였다. 320대의 H100 GPU로 구현된 이 대칭적 옴니 아키텍처는 지연 시간을 획기적으로 줄임과 동시에 실시간 월드 시뮬레이터 및 로보틱스 제어 모델로서의 뛰어난 가능성을 명확히 제시한다.

이 보고서는 제공된 원문만 사용했다
