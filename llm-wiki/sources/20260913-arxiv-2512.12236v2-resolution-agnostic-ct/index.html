Resolution-Agnostic Neural Operators for Multi-Rate Sparse-View CT

원문

CTO(Computed Tomography neural Operator): 다중 해상도 및 샘플링률 대응을 위한 희소 뷰 CT 재구성 기술 보고서

1. 희소 뷰 CT(Sparse-view CT)의 개요와 역문제(Inverse Problem)의 난제

희소 뷰 CT(Sparse-view CT, SVCT)는 방사선 피폭량을 최소화하고 촬영 효율을 극대화하기 위해 제한된 각도에서만 투영 데이터를 획득하는 기법이다. 본 연구의 핵심은 시노그램(Sinogram) 공간의 물리적 특성을 보존하면서도 불완전한 데이터로부터 고해상도 영상을 복원하는 것이다.

병렬 빔(Parallel-beam) 기하구조에서 투영 데이터 $p(\theta, r)$와 대상 이미지 $x$의 관계는 라돈 변환(Radon Transform) $R$을 통해 다음과 같이 정의된다: $$p(\theta, r) := R(x) + \epsilon$$ 실제 SVCT 환경에서는 샘플링 마스크 $M$이 도입되어 측정치 $\tilde{p} = Mp$가 생성된다. 이때 전체 순방향 오퍼레이터(Forward operator)를 $A := MR$로 정의할 수 있다. 샘플링 뷰가 극도로 제한됨에 따라 $M$ 오퍼레이터는 심각한 정보 손실을 야기하며, 결과적으로 역변환은 **부적절한 역문제(Ill-posed inverse problem)**가 된다. 이를 필터 보정 역투영(FBP)과 같은 직접 반전(Direct inversion) 방식으로 해결할 경우, 샘플링 이론에 따른 나이퀴스트 조건을 충족하지 못해 극심한 에일리어싱(Aliasing) 및 노이즈 아티팩트가 발생하여 진단적 가치를 상실하게 된다.

2. 기존 CNN 기반 접근법의 기술적 한계: 이산화 결합(Discretization Binding)

현재 딥러닝 기반의 CT 재구성 기술, 특히 CNN(Convolutional Neural Networks)은 고정된 이산 격자(Fixed discretized grids) 위에서 학습된다는 근본적인 설계 한계를 지닌다.

  • 수학적 수렴성 결여: CNN의 컨볼루션 커널은 특정 해상도에 고정되어 있다. 해상도가 높아짐에 따라 커널은 물리적 의미를 가진 '국소 적분 오퍼레이터(Local integral operators)'로서의 성질을 잃어버리고, 단순한 '점별 선형 매핑(Pointwise linear mappings)'으로 수렴하게 된다. 이는 모델이 해상도 변화에 따른 국소 구조의 변화를 수학적으로 포착하지 못하게 만든다.
  • 귀납적 편향(Inductive Bias)의 과적합: CNN 기반의 언롤드 네트워크(Unrolled Network)는 특정 샘플링률에 과적합(Overfitting)되어, 학습 시와 다른 장기(Organ)나 진단 프로토콜에 따라 샘플링 밀도가 변경될 경우 심각한 성능 저하와 아티팩트를 노출한다. 이는 수평적 이동 등변성(Translational equivariance)은 보유하나, 해상도 및 샘플링 불가지론(Agnostic)적 특성을 확보하지 못했기 때문이다.

3. CTO(Computed Tomography neural Operator)의 핵심 설계 원리

CTO는 이산화된 데이터가 아닌 무한 차원 함수 공간(Infinite-dimensional function spaces) 간의 매핑을 학습하는 뉴럴 오퍼레이터(Neural Operator, NO) 프레임워크를 CT 재구성에 최초로 도입하였다.

  • DISCO(Discrete–Continuous) Convolution: CTO의 기본 연산 단위인 DISCO는 커널 $\kappa$를 연속 함수로 정의한다. 이 커널은 입력 데이터의 실제 해상도에 맞춰 실시간으로 이산화(Discretize)된다. DISCO는 이론적으로 **이산화 수렴성(Discretization-convergent)**을 보장한다. 즉, 해상도가 증가함에 따라 근사 오차가 0으로 수렴하며, 단일 모델로 다양한 해상도에 대응할 수 있는 수학적 근거를 제공한다.
  • 함수 공간 기반 일반화: CTO는 특정 격자에 종속되지 않으므로, 추가적인 재학습이나 아키텍처 변경 없이도 다양한 측정 샘플링률과 이미지 해상도 사이의 이산화 간 일관성(Cross-discretization consistency)을 유지한다.

4. 이중 도메인(Dual-domain) 및 회전 등변성(Rotation-equivariant) 아키텍처

CTO는 물리적 일관성을 확보하기 위해 시노그램 공간($NO_s$)과 이미지 공간($NO_i$)을 순차적으로 정제하는 언롤드 아키텍처를 채택한다.

4.1 Sinogram-space Operator ($NO_s$): 물리적 연속성 보존

$NO_s$는 CT 측정의 고유 좌표계인 극좌표 $(r, \theta)$에서 직접 연산을 수행하여 프로젝션 오류를 최소화한다.

  • $\pi$-주기성 및 반전 대칭성($\pi$-periodicity-with-flip identity): CT의 물리적 특성상 180도($\pi$) 회전된 투영 데이터는 0도 데이터의 검출기 축($r$)을 반전(Flip)한 것과 동일하다. CTO는 이를 반영하여 각도($\theta$) 축에 대해 Flipped Circular Padding을 적용한다. 즉, $180^\circ + \alpha$의 데이터를 $\alpha$의 $r$축 반전 데이터로 처리함으로써 물리적 연속성을 보존하고 경계면 아티팩트를 획기적으로 억제한다.
  • Dual-branch 설계: 공간 정보를 처리하는 분기와 주파수 정보를 처리하는 분기를 병렬로 운영한다. 특히 주파수 분기는 $r$축을 따라 1D FFT를 수행하여 전역적인 구조적 특징을 포착하는데, 이는 Fourier Slice Theorem에 기반한 설계로 FBP 알고리즘의 장점을 수용한다.
4.2 Image-space Operator ($NO_i$): 고주파 세부 복원

$NO_s$를 통과한 데이터는 데이터 일관성(Data Consistency) 업데이트를 거쳐 $NO_i$로 전달된다. $NO_i$는 2D 데카르트 좌표계에서 DISCO 기반의 UDNO(U-Shaped DISCO) 구조를 통해 해부학적 미세 구조와 고주파 세부 정보를 정밀하게 복원한다.

5. 실험적 성능 검증 및 수치 결과

AAPM 저선량 복부 CT 및 Kidney CT 데이터셋을 활용하여 CTO의 성능을 검증하였다. CTO는 모든 뷰(View) 설정에서 기존 SOTA 모델들을 압도하는 결과를 보여주었다.

[표 1] AAPM 데이터셋 기반 재구성 성능 비교
모델 카테고리 알고리즘 18-view (PSNR / SSIM) 36-view (PSNR / SSIM) 72-view (PSNR / SSIM) 추론 속도

(주: CTO는 기존 CNN 기반 Unrolled 모델 대비 평균 3.4dB 이상의 PSNR 향상을 기록함)

주요 분석 결과
  • 효율성: CTO는 Diffusion 모델(DPS 등) 대비 약 3dB 이상의 PSNR 이득을 얻으면서도, 반복적 샘플링 과정이 필요 없어 추론 속도가 500배 이상 빠르다. 또한 모델 파라미터와 FLOPs 오버헤드는 기존 CNN 기반 Unrolled Network와 유사한 수준을 유지한다.
  • OOD(Out-of-Distribution) Robustness: CTO는 학습 시와 다른 샘플링 패턴(Different sampling rates) 하에서도 성능 저하가 거의 없었으며, 특히 제로샷 초해상도(Zero-shot super-resolution) 환경에서도 강건한 복원 능력을 입증하였다. 이는 DISCO의 이산화 수렴성이 실질적인 일반화 성능으로 이어짐을 의미한다.

6. 연구의 범위와 실용적 한계

본 보고서의 수치 결과는 논문 저자들이 설정한 특정 시뮬레이션 환경(Parallel-beam 등)과 AAPM/Kidney 데이터셋 내에서 도출된 것이다. CTO는 Neural Operator를 활용하여 SVCT 재구성을 위한 원칙적이고 실용적인 패러다임을 제시하였으며, 해상도 의존성이라는 딥러닝 재구성의 고질적 난제를 해결하였다. 비록 임상 현장의 모든 가변적인 환경(Fan-beam, Cone-beam 등)에 대한 즉각적인 적용은 추가 검증이 필요하나, 본 기술은 차세대 고유연성(Flexible) 지능형 의료 영상 시스템의 핵심 기반 기술이 될 것으로 평가된다.
