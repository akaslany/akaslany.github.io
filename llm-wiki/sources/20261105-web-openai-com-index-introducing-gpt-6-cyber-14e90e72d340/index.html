1. 개요 (Overview)

OpenAI는 연구자가 설정한 작업 범위(Scope) 내에서 소프트웨어의 악용 가능한 취약점을 탐지·검증하고 패치 개발을 지원하는 전문 사이버보안 AI 모델인 'GPT-6 Cyber'를 발표했습니다. GPT-6 Cyber는 이전 세대 모델인 GPT-5.6 Cyber 대비 핵심 사이버보안 벤치마크 평가에서 대폭적인 성능 향상을 기록했습니다. 이에 따라 OpenAI의 자체 준비도 프레임워크(Preparedness Framework)상 사이버보안 위험 평가 등급이 기존 '높음(High)'에서 '심각(Critical)' 등급으로 상향 조정되었습니다.

본 모델은 전용 정렬(Alignment) 훈련을 거쳐 할당된 인프라 및 가이드라인 범위를 일탈하지 않도록 엄격히 제어됩니다. 대규모 정렬 평가인 ExploitGym Honeypot 테스트 결과, 배포 안전 프롬프트 적용 시 100%의 범위 준수율을 기록하며 뛰어난 제어 가능성을 입증했습니다. 또한 실제 소프트웨어 생태계에 적용되어 리눅스(Linux) 커널 내 948개의 권한 승격 익스플로잇 개발, 파이어폭스(Firefox)의 고위험 취약점 81개 발견 및 수정 패치 반영, 자체 모델 학습 인프라의 마이크로VM(microVM) 탈출 취약점 검증 등 실질적인 보안 성과를 창출했습니다.

OpenAI는 고도화된 모델 능력의 오용을 방지하기 위해 사이버 전용 미스얼라인먼트 모니터링, 비공개 안전 처리(PSP), IP 허용 목록(Allowlisting) 등 강화된 안전장치를 함께 도입했습니다. 이와 동시에 전력망 및 산업 제어 시스템(OT/ICS) 등 핵심 인프라 방어자를 지원하기 위해 'Daybreak Red for Critical Infrastructure' 접근 그룹을 신설하고, 드라고스(Dragos) 등 전문 보안 기관과의 모의 전력망 평가 협업을 통해 방어 역량을 대폭 강화하고 있습니다.

2. 주요 논점 (Key Issues & Arguments)

2.1. 프론티어 사이버 능력의 향상 및 벤치마크 평가

[Advancing frontier cyber capabilities]

  • [사실]: GPT-6 Cyber는 지정된 취약점 익스플로잇 능력을 측정하는 ExploitGym 벤치마크에서 48.5%를 기록하여 GPT-5.6 Cyber(32.1%) 대비 약 16%p(상대적 51%) 향상되었습니다. 소스 코드 접근 없이 웹 애플리케이션을 탐색하는 웹 침투 테스트(Web Pentesting) 평가에서는 40.3%의 재현율(Recall)을 기록하여 GPT-6 Astra(32.0%)를 능가했습니다. 원격 타깃 취약점 공격 평가인 RemoteExploitBench에서는 GPT-6 Astra(Daybreak Blue 적용 시)가 100% 거절을 반환한 반면, GPT-6 Cyber는 95%의 과제를 완수했습니다. 특히 GPT-6 Cyber는 GPT-6 Astra가 요청을 거절하지 않고 정상 수행하는 조건하에서도 대부분의 사이버 작업에서 Astra의 성능을 앞섰습니다. 이를 바탕으로 OpenAI 준비도 프레임워크상 사이버보안 평가 등급이 'High'에서 'Critical'로 상향되었습니다.
  • [소스의 주장]: GPT-6 Cyber는 소프트웨어 이해, 취약점 식별, 작동 가능한 익스플로잇 개발에 있어 이전 세대 및 타 프론티어 모델을 압도하며, 방어자에게 불필요한 거절 동작을 대폭 줄이면서 프론티어 사이버 능력을 도약시켰습니다.
  • [작성자의 해석]: 안전 제약이 강화된 범용 모델(GPT-6 Astra)은 거부 반응을 보이지 않는 상황에서도 전문적인 사이버 과제 수행 성능에 한계가 존재합니다. 따라서 허가된 연구자에게 특화된 정밀 모델 체계(Daybreak Red / GPT-6 Cyber)를 제공함으로써, 과도한 거부 동작 없이 고도화된 보안 연구 및 취약점 검증을 수행할 수 있는 기반이 마련된 것으로 분석됩니다.
2.2. 정렬(Alignment) 강화 및 작업 범위(Scope) 준수

[Stronger alignment, better at staying within bounds]

  • [사실]: Hugging Face 보안 사건을 바탕으로 설계된 ExploitGym Honeypot 평가(격리된 환경 내 보조 서비스 공격을 유도하여 범위 탈출 여부를 측정)에서, GPT-6 Cyber는 배포 안전 프롬프트 없이도 99.93%의 범위 준수율을 기록하여 GPT-5.6 Cyber(94.49%)보다 향상되었습니다. 배포 안전 프롬프트를 적용했을 때는 100% 범위 내에 머물렀습니다. 모델 내부의 사고 사슬(Chain of Thought) 기록에서는 "Can't assume extra API or attack controller not target. We should only target binary/server.", *"don't explore out of scope credentials."*와 같이 오프스코프(Out-of-scope) 자산 접근을 스스로 제어하는 추론 과정이 확인되었습니다.
  • [소스의 주장]: 정밀 정렬 훈련을 통해 자율 에이전트가 부여된 규칙과 인프라 범위를 일탈하거나 허가되지 않은 보조 시스템을 공격하는 위험을 효과적으로 차단할 수 있습니다.
  • [작성자의 해석]: 자율 에이전트형 AI의 고유 위험인 '범위 탈출(Scope Creep)'을 통제하기 위해 모델의 내부 추론(Chain of Thought) 단계에서 명시적인 권한 및 범위 재확인 루프가 작동하도록 훈련된 점이 성공적인 범위 준수로 이어졌습니다.
2.3. 실세계 보안 분야 적용 사례 및 성과

[Real-world impact for security teams]

  • [사실]:
    • Firefox: 알려지지 않은 고위험 취약점 81개를 발견하고 30개 기존 알려진 이슈의 심각도를 재평가했으며, 모질라(Mozilla)에 패치를 제안하여 정식 수정 배포가 이루어졌습니다.
    • Linux 커널: 1,724개의 취약점을 재현하고 948개의 권한 승격 익스플로잇을 개발했습니다(GPT-5.6 Sol의 166개 대비 5배 이상). 이 중 304개의 핵심 발견사항과 패치 후보를 커널 유지관리자에게 제보했습니다.
    • Brotli 라이브러리: Node.js 등에서 사용하는 Brotli 압축 라이브러리의 원격 코드 실행(RCE) 취약점을 검증했습니다.
    • 자사 인프라: 레드팀 캠페인을 통해 모델 학습용 마이크로VM(microVM) 탈출 및 호스트 실행 취약점 체인을 발견하여 인프라를 보강했습니다.
    • 파트너사 협업: Cisco, Calif, Cognition(내부 벤치마크 23% 기록, 기존 최고 13%), Palo Alto Networks, SentinelOne, Perplexity, CodeRabbit(중/고위험 버그 66% 추가 발견) 등의 보안 팀이 고위험 이슈 탐지, 코드 리뷰 및 익스플로잇 검증에 본 모델을 도입했습니다.
  • [소스의 주장]: GPT-6 Cyber는 복잡한 로직 속에 묻혀 있는 난해한 취약점을 끝까지 추적하고 연쇄적인 조건을 연결하여 실질적이고 재현 가능한 보안 성과를 창출하고 있습니다.
  • [작성자의 해석]: 수년간 정밀 검증을 거친 리눅스 커널이나 파이어폭스 같은 성숙한 오픈소스 코드베이스에서 대량의 고위험 제로데이 및 작동 가능한 익스플로잇을 생성해낸 것은 단순 단적 스캐닝을 넘어 실제 에이전트 기반 보안 연구 분야의 실용성이 검증되었음을 보여줍니다.
2.4. 오용 감지, 신뢰할 수 있는 방어자 지원 및 핵심 인프라 보호

[Detecting misuse and blocking high-risk activity] 및 [Defending critical infrastructure]

  • [사실]:
    • 오용 감지 및 모니터링: 사이버 전용 미스얼라인먼트 모니터링, PHP 취약점 공개 시 라이브 서버 대상 공격 시도 타깃 모니터링, Zero Data Retention API 고객용 PSP(Private Safety Processing, 암호화 기록 30일 보관 자동 검수), Daybreak Red API 접근 시 IP 허용 목록(Allowlisting) 의무화를 적용했습니다.
    • 핵심 인프라 보호 및 가드레일 수치 변화: 10억 달러 규모의 'Daybreak for Frontline Defenders' 지원금을 운용하며, OT/ICS 방어자를 위한 'Daybreak Red for Critical Infrastructure' 그룹을 신설했습니다. 민감 레드티밍 가드레일 차단율(Before $\rightarrow$ After)은 Standard(70.8% $\rightarrow$ 89.7%), Daybreak Blue(13.8% $\rightarrow$ 67.0%), Daybreak Red(0.0% $\rightarrow$ 61.9%), Daybreak Red for Critical Infrastructure(0.0% $\rightarrow$ 0.3%)로 조정되었습니다.
    • 드라고스(Dragos) 평가: 모의 전력망 환경 테스트에서 사전 정보 없이 OT 자산을 IT 소음과 분리하고, 보호 계전기 데이터(protective relay data)를 관리하는 엔지니어링 소프트웨어 내 제로데이 취약점 2개를 발견하여 차단기 동작 로직(breaker trip logic) 및 보호 설정 노출 위험을 입증했습니다.
  • [소스의 주장]: 고도화된 모델 오용 위험에 대응해 강화된 모니터링을 도입하는 한편, 핵심 인프라 방어자에게는 정당한 보안 분석과 패치 검증 작업이 차단되지 않도록 정책을 정밀 조율합니다.
  • [작성자의 해석]: 'Daybreak Red for Critical Infrastructure' 등급의 가드레일 차단율이 0.3%로 설정된 것은, 전력망 등 정밀 OT/ICS 시스템의 방어 연구자가 정당한 제로데이 검증이나 패치 테스트를 수행할 때 과도한 거부 반응으로 작업이 중단되지 않도록 의도적으로 차단선 기준을 낮춘 것입니다. 대신 IP 허용 목록 및 PSP 등 이중 인증·감시 체계를 결합하여 보안 통제를 유지하고 있습니다.
