1. 개요 (Overview)

[사실] 본 보고서는 엔비디아(NVIDIA) 연구진이 발표한 40억 개(4B) 파라미터 규모의 잠재 재귀/루프형(Latent-recurrent) 언어 모델인 Dory1.0-4B의 아키텍처, 학습 파이프라인, 성능 평가 및 추론 최적화 기술을 체계적으로 분석합니다. Dory1.0-4B는 단일 체크포인트로 가변적 추론 연산 예산(Elastic depth)을 지원하도록 설계되었습니다. 이를 통해 재훈련이나 모델 교체 과정 없이 추론 시점의 루프 반복 횟수($k$)를 유연하게 조정하여 추론 연산량과 성능 간의 균형을 즉각적으로 제어할 수 있습니다. (근거: Abstract, Section 1)

[사실] 모델의 백본 아키텍처는 정규화 트랜스포머(Normalized Transformer, nGPT)를 기반으로 구축되었으며, 게이트형 그룹 쿼리 어텐션(GQA)과 슬라이딩 윈도우 어텐션(SWA) 및 전체 어텐션(Full Attention)이 3:1 비율로 교차 배치된 72개의 물리적 레이어로 구성됩니다. 전체 물리적 스택은 16개 레이어의 입력 블록(Input block), 40개 레이어의 공유 재귀 블록(Shared recurrent block), 16개 레이어의 출력 블록(Output block)으로 분할됩니다. 추론 과정에서 입력 및 출력 블록은 단 1회만 실행되며, 공유 재귀 블록은 설정된 추론 연산 예산에 따라 $k$회 반복 적용됩니다. (근거: Abstract, Section 1, Section 2)

[사실] 학습 파이프라인은 3단계 사전 학습과 사후 학습(Post-training) 파이프라인으로 구성됩니다. 사전 학습은 총 6조(6T) 토큰으로 수행되었으며, 초기 4.5조 토큰은 NVFP4 정밀도로 기본 모델을 학습한 후, 1.5조 토큰 동안 BF16 정밀도에서 루프 재귀 구조와 절단된 루프 역전파(TBPTL)를 도입하여 진행되었습니다. 이후 3,000억(300B) 토큰의 추가 학습을 통해 컨텍스트 길이를 262,144(256K) 토큰으로 확장했습니다. 사후 학습 단계에서는 지도 미세 조정(SFT)과 난이도 인식 루프 커리큘럼(Difficulty-Aware Loop Curriculum)이 결합된 검증 가능한 보상 기반 강화학습(RLVR)을 적용했습니다. (근거: Abstract, Section 3, Section 4)

[사실] 벤치마크 평가에서 Dory1.0-4B는 루프 반복 횟수($k$)가 증가함에 따라 코딩, 에이전트, 긴 컨텍스트 이해 영역을 중심으로 현저한 성능 향상을 나타냈습니다. 12개 주요 벤치마크 평균 점수 기준 $k \ge 2$ 설정 시 Qwen3.5-9B, Gemma 4 12B, Gemma 4 26B-A4B 등 가용 파라미터가 훨씬 큰 모델들을 상회했습니다. 또한 루프 반복을 통해 연산을 텍스트 생성이 아닌 잠재 공간(Latent space) 내부에서 수행함으로써, 에이전트 작업에서 시도당 생성 토큰 수를 1.3~2.5배 감소시키는 높은 토큰 효율성을 입증했습니다. (근거: Abstract, Section 1, Section 4.3, Section 4.4)

2. 주요 논점 (Key Arguments & Technical Analysis)

2.1. 모델 아키텍처 및 루프 재귀 구조

[사실] Dory1.0-4B는 물리적으로 총 72개의 레이어(36개 MLP 전용 레이어, 27개 SWA 레이어, 9개 Full Attention 레이어)로 구제화됩니다. 이 스택은 16개 레이어의 입력 블록, 40개 레이어의 공유 재귀 블록, 16개 레이어의 출력 블록으로 구조화되어 있습니다. (근거: Section 1, Section 2)

[사실] 입력 블록의 출력 벡터를 $x$라 하고 공유 재귀 블록의 연산을 $F_\theta$, 토큰별 L2 정규화 연산자를 $N$이라 할 때, 루프 전방 재귀 메커니즘은 다음 수식에 따라 작동합니다.

  • 초기 상태 설정: $s_0 = x$
  • $t$번째 루프 순환 ($t = 1, \dots, k$): $$u_t = N(s_{t-1} + x)$$ $$s_t = N(F_\theta(u_t))$$ 최종 생성된 상태 $s_k$는 별도의 어댑터 파라미터 추가나 외부 잔차 연결 없이 출력 블록 및 언어 모델 헤드(LM Head)로 전달되어 로짓 $z_0 = s_k \cdot (s / \sigma_0)$ 형태로 변환됩니다. (근거: Section 2, Figure 2)

[사실] Dory1.0-4B는 초시공간 하이퍼스피어 상에서 표현 학습을 수행하는 nGPT 아키텍처의 잔차 업데이트 규칙을 수용하고 이를 확장했습니다. 서브레이어의 잔차 혼합(Residual Blending) 수식은 다음과 같이 정의됩니다. $$\text{Output} = N\left( (1 - a) \cdot N(x) + a \cdot N(\text{Sublayer}(N(x))) \right)$$ 여기서 $a = |\hat{\alpha}|$는 채널별 학습 가능한 스케일링 가중치입니다. 원본 nGPT 논문이 잔차율 하이퍼파라미터 및 쿼리-키 스케일을 $1/\sqrt{d_{\text{model}}}$로 초기화했던 것과 달리, Dory1.0-4B 연구진은 초기 파라미터를 $\sigma_0 = 0.0177$로 설정하면서 실효 잔차율(Effective residual rate)을 0.05 수준으로 일정하게 유지하도록 설계했습니다. 정규화 연산은 $\epsilon = 10^{-6}$ 조건을 갖는 FP32 정밀도의 단일 단위 L2 정규화(Unit norm)를 적용하며, 헤드 단위 L2 정규화($h_q d_h$), 결합된 어텐션 출력 L2 정규화, SwiGLU 활성화 전후의 L2 정규화 연산을 융합된 Triton 커널로 구동하여 수량적 연산 병목을 제거했습니다. (근거: Section 2, Figure 2)

[사실] 레이어 교차 구성 측면에서는 슬라이딩 윈도우 어텐션(SWA)과 전체 어텐션(Full Attention)이 3:1 비율로 배치됩니다. 8개 레이어마다 3개의 SWA-SwiGLU 쌍과 1개의 Full Attention-SwiGLU 쌍이 교차 배치되는 구조입니다. SWA는 윈도우 크기 $W=1024$ 토큰 및 RoPE base $\theta=10^4$를 채택하고, 전체 어텐션은 사전 학습 초기 $\theta=500,000$에서 컨텍스트 확장 단계 시 $\theta=10^7$로 전환되었습니다. 어텐션 구조는 16개 쿼리 헤드와 4개 KV 그룹을 갖는 GQA(Grouped-Query Attention) 사양을 따르며, 시그모이드(Sigmoid) 기반의 입력 의존형 어텐션 출력 게이트를 적용했습니다. (근거: Section 1, Section 2, Section 3.4)

2.2. 사전 학습 및 확장 파이프라인

[사실] 사전 학습 파이프라인은 3가지 연차적 단계로 구율화되어 진행되었습니다. (근거: Section 3.1 ~ 3.4)

  1. 1단계: NVFP4 사전 학습 (약 4.535조 토큰)
    • 엔비디아 트랜스포머 엔진(Transformer Engine)의 NVFP4 블록 스케일링 방식을 적용하여 지원되는 선형 레이어 행렬 곱셈 연산에 E2M1 4비트 피연산자를 활용했습니다. 모델 가중치는 BF16, 옵티마이저 마스터 가중치/Adam 모멘트/그래디언트 집계는 FP32를 유지함으로써 BF16 대비 엔드투엔드 학습 속도를 20% 향상시켰습니다.
    • 첫 3조 토큰은 시퀀스 길이 8,192에서 다변성 중심의 1단계 데이터 믹스로 학습하였으며, 이후 고품질 2단계 데이터 믹스로 전환하면서 시퀀스 길이를 32,768로 확장했습니다. 글로벌 배치 크기를 768에서 192 시퀀스로 축소하여 스텝당 6,291,456 토큰의 처리량을 고정 유지했습니다. 최고 학습률은 $3.2 \times 10^{-4}$에서 시작하여 6조 토큰 시점에 $10^{-5}$에 도달하도록 마이너스 제곱근(minus-square-root) 감쇄 스케줄을 적용했습니다.
  2. 2단계: BF16 루프 재개 학습 (약 1.465조 토큰, 누적 6조 토큰)
    • NVFP4 사전 학습 체크포인트를 바탕으로 BF16 정밀도로 재개(Continuation) 학습을 수행하였으며, 이 단계에서 물리적 레이어를 16개 입력, 40개 공유 재귀, 16개 출력 블록으로 나열하여 루프 재귀 아키텍처를 적용했습니다.
    • 루프 수 $k \in {1, 2, 3, 4}$ 확률 분포(각 0.25)를 기본 적용하되, 0.1 비율의 랭크 수준 순환 오버라이드(Rank-level override)를 도입하여 192개 데이터 병렬 리플리카 중 약 9.9%(19개)가 정밀하게 $k=1$을 실행하도록 설정했습니다.
    • 절단된 루프 역전파 (TBPTL, 깊이 1) 메커니즘: 메모리와 연산 오버헤드를 제어하기 위해 깊이 1의 TBPTL을 적용했습니다. 이전 루프 반복($t = 1, \dots, k-1$)은 그래디언트 추적(Gradient tracking) 없이 순방향 연산만 수행되며, 최종 반복($t=k$)과 입력 및 출력 블록에만 그래디언트가 전달됩니다. 이때 입력 블록은 최종 루프 반복의 잔차 입력 연결($x$)을 통해 그래디언트를 역전파 수신합니다. 손실 함수는 최종 루프 출력에 대해서만 다음 토큰 교차 엔트로피를 계산하며 중간 루프 보조 손실은 적용하지 않습니다.
  3. 3단계: 긴 컨텍스트 확장 (약 3,000억 토큰, 누적 6.3조 토큰)
    • 시퀀스 길이를 32,768토큰에서 262,144(256K)토큰으로 확장했습니다. 전체 어텐션의 RoPE base를 기존 $500,000$에서 $10,000,000$($10^7$)으로 변경하였으며, SWA의 RoPE base($10,000$) 및 윈도우 크기($1,024$)는 유지했습니다.
    • 옵티마이저 상태를 초기화하고 학습률 $10^{-5}$ 고정값으로 47,683 스텝 동안 학습을 수행했습니다. 8방향 컨텍스트 병렬 처리(Context Parallelism)와 24방향 데이터 병렬 처리를 결합했으며, 24개 데이터 병렬 리플리카 중 2개(약 8.3%)에 $k=1$ 오버라이드가 적용되었습니다.
2.3. 사후 학습: SFT 및 난이도 인식 RLVR

[사실] 사후 학습 파이프라인은 지도 미세 조정(SFT) 단계와 검증 가능한 보상 기반 강화학습(RLVR) 단계로 연속 구성됩니다. (근거: Section 4.1 ~ 4.2)

  • SFT 단계: 256K 토큰으로 패킹된 시퀀스 데이터셋 환경에서 128 글로벌 배치 크기로 9에포크(32,400 이터레이션) 동안 학습을 수행했습니다. 사유 표현 입력(<think> ... </think>)과 비사유 표현 입력을 조합하여 응답을 정렬했습니다. 에포크 1(3,600 이터레이션)에서 에포크 9로 진행됨에 따라 $k=1$ 기준 SciCode(13.11% $\rightarrow$ 18.14%), Terminal-Bench v2.1(4.2% $\rightarrow$ 13.5%), GPQA Diamond(43.13% $\rightarrow$ 54.95%), IFBench(28.94% $\rightarrow$ 38.50%), MATH-500(60.2% $\rightarrow$ 75.2%), AA-LCR(29.5% $\rightarrow$ 37.3%) 등 전 방위적 지표가 비약적으로 상승했습니다.
  • RLVR 단계: 코딩, 에이전트, 긴 컨텍스트 QA, 지시 이행 등 23개 단일 스텝 환경에서 200스텝 동안 비동기 그룹 상대 정책 최적화(GRPO)를 전개했습니다. 학습 전, SFT 체크포인트 기반으로 프롬프트 당 8개 응답을 수집·채점하여 평균 보상이 0 초과 1 미만인 유효 프롬프트를 필터링했습니다.

[소스의 주장 및 설명] 난이도 인식 루프 커리큘럼 메커니즘 (Difficulty-Aware Loop Curriculum) RLVR 단계에서는 프롬프트의 미세 조정 단계 보상 승률(프로파일링 패스율)을 프롬프트의 난이도 대리 지표로 설정하고, 난이도가 높은 프롬프트일수록 더 깊은 루프(높은 $k$값)를 실행하는 롤아웃 워커에 배치하는 라우팅 커리큘럼을 도입했습니다. (근거: Section 4.2)

$$s_i = \alpha q_i + (1 - \alpha) u_i \quad (\text{단, } u_i \sim \text{Uniform}(0, 1), \alpha = 0.3)$$

여기서 $q_i$는 프롬프트의 프로파일링 보상 점수에 대응하는 분위수(Quantile)이며, $u_i$는 무작위 균등 난수입니다. 라우팅 점수 $s_i$가 낮은 프롬프트(즉, 보상 승률 $q_i$가 낮아 난이도가 높은 프롬프트)가 deeper loop 수용 슬롯을 우선적으로 점유하게 됩니다. $\alpha=0.3$ 보간 가중치를 적용함으로써 단조적인 난이도 정렬 방식에 무작위성을 결합하여 정책 탐색의 경합을 방지했습니다.

[사실] 커리큘럼 적용 여부에 따른 절멸 연구(Ablation) 결과, 루프 커리큘럼 적용 시 미적용 대비 $k=4$ 설정에서 Terminal-Bench v2.1 점수가 14.0%에서 21.4%로 상승(7.4%p 증가)하고, GDPval-AA v2 지표가 98 Elo 상승(869 $\rightarrow$ 967 Elo), $\tau^3$-Banking이 4.9%p 상승하는 등 고난도 에이전트 과제에서 탁월한 성과를 보였습니다. (근거: Section 4.2, Figure 5)

5. 한계와 불확실성 (Limitations & Uncertainties)

[사실 및 해석] 소스 문서 분석을 통해 명확히 확인된 본 아키텍처의 한계점 및 미확인 불확실 요소는 다음과 같습니다.

  • 루프 횟수 확장에 따른 성능 정체 (Saturation):
    • 베이스 모델 평가(Base Model Evaluation, Table 1) 결과, 공유 재귀 블록의 루프 횟수 $k$를 4 이상($k=6, 8$)으로 확장하는 연산 외삽(Extrapolation) 시 MMLU, GSM8K, MBPP 등 주요 지표에서 추가적인 성능 향상이 관찰되지 않거나 정체되는 한계가 관찰되었습니다. 이에 따라 사후 학습 및 본 평가에서는 최대 루프 수가 $k=4$로 한정되었습니다. (근거: Section 3.5, Table 1)
  • 작업 과제 유형별 개선 효율의 이질성:
    • 지식 신뢰성 및 단순 정보 인출을 평가하는 AA-Omniscience accuracy 지표의 경우, 루프 횟수를 $k=1$에서 $k=4$로 늘려도 점수가 10.03%로 동일하게 정체되었습니다. 잠재 공간 연산 확장이 모든 인지 작업 유형에서 균일한 이점을 제공하지 못함을 나타냅니다. (근거: Section 4.3, Table 2)
  • Last-loop KV 캐싱 적용 시 특정 벤치마크 점수 손실:
    • 메모리 고정을 위한 Last-loop KV 캐싱 기법 적용 시, 대다수 벤치마크에서는 성능 변동이 미미했으나 장문 문맥 이해를 측정하는 AA-LCR 벤치마크의 경우 Per-loop 캐싱 대비 점수가 2.12포인트 하락(72.94% $\rightarrow$ 70.81%)하는 성능 손실이 확인되었습니다. (근거: Section 6.1, Table 6)
  • 소스 텍스트 상의 미확인 요소 (확인 불가 사항 명시):
    • 저자별 세부 역할 분담: 저자의 성명 및 소속 기관은 기재되어 있으나, 각 저자별 세부 구현/실험 구획 업무는 명시되지 않음 ("확인 불가").
    • 사전 학습 데이터셋의 저작권 및 인스턴스 명세: Nemotron 계열 커리큘럼 데이터 믹스가 사용되었음은 서술되어 있으나, 데이터 인스턴스의 구체적인 개별 저작권이나 전수 데이터 명세는 서술되지 않음 ("확인 불가").
    • 타사 모델과의 평가 하네스 차이 가능성: 타사 모델(Qwen, Gemma 등)과의 수치 비교 시 NeMo Gym / NeMo Evaluator 기반 통일 프로토콜을 준수했으나 외부 공개 모델의 자체 발표 수치(† 표기) 간 환경 및 하네스 차이가 존재할 수 있음이 명시됨. (근거: Section 4.3)
