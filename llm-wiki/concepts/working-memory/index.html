Working Memory

근거 소스 3편

추출 근거

5세 작업기억이 6년 뒤 문해·수리 성취를 예측했고 해당 연구에서 IQ보다 강한 예측자였다.

Alloway와 Alloway의 연구에서는 5세 아동의 작업기억이 6년 뒤 문해·수리 성취를 예측했으며 해당 표본에서 IQ보다 강한 예측자였다. 근거 A

9~12세 81명, 언어 IQ와 나이를 통제한 분석에서 작업기억의 고유 설명분산은 수학 유창성 5%, 계산 4%였다.

Blankenship 등의 9~12세 아동 81명 연구에서 언어 IQ와 나이를 통제한 뒤 작업기억의 고유 설명분산은 수학 유창성 5%, 계산 4%였다. 근거 A

이 결과는 아동 표본의 통계적 예측이며 전문 수학자·LLM 비교 실험이 아니다.

보고서는 아동 작업기억 연구가 전문 수학자와 LLM 사이의 격차 원인을 직접 입증하지 못한다고 해석한다. 근거 A

정책은 전체 이력이 아닌, 현재 WM에 기록된 '미해결 상태'를 기준으로 EM에서 필요한 기술만을 선택한다.

Recuris의 호출 정책은 작업 메모리에 기록된 미해결 상태를 기준으로 경험적 메모리에서 필요한 기술을 선택한다. 근거 B
