사후 학습 규모 확대

Z.ai는 전작과 동일한 기반 모델에서 출발해 사후 학습 규모를 늘렸으며, 코딩 성능 향상이 이 과정에서 비롯됐다고 설명했다. 근거 A · 근거 B

특정 업무에 맞춘 사후 학습

Harvey와 Fireworks는 장기 법률 업무에 맞춰 기반 모델을 사후 학습해 Tenet을 개발했다. Harvey는 법률 업무를 모사한 환경에서 전문가가 마련한 평가 기준과 판별 모델을 결합해 에이전트의 수행에 보상을 부여했다. 근거 C

Harvey의 내부 평가에서는 보류 과제의 성공 건수와 전체 통과율이 기반 모델보다 높았다. 계약 업무 평가에는 공개 리더보드가 없었다. 근거 C

기업 운영에서의 평가

기업 AI 운영 전략 보고서는 평가 결과를 바탕으로 실행 환경과 입력 맥락을 조정하고, 사후 학습과 온라인 학습을 거쳐 다시 평가하는 반복 과정을 제시한다. 근거 D
