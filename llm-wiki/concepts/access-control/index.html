금융 서비스의 권한 검사

금융권 개인정보 유출을 다룬 보고서의 원출처는 업무 편의를 위해 권한 검사를 느슨하게 적용한 보조 기능이 침해 경로가 됐다고 주장했다. 보고서는 연이은 유출 이후 금융위원장이 전체 금융사에 IT 자산과 서비스 전수 파악, 접근 통제, 취약점 재점검, 침해 탐지 체계 재정비를 지시했다고 기록했다. 근거 B

내부 기술의 외부 접근 제한

Poetiq을 다룬 보고서는 회사가 재귀적 자기개선 기술을 내부 전용으로 운영하고 외부 판매를 제한한다고 전했다. 작성자는 판매 제한만으로 기술의 안전성을 입증할 수 없다고 평가했으며, 내부 기술 문서나 외부 보안 평가 결과를 독립적으로 검증하지 않았다고 밝혔다. 근거 A

민감한 데이터의 접근 제한
