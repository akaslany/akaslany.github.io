업무 적용

오픈라우터 CEO 아탈라는 프런티어 모델이 전체 작업을 조율하고, 비용이 낮은 오픈웨이트 하위 에이전트가 정형화된 작업을 맡는 구성을 유망하게 봤다. 근거 A

켄 그리핀은 미국 기업들이 안소픽이나 오픈AI의 고가 프런티어 모델이 필요한 업무와 저렴한 오픈소스 모델로 처리할 수 있는 업무를 구분하기 시작했다고 말했다. 근거 C

모델 경쟁

아탈라는 중국이 오픈웨이트 모델의 개발과 배포 속도에서 미국을 앞선다고 평가했다. 사이버 보안 기능과 복잡한 장기 과업에서는 중국 모델이 서구 프런티어 모델에 뒤처진다고 봤다. 근거 A

이철 박사는 미·중 경쟁을 분야별로 나눠 미국이 프런티어 모델에서 앞서고 중국이 오픈소스와 피지컬 AI에서 우세하다고 평가했다. 근거 D

개발사의 안전 협약

올인 팟캐스트를 정리한 보고서는 주요 프런티어 모델 개발사들이 백악관 초지능 협약에 서명했다고 전했다. 삭스가 소개한 협약에 따르면 이사회 내 독립 위원회가 외부 감사인의 검증 보고를 직접 받는다. 근거 B
