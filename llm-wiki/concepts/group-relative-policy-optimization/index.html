이진 보상과 코드 품질

가가르 보고서는 이진 보상을 쓰는 GRPO가 같은 그룹에서 테스트를 통과한 모든 실행 궤적에 동일한 결과 어드밴티지를 부여해 코드 품질 차이를 반영하기 어렵다고 지적한다. 근거 A

가가르는 성공과 실패가 함께 있는 그룹만 학습에 사용한다. 품질이 낮은 성공 궤적에서 줄인 어드밴티지를 품질이 높은 성공 궤적에 배분해 양의 어드밴티지 총합을 보존하고, 실패 궤적의 어드밴티지는 기존 값을 유지한다. 근거 A

하네스 제안자 학습

하네스 러닝 연구진은 실행 보고서를 바탕으로 파이썬 하네스 코드의 수정을 제안하는 모델을 GRPO로 학습했다. 실험에서 하네스를 사용하는 솔버의 파라미터는 고정했다. 근거 B

실패한 롤아웃 폐기의 영향

Rocket 분석 보고서의 작성자는 실패한 롤아웃을 즉시 폐기하면 학습 지연이 줄어드는 한편, 특정 실패 패턴이나 복잡도를 공유하는 샘플이 제외돼 GRPO의 어드밴티지 산출에 편향이나 잡음이 생길 수 있다고 분석했다. 근거 C

인용

테스트를 통과한 성공 궤적(Test-passing trajectories) 모두에 동일한 결과 어드밴티지(Outcome Advantage)를 부여하는 근본적인 한계를 가진다.
