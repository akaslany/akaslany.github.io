추출 근거

특정 장기 코딩 RL 학습 작업(Long-horizon coding RL tasks)에서 End-to-end RL 학습 처리량이 2.3배 이상 향상되었습니다.

보고서가 인용한 시스템 최적화 결과에 따르면 특정 장기 코딩 강화학습 작업에서 전체 학습 처리량이 2.3배 이상 향상됐다. 근거 A

RL 최적화에 있어 코딩이 핵심 데이터 소스가 된 이유는 '보상(Reward)의 명확성' 때문입니다. 코드는 실행했을 때 작동 여부를 0과 1로 명확히 판별할 수 있습니다.

보고서는 코드의 작동 여부를 명확하게 판별할 수 있다는 점을 코딩이 강화학습에 적합한 이유로 설명한다. 근거 B
