모델 개발과 훈련 설계

카부쿠오글루는 인터뷰에서 Google DeepMind가 Gemini 4를 개발 중이며 역대 가장 야심 찬 사전학습을 추진하고 있다고 설명했다. 보고서는 이 발언을 내부 개발 계획의 근거로 분류했다. 근거 A

Core Automation은 모델의 초기 능력을 형성하는 사전학습과 결과를 최적화하는 강화학습을 하나의 최적화 과정으로 통합해 훈련 효율을 높이는 것을 목표로 한다. 근거 B

학습 데이터 구성

Jerry Tworek은 AI 생성물이 늘면서 사전학습이 다른 모델의 출력을 학습하는 증류 과정으로 바뀌고 있다고 경고했다. 근거 B

훈련 손실과 능력 평가

OpenAI의 평가를 분석한 보고서에 따르면, 원출처는 사전학습 손실이 줄어들면 예측하기 어려웠던 고도 능력의 대부분이 나타난다고 주장했다. 또한 안전 기술이 능력 향상 속도를 따라가지 못할 위험에 대응해 혼잡도에 기반한 업계 공통 개발 제한선을 제안했다. 근거 C

같은 원출처는 평가 데이터와 사전학습 데이터의 구성 차이로 연구소 간 혼잡도를 직접 비교하기 어렵다고 지적했다. 생각의 사슬 추론처럼 사전학습 밖에서 얻은 성능 향상도 이 지표에 직접 반영되지 않는다고 설명했다. 근거 C
