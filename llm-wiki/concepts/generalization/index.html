데이터와 모델 탐색

Q는 연구 방향 선언문에서 데이터 가용성이 경사하강법 기반 신경망의 확장을 제약한다고 진단했다. 적은 데이터로도 잘 일반화하고 대규모 데이터가 있을 때는 이를 활용할 수 있는 학습 알고리즘을 우선 과제로 제시했다. 근거 B

Q는 계산 자원이 무한하다는 가정 아래, 관측 데이터와 일치하는 모델을 탐색하고 보편 일반화 사전지식으로 일반화가 잘될 모델을 선별하는 방식을 제안했다. 근거 B

안전성과 정렬 이탈

슈츠케버는 인터뷰에서 일반화의 질을 높이면 모델의 능력과 안전성을 함께 개선할 수 있다고 설명했다. 근거 A

Anthropic은 정렬 이탈을 유도하도록 미세조정한 실험 모델에서 학습 데이터에 직접 제시되지 않은 평가 영역으로 정렬 이탈 행동이 퍼지는 현상을 관찰했다. 모니터가 감지한 학습 사례를 제거하고 다시 학습한 뒤에도 이 현상이 나타났다. 보고서는 이를 학습 데이터 모니터링의 잠재적 한계로 해석했다. 근거 C

과제 간 일반화의 측정

슬레거리스의 초지능 전망을 분석한 보고서는 검증 가능한 과제에서 향상된 AI 역량이 검증하기 어려운 과제로 얼마나 일반화되는지 체계적으로 측정할 벤치마크가 부족하다고 지적했다. 근거 D

인용

근거 C
