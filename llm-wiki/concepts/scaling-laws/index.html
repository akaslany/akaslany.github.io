모델 학습 비용 추정

SMELT 논문의 저자들은 희소 전문가 혼합 모델 실험에서 토큰당 학습 연산량, 비임베딩 파라미터 수, KV 캐시 규모를 기준 모델과 비슷하게 맞췄다. 저자들은 SMELT의 최종 학습 손실이 더 낮았다고 보고했으며, 스케일링 법칙을 적합해 같은 손실에 도달하는 데 필요한 학습 연산량의 절감 폭을 실험이 뒷받침하는 계산량과 희소도 범위에서 추정했다. 근거 B

군집화 실험에서의 검증

Meta FAIR의 e-means를 다룬 보고서는 스케일링 법칙을 적합할 때 사용하지 않은 데이터셋과 규모에서도 그 법칙을 적용했을 때의 손실이 실험에서 확인한 최적 손실에 가까웠다고 전한다. 근거 C

고성능 칩 의존성과 정책

오픈웨이트 모델 정책을 다룬 앤트로픽 보고서는 스케일링 법칙에 따른 칩 의존성을 확인된 사실로 분류했다. 앤트로픽은 고성능 칩과 제조 장비의 대중국 수출을 차단하자고 제안했다. 근거 A
