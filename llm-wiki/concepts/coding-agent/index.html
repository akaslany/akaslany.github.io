개발 현장의 활용

사이먼 윌리슨은 회고에서 Claude Code와 Codex를 사용하는 코딩 에이전트가 일상적인 소프트웨어 개발에 투입할 만한 신뢰성에 도달했다고 평가했다. 이 회고를 정리한 보고서는 간단한 작업의 자동화가 개발 속도를 높이면서 엔지니어에게 더 어려운 문제를 남긴다고 해석했다. 근거 A

같은 보고서에 따르면 StrongDM의 Dark Factory는 코드 작성과 리뷰를 에이전트에 맡기는 개발 방식을 채택했다. 근거 A

하네스와 과업에 따른 성과

DeepSWE 실험에서는 같은 모델도 하네스에 따라 성공률이 달라졌다. 실험 보고서의 작성자는 모델과 하네스를 결합한 시스템 전체를 평가하라고 권고했다. 보고서는 과제별 반복 실행이 제한적이어서 재현성 수치를 상한으로 해석해야 한다고 덧붙였다. 근거 B

OpenAI의 내부 측정에서는 사람의 개입 없이 과업을 완수하는 비율이 관측 기간에 상승했다. 과업별 격차도 컸으며, 학습 상태 모니터링의 완수율이 추론·서빙 코드 작성보다 높았다. 근거 D

장시간 실행을 위한 인프라

모프는 코딩 에이전트 개발자를 위한 요금제 Morph Ultra를 발표했다. 관련 인터뷰에 따르면 모프는 장시간 세션의 KV 캐시를 오래 보존하기 위해 클러스터에 스토리지 노드를 추가 배치한다. 근거 C
