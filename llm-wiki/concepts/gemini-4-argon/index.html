근거 소스 4편

출시와 추론 기능

구글 딥마인드는 제미나이 4 아르곤의 정식 출시를 발표했다. 출시 보고서에 따르면 제미나이 앱, AI 스튜디오, 구글 클라우드의 제미나이 API, 안티그래비티에서 이용할 수 있다. 근거 C

대담 발언자들은 아르곤이 디코딩을 이어가며 장시간 추론할 수 있다고 설명했다. 출시 보고서에 따르면 앱과 API에서는 사용자가 선택적으로 추론 요약을 볼 수 있다. 후속 보고서에서 구글은 연산 효율을 높인 증류 모델을 개발해 접근성을 확대할 계획이라고 밝혔다. 근거 C · 근거 D

적용 사례

출시 대담을 다룬 보고서에 따르면 안티그래비티 팀은 기존 포트란 코드를 러스트로 전환하는 데 아르곤을 사용했다. 같은 보고서는 아르곤이 기존 디버깅 도구와 오류 정정 메모리에서 감지되지 않았던 고대역폭 메모리의 데이터 손상을 진단했다고 전했다. 근거 C

적용 사례를 분석한 보고서는 핵융합 연구에서 Grad의 가설에 대한 확장된 형태의 반례 해 집합이 발견돼 논문으로 공개됐다고 기록했다. 같은 보고서에 따르면 카트휠은 일반 영상을 물리 엔진을 적용할 수 있는 입체 장면으로 변환하는 작업에서 실행 시간과 토큰 사용량이 줄었다고 평가했다. 근거 A

안전성 평가

안전성 보고서가 인용한 원평가는 완화 조치가 없는 모델이 생물학적 임계 역량 수준에 도달했을 가능성을 배제할 수 없다고 판단했다. 사이버 평가도 해당 영역의 임계 역량 수준에 도달했을 가능성을 배제할 수 없다고 결론 내렸다. 근거 B

안전성 보고서에 따르면 구글은 모델 역량의 오용을 막기 위해 다층 방어를 적용했다. 완화 조치 적용 후 평가에서 사이버 탈옥의 종합 목표 성공률은 비교 대상 모델보다 낮았다. 근거 B

인용

제미나이 앱(Gemini app), AI 스튜디오(AI Studio), 구글 클라우드 기반 제미나이 API(Gemini API on cloud), 그리고 안티그래비티(Antigravity) 플랫폼
