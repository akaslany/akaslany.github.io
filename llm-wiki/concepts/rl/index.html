미세조정과 보상 검증

Denny Zhou의 강연을 정리한 보고서는 강화학습 미세조정의 목표를 모델이 직접 생성한 풀이의 품질을 높이는 것으로 설명한다. Zhou는 추론 강화학습에서 알고리즘의 복잡성보다 신뢰할 수 있는 검증기를 확보하는 일이 더 중요하다고 본다. 근거 D

Poetiq은 모델이 풀이에 필요한 개별 사실을 이미 알고 있고 정답 일치 여부로 보상을 검증할 수 있는 추론 실패를 강화학습 후보로 제안한다. 근거 E

검색과 게임 실험

Neon과 Castform의 검색 과제 자체 평가에서는 강화학습 후 모델의 평균 보상이 높아졌다. 보고서는 이 평가가 독립 검증을 거치지 않았다고 밝힌다. 근거 B

Odysseus 실험은 게임 캐릭터의 가로 이동량을 훈련 보상으로 사용했으며, 평균 진행 거리는 기반 모델보다 길었다. 저자는 훈련에 사용되지 않은 궤적에서의 성능 향상을 일반화의 징후로 해석했다. 보고서는 범용 규칙을 학습했는지 입증되지 않았으며 독립 재현도 확인하지 못했다고 밝혔다. 근거 C

사전학습과의 공동 최적화

Core Automation을 다룬 보고서가 인용한 인터뷰와 기사는 사전학습과 강화학습을 하나의 시스템으로 공동 최적화하면 연산 효율을 높일 수 있다고 전망한다. 근거 A

인용

RL의 핵심은 모델이 **'자신이 생성한 분포(Self-generated distribution)'**에서 나온 풀이를 대상으로 생성 품질을 직접 최적화한다는 목표에 있습니다.
