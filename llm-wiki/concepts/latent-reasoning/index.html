모델 내부의 잠재 추론

HybridAgent의 원출처는 모델이 한 생성 과정에서 연속적인 잠재 공간의 추론과 텍스트를 통한 외부 도구 호출을 오갈 수 있다고 설명한다. HybridLink는 마지막 층의 은닉 상태를 입력 임베딩 공간으로 변환한다. 근거 A

HybridAgent 보고서 작성자는 벤치마크에서 기존 텍스트 기반 및 잠재 추론 기반 비교 모델보다 성능이 높았으며, 텍스트 토큰 사용량과 연산 비용이 줄고 추론 속도가 빨라졌다고 평가했다. 근거 A

시각 평가에서의 잠재 추론

HSS 보고서는 화면에 직접 나타나지 않은 맥락과 상태, 기저의 인과관계를 복원하는 능력을 평가한다. 이 평가에서는 인간의 정답률이 최고 성능을 기록한 단일 모델과 에이전트보다 높았다. 근거 B

HSS 보고서의 오류 분석에서는 비디오 과제 실패의 절반 이상이 잠재 추론 오류로 분류됐다. 결정적 단서를 놓친 사례도 이 범주에 포함됐다. 근거 B

인용

단일 생성 과정(Single Generation Process) 내에서 연속적인 잠재 추론 공간과 명시적인 텍스트 기반 외부 환경 상호작용을 동적으로 전환하는 통합 아키텍처

근거 A
