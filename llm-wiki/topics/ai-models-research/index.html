모델의 예측과 학습

다음 토큰 예측을 분석한 보고서는 예측 학습이 데이터의 공통 구조를 포착하도록 유도할 수 있다고 본다. 서로 다른 세계 모형이 같은 텍스트 분포를 설명할 수 있어, 예측 성능만으로 실제 생성 과정의 인과관계를 식별하기는 어렵다고 지적한다. 근거 F

중간층을 선별해 강화학습한 프리프린트는 수학 추론 실험에서 전체 층을 훈련한 경우와 대등하거나 더 높은 성능을 보고했다. 코드와 에이전트 과제에서도 같은 훈련 전략이 성능을 높이는지는 후속 검증 과제로 남았다. 근거 Q

수학 추론과 성과 검증

OpenAI는 Astra가 장기 미해결 문제에서 해법을 찾거나 상당한 진전을 냈다고 발표했다. 별도의 OpenAI 내부 모델 증명집 분석은 수학적 주장을 확정하려면 독립적인 동료 심사가 필요하다고 판단했다. 근거 AC · 근거 B

Gowers의 논의를 검토한 보고서는 검증 가능한 후보를 폭넓게 탐색하는 능력을 언어 모델의 강점으로 평가한다. Gowers는 분기가 많은 증명 탐색에서 가능성이 낮은 방향을 일찍 버리는 판단이 당분간 인간의 강점일 수 있다고 보았다. 근거 AC

과학 연구 자동화

과학용 AI를 분석한 보고서는 문제 정의부터 실험과 검증까지 이어지는 연구 과정에서 검증 자동화와 피드백 속도가 분야별 진전의 차이를 만든다고 본다. 실제 실험이 필요한 분야에서는 실험 비용과 시간이 병목으로 남는다. 근거 AM

발견 사례를 종합한 보고서는 검색, 메모리, 검증기, 실험 환경과 인간 감독을 결합한 시스템에서 제한된 해법 발견의 근거가 강하다고 평가했다. 자율적인 패러다임 전환은 입증되지 않았으며, 보고서는 모델과 데이터를 먼저 고정한 뒤 새 문제를 제공하는 전향적 평가를 제안했다. 근거 AQ
