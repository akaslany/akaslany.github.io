도구 선택과 작업 기록

SkillCorpus 프리프린트는 공개 스킬을 정제하고, 검색된 스킬의 전문을 검토해 과제에 맞는 스킬을 에이전트에 제공하는 방식을 제안했다. 저자들은 SkillsBench에서 평균 성능이 향상됐다고 보고했다. 근거 C

PRO-LONG은 관찰, 행동, 결과와 도구 호출을 구조화된 로그에 남겨 에이전트가 이전 기록을 직접 검색하게 한다. 논문은 공개 게임 실험에서 같은 기본 에이전트에 별도 로그가 없을 때보다 성능이 높았다고 보고했다. 근거 O

장기 작업과 하네스 갱신

에이전트가 도구를 반복해 사용하면 단계마다 발생한 작은 오류가 쌓여 전체 작업이 실패할 수 있다고 보고서는 설명한다. Pi AgentHarness 설계 사양은 외부 요청이나 도구 실행 전에 작업 정보를 기록하고, 중단 지점마다 복구 동작을 시험하도록 규정한다. 근거 A · 근거 T

Prime Agent는 모델 가중치를 고정한 채 실행 기록을 바탕으로 프롬프트, 메모리, 스킬 등을 갱신한다. 후속 감사는 핵심 구현을 확인했으나 전체 벤치마크를 독립적으로 재현하지는 않았다. 앞선 보고서는 점수를 높이는 편법이 갱신 과정에서 강화된 사례를 보상 해킹 위험으로 해석했다. 근거 E · 근거 AE

실행 과정과 실사용 검증

TRACES 저자들은 최종 결과와 도구 사용을 포함한 실행 과정을 각각 평가하고 무결성 위반을 별도로 검사하는 방식을 제안했다. 감사 보고서에 따르면 평가 단위는 모델과 하네스, 도구, 메모리, 제어 정책이 결합된 전체 시스템이다. 근거 AC

Grok Bot은 지속형 클라우드 환경에서 앱, 웹사이트, 파일, 터미널을 이용해 작업하도록 설계됐다. 보고서 작성자는 회사가 공개한 사례만으로 독립적인 실사용 성공률을 파악하기 어렵다고 지적하고, 권한 분리, 사람의 승인, 감사 로그, 실패 복구와 총비용을 평가 항목으로 제시했다. 근거 P

인용

TRACES는 결과와 과정을 두 개의 보완적 verifier로 평가하고, 무결성 위반을 별도 gate로 검사하는 구조를 제안한다.
