보고서는 DeepSeek 기술 보고서를 근거로 전체 약 671B개 파라미터 중 토큰 생성 시 약 37B개가 활성화된다고 설명한다. 근거 A

보고서가 인용한 DeepSeek 공식 요금표에 따르면 캐시 적중 입력은 100만 토큰당 0.014달러로 일반 입력의 10분의 1 수준이다. 근거 A

기술적으로 확보된 '절감분'을 내부 이익으로 취하지 않고, 시장 점유율 확대를 위해 소비자 가격에 즉각 반영하는 전략을 취하고 있습니다.

작성자는 DeepSeek이 시장 점유율을 높이기 위해 기술로 줄인 비용을 API 가격에 즉각 반영한다고 해석한다. 근거 A
