기업용 제미나이 에이전트

구글 클라우드가 발표한 제미나이 에이전트는 공통 인터페이스와 API를 통해 업무 목표와 원하는 결과물을 위임받는다. 발표에 따르면 복잡한 과제를 단계별로 처리하기 위해 하위 에이전트를 임시로 구성해 조율한다. 발표를 다룬 보고서는 Gmail, Drive, Docs 등 Google Workspace 앱에서 바로 작동한다고 설명한다. 근거 B

앤트로픽의 클로드 오퍼스 출시를 다룬 보고서는 해당 모델을 출시 시점부터 구글 클라우드에서 이용할 수 있었다고 전한다. 근거 A

AI 연산 인프라

구글은 기밀 컴퓨팅 기반의 보안 추론과 소규모 학습에 특화된 TPU 8tx와 긴 문맥 처리용 TPU 8i Max를 발표했다. 이 발표를 다룬 보고서에 따르면 TorchTPU 공개로 기존 PyTorch 코드와 Hugging Face 모델을 수정 없이 TPU에서 실행할 수 있게 됐다. 근거 D

이네퍼블 인텔리전스를 다룬 보고서에 따르면 이 연구실은 구글 클라우드의 최대 규모 엔비디아 루빈 GPU 클러스터를 이용하는 계약을 맺었다. 근거 C

에이전트 실행 규칙 연구

구글 클라우드 연구진은 외부 평가자 없이 에이전트의 실행 규칙을 개선하는 GUARD를 제안했다. 연구를 다룬 보고서에 따르면 GUARD는 작업 프롬프트와 도구 스키마에서 검증 조건을 도출하고, 기존에 성공한 동작의 성능 저하에 따른 불이익보다 순이득이 클 때만 수정안을 채택한다. 근거 E

인용

제미나이 에이전트는 단일 인터페이스 및 단일 API를 통해 사용자의 단순 세부 지시가 아닌 '목표(Objective)'와 '결과물'을 위임받아 작업을 수행하는 단일·보편적 엔터프라이즈 에이전트다.
