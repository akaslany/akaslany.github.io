보고서에 따르면 Core Automation은 연구자가 아이디어를 실험하고 검증하는 반복 주기를 단축하는 자동화 연구소를 지향한다. 근거 A

Core Automation은 새로운 모델 발표보다 커널 생성(Kernel Generation; GPU에서 실행되는 하위 연산 프로그램 작성) 자동화를 최우선 과제로 설정했습니다.

보고서에 따르면 Core Automation은 GPU 연산 커널 생성 자동화를 단기 최우선 과제로 삼았다. 근거 A

모델은 배포 후에도 사용자의 데이터로부터 실시간으로 학습해야 합니다.

보고서는 Core Automation이 배포 후에도 사용자의 데이터로 실시간 학습하는 모델을 지향한다고 설명한다. 근거 B
