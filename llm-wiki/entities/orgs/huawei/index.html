타우 스케일링과 LogicFolding

화웨이의 타우 스케일링은 칩과 시스템의 성능 개선에서 신호 지연 최소화를 우선하는 설계 전략이다. LogicFolding은 논리 블록 내부의 게이트와 임계경로를 수직으로 나누어 배치하는 기술이다. 초기 검토는 칩이 실리콘 샘플 단계라고 설명했고, 후속 보고서는 Kirin 9050 Pro를 탑재한 Mate XT 2의 공식 출시를 근거로 양산 단계 진입을 확인했다. 근거 B · 근거 C

후속 보고서는 화웨이가 발표한 면적당 밀도 증가를 로직 층을 수직으로 쌓은 결과로 설명했다. 전력 절감은 화웨이 내부 측정에 근거했으며, 보고 시점에는 전력에 대한 독립 벤치마크와 본딩 간격에 대한 독립 단면 실측이 없었다. 층간 온도 주장 검증에 필요한 측정 정보도 공개되지 않았다. 근거 C

어센드와 슈퍼팟 전략

박수현의 분석에 따르면 화웨이는 개별 칩의 성능 열세를 여러 칩과 연산 인프라로 보완하는 슈퍼팟 전략을 공개했다. 별도의 DeepSeek API 분석 보고서는 화웨이 어센드 칩셋의 도입 원가가 엔비디아 칩셋보다 낮을 것으로 추정했다. 근거 D · 근거 A

호림골의 AI 연산 인프라

호림골 분석 보고서는 위성 영상으로 시설의 가동 징후를 파악하고, 칩 출하량과 배치 시차를 모델링해 가동 연산력을 추정했다. 보고서는 신규 건물이 가동되면 연산력이 늘어날 것으로 전망했으며, 위성 영상만으로는 내부 랙의 장착 상태와 실제 서버 가동률을 정밀하게 확인하기 어렵다고 밝혔다. 근거 E
