사후 학습과 코딩 성능

Z.ai는 GLM-5.3이 전작과 같은 기반 모델에서 출발했으며, 성능 향상은 사후 학습 규모를 늘린 결과라고 설명했다. Z.ai는 전작 대비 코딩 성능이 크게 향상됐다고 보고했다. 보고서가 검토한 공개 코딩 평가에서는 일부 경쟁 모델보다 점수가 낮았다. 근거 B · 근거 C

보안 평가와 가중치 공개 계획

Z.ai는 사후 학습 규모를 늘린 뒤 다단계 보안 평가 성능이 향상됐다고 보고했으며, 이를 창발적 사이버 역량으로 해석했다. 보고서 작성자는 Z.ai 발표 본문과 보안 공개 원장 요약이 같은 집계에 서로 다른 심각도 범주를 적용했다고 지적했다. 근거 B

발표 당시 가중치는 미공개 상태였다. Z.ai는 안전성 평가와 보안 강화를 마친 뒤 가중치를 공개할 계획이라고 밝혔다. 근거 B
